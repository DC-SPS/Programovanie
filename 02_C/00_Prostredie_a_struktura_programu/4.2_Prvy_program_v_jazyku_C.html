4.2 Prvý program v jazyku C

1 × 45 min Tematický celok 4 C17 VS Code + GCC

Nadväznosť na predchádzajúcu prednášku

V prednáške 4.1 ste spoznali jazyk C, jeho vývoj a význam štandardu C17. Teraz vytvoríte prvý jednoduchý program: textový súbor zapísaný v C preložíte pomocou GCC a spustíte. Zatiaľ sa sústredíme na štruktúru programu a výstup; ladenie a vstup z klávesnice budú témou ďalších prednášok.

Ciele vyučovacej hodiny

Po absolvovaní hodiny žiak dokáže:

  • vytvoriť základný program v C so súborom hlavičky a funkciou int main(void);
  • vysvetliť účel #include <stdio.h>, printf, bodkočiarky a return 0;;
  • zapísať a predpovedať výstup aspoň dvoch volaní printf s novým riadkom;
  • preložiť súbor .c pomocou GCC v režime C17 a spustiť vytvorený program, ak je prostredie dostupné.

1. Motivácia: počítač vypíše hlásenie

Predstavte si jednoduchý testovací program, ktorý po spustení zobrazí obsluhe správu, že meranie sa začína. Počítač však nevie, čo chceme, kým presný pokyn nezapíšeme v jazyku, ktorému rozumie jeho nástroj na spracovanie programu.

Otázky na úvod: Čo musí programátor pripraviť, aby sa hlásenie zobrazilo? Je súbor s textom programu už hotovým programom, ktorý počítač vie spustiť?

V tejto hodine pripravíme zdrojový súbor, v ktorom bude pokyn na výpis textu. Kompilátor z neho vytvorí spustiteľný program.

2. Teoretický výklad

Zdrojový kód a kompilátor

Zdrojový kód je text programu zapísaný programátorom. V tejto lekcii ho uložíme do súboru s príponou .c, napríklad main.c. Kompilátor spracuje tento text podľa pravidiel jazyka a vytvorí spustiteľný súbor. VS Code je editor, v ktorom píšeme kód; GCC je samostatný kompilátor.

Postup môžeme zhrnúť takto:

main.c (zdrojový kód) → GCC (preklad v režime C17) → spustiteľný program → výstup v termináli

Základná štruktúra programu

V bežnom prostredí má jednoduchý program v C jednu funkciu main. Vykonávanie sa začína v tejto funkcii. Zápis int main(void) znamená, že funkcia vracia celočíselný výsledok a neprijíma argumenty. Na začiatku používame return 0; na vyjadrenie úspešného skončenia.

Hlavičkový súbor <stdio.h> sprístupní deklaráciu funkcie printf, ktorú použijeme na výpis textu na štandardný výstup, obyčajne do terminálu. Riadok #include je pokyn pre preprocesor, preto sa zaň nepíše bodkočiarka.

Príkaz, bodkočiarka a nový riadok

Volanie printf("Ahoj, svet!\n"); vypíše text v úvodzovkách. Zápis \n je riadiaca sekvencia označujúca nový riadok. Bodkočiarka ukončuje príkaz. Zložené zátvorky { } ohraničujú telo funkcie main.

Komentáre

Komentár vysvetľuje zdrojový kód človeku; kompilátor ho nepovažuje za vykonávaný príkaz. V C17 môžeme použiť jednoriadkový komentár // text alebo viacriadkový komentár /* text */. Komentár má objasňovať zámer, nie zbytočne opakovať, čo už jasne hovorí kód.

Preklad a spustenie

Uložte súbor ako main.c. V termináli otvorte priečinok, v ktorom sa tento súbor nachádza, a zadajte:

gcc -std=c17 -Wall -Wextra -Wpedantic main.c -o prvy_program
  • gcc spustí kompilátor GCC;
  • -std=c17 zvolí režim štandardu C17;
  • -Wall -Wextra -Wpedantic zapne užitočné upozornenia;
  • main.c je vstupný zdrojový súbor a -o prvy_program určuje názov výsledného programu.

Vo Windows PowerShelli spustite vytvorený súbor príkazom .\prvy_program.exe. V Linuxe použite ./prvy_program. Ak GCC nie je nainštalované alebo dostupné cez terminál, preklad v tejto hodine vykoná učiteľ na pripravenom zariadení; problém s nastavením prostredia budeme riešiť osobitne.

3. Názorné programové príklady

Príklad 1 – prvý pozdrav

Problém: po spustení programu zobrazte používateľovi krátky pozdrav.

#include <stdio.h>

int main(void) {
    // Vypiseme uvodny pozdrav.
    printf("Ahoj, svet!\n");
    return 0;
}

Očakávaný výstup:

Ahoj, svet!

Rozbor: Príkaz #include sprístupní printf. Program začne vykonávať telo funkcie main, vypíše text a sekvenciou \n prejde na ďalší riadok. Potom vráti hodnotu 0 a skončí.

Príklad 2 – hlásenie testovacej stanice

Problém: zobrazte dve krátke správy, každú na samostatnom riadku.

#include <stdio.h>

int main(void) {
    printf("Meranie sa zacina.\n");
    printf("Stav: pripraveny.\n");
    return 0;
}

Očakávaný výstup:

Meranie sa zacina.
Stav: pripraveny.

Každé volanie printf vypíše svoju správu. Každý text končí sekvenciou \n, preto sa druhé hlásenie zobrazí na novom riadku.

Krátka analýza chyby

#include <stdio.h>

int main(void) {
    printf("Program spusteny\n")
    return 0;
}

Všimnite si chýbajúcu bodkočiarku po volaní printf. V C sa príkaz musí ukončiť bodkočiarkou. Predpovedzte, akú informáciu môže kompilátor oznámiť, a opravte riadok.

4. Samostatná práca (10 minút)

Úloha A – povinná: pozdrav

Vytvorte súbor main.c a program, ktorý vypíše jeden krátky pozdrav na samostatný riadok.

Očakávané správanie: po spustení sa v termináli zobrazí pozdrav a kurzor prejde na nový riadok.

Kritérium úspechu: súbor obsahuje #include <stdio.h>, funkciu int main(void), jedno volanie printf ukončené bodkočiarkou a return 0;.

Úloha B – dve stavové správy

Upravte svoj program tak, aby vypísal dve vlastné stavové správy, každú na samostatnom riadku. Aspoň jedna správa nech sa týka merania, zariadenia alebo pracoviska.

Očakávané správanie: zobrazia sa presne dve správy v zadanom poradí.

Kritérium úspechu: použijete dve volania printf a na konci každej správy bude \n.

Úloha C – rozšírenie pre rýchlejších

Pridajte komentár, ktorý vysvetľuje účel programu, a zmeňte poradie dvoch stavových správ. Pred spustením zapíšte, v akom poradí sa zobrazia.

Očakávané správanie: výstup zodpovedá novému poradiu volaní printf; komentár sa vo výstupe nezobrazí.

Kritérium úspechu: viete odôvodniť poradie výpisu podľa postupnosti príkazov a odlíšiť komentár od vykonávaného príkazu.

Postup pri práci: Najprv predpovedzte výstup, potom program spustite. Ak GCC nie je na počítači dostupné, dokončite zápis a kontrolu kódu; preklad zabezpečí učiteľ. Riešenia úloh nie sú súčasťou zadania.

5. Opakovanie a overenie vedomostí

  1. Ktorý súbor spracuje kompilátor: main.c alebo spustiteľný súbor?
  2. Prečo pripájame <stdio.h>?
  3. Kde sa začína vykonávanie bežného programu v C?
  4. Čo vypíše program, ak sa v reťazci printf nachádza \n?
  5. Čo treba opraviť v ukážke s chybou: názov funkcie, hlavičku alebo ukončenie príkazu?

Otázka na princíp: Prečo nestačí napísať zdrojový kód do VS Code, ak chceme program spustiť?

Očakávané odpovede: Kompilátor spracuje main.c; stdio.h deklaruje printf; vykonávanie sa začína vo funkcii main; \n presunie výstup na nový riadok; v chybovej ukážke chýba bodkočiarka. VS Code je editor a na vytvorenie spustiteľného programu potrebujeme kompilátor.

Lístok pri odchode

Na konci hodiny odpovedzte stručne:

  1. Ktorý príkaz v dnešnom programe vypisoval text?
  2. Čo vytvorí GCC po úspešnom preklade?
  3. Uveďte jednu chybu, na ktorú si pri zápise programu v C treba dávať pozor.

Poznámky a povinné vedomosti, ktoré si zapamätať z hodiny

  • Zdrojový kód programu v C uložte napríklad do súboru main.c; GCC ho preloží na spustiteľný program.
  • V bežnom hostovanom programe sa vykonávanie začína vo funkcii int main(void).
  • #include <stdio.h> sprístupní deklaráciu funkcie printf.
  • printf("Text\n"); vypíše text a \n presunie výstup na nový riadok.
  • Príkazy ukončujte bodkočiarkou; telo funkcie ohraničujú zložené zátvorky.
  • Komentáre // ... a /* ... */ slúžia na vysvetlenie kódu a nevypisujú sa.
  • Príklad prekladu: gcc -std=c17 -Wall -Wextra -Wpedantic main.c -o prvy_program.
  • Na typické chyby patrí chýbajúca bodkočiarka, hlavička alebo nesprávny názov súboru v príkaze prekladu.
