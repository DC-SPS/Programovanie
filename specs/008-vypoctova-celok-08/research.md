# Research sources and decisions

- Raspberry Pi OS and Imager: https://www.raspberrypi.com/software/raspberry-pi-os/
- Raspberry Pi remote access and SSH: https://www.raspberrypi.com/documentation/computers/remote-access.html
- GPIO Zero input devices: https://gpiozero.readthedocs.io/en/stable/api_input.html
- GPIO Zero output devices: https://gpiozero.readthedocs.io/en/stable/api_output.html
- Linux GPIO character device API: https://www.kernel.org/doc/html/latest/userspace-api/gpio/chardev.html
- Linux sysfs GPIO is obsolete: https://www.kernel.org/doc/html/latest/userspace-api/gpio/sysfs.html
- systemd systemctl: https://www.freedesktop.org/software/systemd/man/latest/systemctl.html

Wokwi Raspberry Pi Pico emulates an MCU, not a Raspberry Pi Linux SBC. Shell and GPIO Zero examples therefore link to Raspberry Pi documentation and require Raspberry Pi OS hardware.
