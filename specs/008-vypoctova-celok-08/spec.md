# Specification: Computing Technology - Theme 08

## Goal
Add seven separate 45-minute lessons about SBC computers and their operating systems using the supplied material.

## Requirements
- Preserve the supplied explanation, objectives, lesson timing, examples, activities, and summaries.
- Add course navigation, sources, and accessible copy controls for code.
- State the compatible Raspberry Pi OS platform for shell and GPIO Zero examples.
- Distinguish the Raspberry Pi Linux SBC from the Raspberry Pi Pico MCU; do not claim Wokwi Pico simulates Raspberry Pi OS.
- Link all seven lessons from the course outline and README.

## Acceptance criteria
- Seven pages correspond to lessons 8.1 through 8.7.
- Every internal link resolves to an existing file.
- Every runnable shell/Python snippet has a copy control and platform note.
- GPIO examples retain 3.3 V safety and Linux timing limitations.
