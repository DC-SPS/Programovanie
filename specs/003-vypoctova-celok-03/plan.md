# Plán implementácie: Pamäťový systém a dátová reprezentácia

**Vetva:** `codex/vypoctova-celok-03`  
**Špecifikácia:** [spec.md](spec.md)

## Súhrn

Doplniť sedem samostatných HTML prednášok, prepojiť ich v osnove a README a uložiť špecifikáciu, plán, výskum a úlohy do `specs/`. Zachovať existujúci vzhľad a správanie materiálov.

## Technické rozhodnutia

- **Technológia:** statické HTML5/CSS a existujúce skripty kurzu.
- **Závislosti:** bez nových knižníc.
- **Cieľ:** prehliadač, desktop aj mobil.
- **Rozsah:** 7 prednášok po 45 minút, index, README a dokumentácia Spec Kit.
- **Overovanie:** kontrola diffu, odkazov, počtu prednášok a úplnosti ovládacích prvkov; testy sa nepridávajú.

## Rozloženie

`05_Vypoctova_technika/3.1–3.7 ...html`, `05_Vypoctova_technika/index.html`, `05_Vypoctova_technika/README.md` a dokumenty v `specs/003-vypoctova-celok-03/`.

## Kontrola ústavy

- Obsah zachová lokálnu osnovu, formálne vykanie a metodickú štruktúru.
- Technické údaje o ATmega328P sa opierajú o datasheet Microchip.
- Každá spustiteľná AVR ukážka má Arduino Uno/Wokwi.
- Bez nových závislostí, testovacích balíkov ani zásahov do iných modulov.
