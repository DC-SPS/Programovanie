# Plán implementácie

1. Zoskupiť nastavenia existujúceho prehrávača do prístupného `<details>` bez zmeny jeho API.
2. Upraviť zdieľané štýly tak, aby ovládacie tlačidlá, stavy, fokus a nastavenia zodpovedali referenčnému panelu na veľkých aj malých obrazovkách.
3. Pridať spoločný hlasový prehrávač pre stránky, ktoré dnes nemajú existujúce ovládanie; integrovať ho do zdieľaných vstupných skriptov kurzov.
4. Pripojiť chýbajúci spoločný vstupný skript na prednášky Git a zabezpečiť, že prehľady predmetov nedostanú prehrávač.
5. Staticky skontrolovať rozsah stránok, skriptové cesty, diff a stav prístupných ovládacích prvkov.
