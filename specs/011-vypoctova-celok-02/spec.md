# Feature: Thematic unit 02 lessons

## Goal
Publish four Slovak 45-minute lessons on microcontroller architecture in the existing Výpočtová technika course.

## Requirements
- Preserve the four lesson titles, objectives, schedules, concepts, examples, class activities, checks for understanding, and notebook summaries in the supplied source.
- Follow the current course page design and use formal address to learners.
- Provide working previous/next lesson navigation, course index navigation, and README links.
- Include a complete copyable Arduino Uno sketch and an online Wokwi Arduino Uno simulator link on every lesson page.
- Cite authoritative technical documentation for AVR, Arm, Espressif, and Wokwi.
- Preserve unrelated local changes.

## Acceptance criteria
- Four lesson pages are linked from the course index and README.
- The four lessons cover Von Neumann/Harvard, MCU CPU/ALU/registers, the instruction cycle, and RISC/CISC/ARM.
- Internal links resolve, copy controls work, and code samples have a matching simulator link.
- All changes remain scoped to the course module and this specification.
