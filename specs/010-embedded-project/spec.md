# Specification: Computing Technology - Theme 10

## Goal
Publish five 45-minute lessons on designing and delivering an embedded project, using the supplied source and the course's formal Slovak style.

## Requirements
- Preserve the five lesson topics, timings, thermal monitoring example, requirements, architecture, testing, documentation, integration, and defense guidance.
- Link all five pages from theme 10 in the course outline and README.
- Add accessible copy controls to code examples and relevant Wokwi links for ESP32 examples.
- Explain the limits of simulated logic versus physical sensors and actuators.
- Add primary references for Wokwi ESP32 simulation and unit testing.

## Acceptance criteria
- Five pages correspond to lessons 10.1-10.5.
- All internal links and copy controls resolve.
- ESP32 code examples link to Wokwi ESP32 and use no real credentials.
- The outline and README list all five lessons.
