# Research sources and decisions

- Wokwi ESP32 simulation guide: https://docs.wokwi.com/guides/esp32
- Wokwi ESP32 Wi-Fi guest network: https://docs.wokwi.com/guides/esp32-wifi
- Wokwi supported hardware: https://docs.wokwi.com/getting-started/supported-hardware
- GoogleTest Primer: https://google.github.io/googletest/primer.html

The source has five lessons. Its C++ snippets describe a pure regulation function and documentation/comment examples. A Wokwi ESP32 link can run the regulation example with a test harness; it does not validate the physical sensor, fan driver, power supply, or the complete project.
