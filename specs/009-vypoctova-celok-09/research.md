# Research sources and decisions

- Arduino-ESP32 Wi-Fi API: https://docs.espressif.com/projects/arduino-esp32/en/latest/api/wifi.html
- Wokwi ESP32 Wi-Fi guest network: https://docs.wokwi.com/guides/esp32-wifi
- Wokwi supported boards: https://docs.wokwi.com/getting-started/supported-hardware
- TCP (RFC 9293): https://www.rfc-editor.org/rfc/rfc9293.html
- UDP (RFC 768): https://www.rfc-editor.org/rfc/rfc768.html
- HTTP semantics (RFC 9110): https://www.rfc-editor.org/rfc/rfc9110.html
- MQTT 5.0 specification: https://docs.oasis-open.org/mqtt/mqtt/v5.0/os/mqtt-v5.0-os.html
- Eclipse Mosquitto documentation and security: https://mosquitto.org/documentation/
- Bluetooth LE primer: https://www.bluetooth.com/bluetooth-le-primer/
- NIST IoT device cybersecurity baseline: https://csrc.nist.gov/pubs/ir/8259/a/final
- OWASP IoT Security Verification Standard: https://owasp.org/projects/iot-security-verification-standard

The ESP32 Wi-Fi example uses Wokwi-GUEST with an empty password and contains no credentials. Bash and Raspberry Pi Python examples need a compatible real machine or local environment. Do not provide a public anonymous broker as a classroom shortcut.
