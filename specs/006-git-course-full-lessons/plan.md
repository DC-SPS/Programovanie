# Plán: Kompletný kurz Gitu

**Špecifikácia:** [spec.md](spec.md)

## Implementácia

- Statické HTML stránky nadväzujúce na existujúci kurz.
- Jednotná navigácia medzi lekciami a späť na katalóg.
- Nultá stránka obsahuje tok Working Directory → Staging Area → Local Repository → Remote Repository a tabuľku príkazov.
- Praktické ukážky používajú bezpečné, lokálne cvičenia; deštruktívne príkazy sú vysvetlené opatrne.
- Odkazy na videá smerujú na overené priame URL alebo na príslušný index playlistu.

## Kontrola

Overiť počet stránok, existenciu interných odkazov, prítomnosť povinných častí a `git diff --check`. Testy nepridávať.
