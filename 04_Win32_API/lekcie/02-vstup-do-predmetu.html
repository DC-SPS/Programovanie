4. ročník SPŠ · Win32 API · C++ · Windows

V tomto kurze budeme postupne tvoriť natívne desktopové aplikácie pre Windows. Už poznáte programovanie v C/C++, Python, algoritmizáciu a základy OOP. Teraz tieto vedomosti využijeme pri práci s oknami, udalosťami, ovládacími prvkami, grafikou a dátami.

Ciele hodiny

Na konci hodiny dokážete:

  • vysvetliť, čo znamená natívna desktopová aplikácia pre Windows;
  • rozlíšiť Win32 API od štandardného C++ a od webovej aplikácie;
  • opísať štyri moduly kurzu a výsledný projekt;
  • pomenovať primárne nástroje kurzu a vysvetliť, na čo slúžia.

Čo vytvoríme?

Na konci kurzu budete vedieť navrhnúť a vytvoriť vlastnú natívnu aplikáciu. V spoločnej ukážkovej línii budeme postupne pracovať s evidenciou študentov: od dátového modelu cez okno a ovládanie až po ukladanie údajov.

Výsledok: aplikácia, ktorú viete zostaviť, spustiť, vysvetliť, zdokumentovať a odprezentovať.

Technické prostredie

  • Windows 10 alebo 11 – cieľová platforma natívnej aplikácie.
  • Visual Studio Code – editor a prostredie na prácu so zdrojovými súbormi.
  • MSVC v143 – primárny C++ kompilátor kurzu.
  • Windows SDK – hlavičky a knižnice potrebné pre Windows API.
  • C++17 a Unicode varianty Win32 funkcií (`...W`).

Win32 program zostavíme a spustíme vo Windows s príslušným vývojovým prostredím. Bežný online C++ editor bežiaci na Linuxe nemá Windows SDK a nespustí natívnu Win32 aplikáciu.

Zhrnutie: 6 dôležitých poznatkov

  1. Win32 API umožňuje C++ programu využívať funkcie operačného systému Windows.
  2. Cieľom je natívna desktopová aplikácia, nie webová simulácia okna.
  3. Primárne prostredie tvorí Windows, VS Code, MSVC v143 a Windows SDK.
  4. Kurz má štyri moduly a spolu 66 vyučovacích hodín po 45 minút.
  5. OOP modul obsahuje aj C++ prípravu potrebnú na ďalšiu prácu.
  6. Ukážková aplikácia rastie od dátového modelu k oknu, udalostiam, zobrazeniu a ukladaniu.

Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: natívna aplikácia je zostavená pre Windows a používa jeho API; Windows SDK poskytuje potrebné hlavičky a knižnice; online kompilátor môže bežať na inom systéme a bez Windows SDK; moduly sú Vstup do predmetu, Úvod do objektového programovania, Prostredie programu a Tvorba projektov.

Interaktívna otázka: správna odpoveď je B. Zdôrazni, že web môže koncept simulovať, ale taká simulácia nie je spustená Win32 binárka.

Hodnotenie úlohy: 5 bodov podľa uvedených kritérií; hodnotiť porozumenie a zdôvodnenie, nie predchádzajúcu znalosť Win32.

Podpora: ponúkni kartičky so štyrmi modulmi a obrázkový tok aplikácie. Neznáme názvy nástrojov vysvetli podľa ich úlohy, nie memorovaním značiek.
