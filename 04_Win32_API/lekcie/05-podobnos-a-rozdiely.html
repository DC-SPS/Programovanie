4. ročník SPŠ · C++ príprava pre Win32

Procedurálny aj objektový program môžu dosiahnuť rovnaký výsledok. Rozdiel je v tom, ako usporiadajú údaje a operácie. Porovnáme oba prístupy na malej úlohe: evidovať knihu a vypísať informáciu o nej.

Cieľ nie je označiť jeden prístup za vždy lepší, ale vybrať usporiadanie podľa úlohy
Začiatok hodiny: skontrolujte pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívajte. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážete:

  • vysvetliť, ako procedurálny program organizuje kroky a funkcie;
  • vysvetliť, ako objektový prístup spája stav a súvisiace operácie;
  • porovnať oba prístupy na rovnakom jednoduchom probléme;
  • zdôvodniť, kedy môže pomôcť zoskupenie dát do vlastného typu.

Prepojenie s predchádzajúcimi hodinami

Poznámeme triedu, objekty a ich atribúty. Teraz sa pýtame: ako napíšeme program, ktorý s týmito údajmi pracuje? V procedurálnom štýle sú dáta často samostatné a funkcie pracujú s nimi. V objektovom štýle sú údaje a súvisiace operácie usporiadané okolo objektu.

Rovnaká úloha, iné usporiadanie

Procedurálny pohľad

Program postupuje cez funkcie. Údaje sa odovzdávajú funkcii ako argumenty.

nazov + pocetStran
          ↓
  vypisKnihu(...)
          ↓
     text na výstupe

Objektový pohľad

Údaje patria konkrétnemu objektu. Operácia môže byť navrhnutá ako jeho metóda.

     objekt Kniha
  ┌──────────────┐
  │ názov        │
  │ počet strán  │
  │ vypis()      │
  └──────────────┘

Je to rozdiel v organizácii kódu, nie v tom, či program „má“ alebo „nemá“ funkcie. Objektový program môže používať aj samostatné funkcie a procedurálny program môže mať vlastné dátové typy.

Ukážka: jeden program, dva prístupy

#include <iostream>
#include <string>

// Procedurálny prístup: údaje a operácia sú oddelené.
void vypisKnihu(const std::string& nazov, int pocetStran) {
    std::cout << nazov << " (" << pocetStran << " stran)\n";
}

// Objektový prístup: stav a súvisiaca operácia sú spolu.
class Kniha {
public:
    std::string nazov;
    int pocetStran{};

    void vypis() const {
        std::cout << nazov << " (" << pocetStran << " stran)\n";
    }
};

int main() {
    // Procedurálne použitie
    std::string nazov = "Tajomny ostrov";
    int pocetStran = 240;
    vypisKnihu(nazov, pocetStran);

    // Objektové použitie
    Kniha kniha{};
    kniha.nazov = "Tajomny ostrov";
    kniha.pocetStran = 240;
    kniha.vypis();
}

Výstup oboch častí je rovnaký: názov knihy a počet strán. Procedurálna funkcia prijíma dva samostatné údaje. Metóda vypis je deklarovaná v triede a pracuje s členmi objektu, na ktorom ju zavoláme.

Nový zápis: const za zoznamom parametrov metódy znamená, že metóda sľubuje nemeniť stav objektu. const std::string& je odkaz na text, ktorý funkcia potrebuje prečítať bez vytvorenia kópie. V tejto ukážke ho možno čítať ako typovaný vstup funkcie.

Zostavenie a spustenie – MSVC

  1. Uložte kód ako pristupy.cpp.
  2. Otvorte Developer Command Prompt for VS 2022 a prejdite do priečinka súboru.
  3. Zostavte: cl /std:c++17 /EHsc /W4 /Fe:pristupy.exe pristupy.cpp.
  4. Spustite: pristupy.exe. Očakávate dva rovnaké riadky výstupu.

Je to konzolový príklad štandardného C++, nie Win32 aplikácia. Nepotrebuje Windows API ani samostatné systémové knižnice. Potrebuje pripravené prostredie MSVC.

Rozhodovacie pravidlo

  • Pre jednorazový výpočet s niekoľkými hodnotami môže stačiť funkcia.
  • Ak program eviduje veľa podobných vecí, vlastný typ pomôže pomenovať údaje každej z nich.
  • Ak operácie prirodzene patria k danému typu, možno ich navrhnúť ako metódy.
  • Štruktúru voľ podľa prehľadnosti a potrieb, nie podľa toho, že jeden štýl je vždy „správny“.

Interaktívna kontrola

Aplikácia eviduje 300 kníh. Každá má názov, počet strán a dostupnosť. Ktoré zdôvodnenie najlepšie vysvetľuje, prečo môže byť vhodný vlastný typ Kniha?

Vyberte odpoveď:

Praktická úloha: dve evidencie

Cieľ: zapísať informácie o knihe dvoma spôsobmi a porovnať ich čitateľnosť.

Predpoklady: premenné, funkcie, trieda a atribúty z predchádzajúcich hodín.

  1. Procedurálne: vytvorte funkciu, ktorá prijme názov knihy a počet strán a vypíše ich.
  2. Objektovo: vytvorte triedu s týmito atribútmi a metódou na výpis.
  3. V oboch prípadoch použite aspoň dve knihy.
  4. Označte, ktorý zápis sa ti ľahšie rozširuje o ďalšie knihy, a zdôvodnite odpoveď.

Očakávaný výsledok: oba varianty vypíšu rovnaké údaje; žiak vie opísať rozdiel v organizácii.

Kritériá (5 b): správna funkcia (1), zmysluplná trieda a členy (2), dve knihy (1), porovnanie s dôvodom (1).

  • Základná: doplňte volanie funkcie a vytvorte jednu inštanciu podľa vzoru.
  • Rozširujúca: pridajte atribút dostupnosti a vypíšte ho v oboch riešeniach.
  • Náročnejšia: vysvetlite, ako by sa menila čitateľnosť, keby pribudlo 50 kníh a ďalšie operácie.

Zhrnutie: 6 poznatkov

  1. Procedurálny prístup organizuje riešenie okolo funkcií a krokov.
  2. Objektový prístup organizuje program okolo objektov, ich stavu a súvisiacich operácií.
  3. Oba prístupy môžu vyriešiť tú istú úlohu a vypísať rovnaký výsledok.
  4. Objekt môže zoskupiť súvisiace hodnoty pod jedným názvom.
  5. Objektový program môže stále používať samostatné funkcie.
  6. Vyberáme usporiadanie, ktoré je primerané veľkosti a štruktúre úlohy.

Kontrolné otázky

  1. Ako procedurálna funkcia získa údaje knihy?
  2. Čo zoskupí objekt triedy Kniha?
  3. Je objektový prístup vždy najjednoduchší? Prečo?
  4. Môže objektový program obsahovať samostatné funkcie?
Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: procedurálna funkcia dostane údaje ako argumenty; objekt spája údaje jednej knihy a môže mať súvisiace metódy; objektový prístup nie je vždy najjednoduchší a pri malej úlohe môže byť zbytočne zložitý; áno, oba prístupy sa môžu kombinovať.

Interaktívna otázka: správna je B. Oprava miskoncepcie: procedurálne programy funkcie bežne používajú a žiadny prístup automaticky nezaručuje bezchybnosť.

Hodnotenie: 5 bodov podľa kritérií zadania. Pri zdôvodnení prijmi oba výbery, ak súvisia s konkrétnou mierkou a požiadavkami riešenia.

Podpora: nechaj žiaka vyplniť dve šablóny: „funkcia dostáva …“ a „objekt obsahuje …“. Vopred priprav názvy atribútov a nechaj sústrediť sa na umiestnenie údajov a volania.

Poznámky a povinné vedomosti, ktoré si zapamätáte z hodiny

  • Procedurálny prístup sústreďuje riešenie do funkcií a krokov.
  • Objektový prístup spája stav objektu so súvisiacimi operáciami.
  • Oba prístupy môžu dosiahnuť rovnaký výsledok.
  • Objektový prístup nie je vždy potrebný; štruktúru vyberám podľa problému.
