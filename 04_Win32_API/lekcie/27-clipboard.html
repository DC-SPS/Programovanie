Schránka Windows a práca s textom

Zisti, ako aplikácia načíta Unicode text zo schránky

4. ročník SPŠ · Natívne Win32 C++ · MSVC v143

Schránka umožňuje preniesť údaje medzi aplikáciami. Dnes ju iba otvoríme na čítanie, overíme dostupný textový formát a načítame text typu Unicode. Vkladanie do ovládacieho prvku a zapisovanie do schránky rozoberieme v ďalšej hodine.

OpenClipboard → IsClipboardFormatAvailable → GetClipboardData → CloseClipboard
Začiatok hodiny: skontroluj pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívaj. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážeš:

  • opísať schránku ako systémový priestor na dočasnú výmenu údajov medzi aplikáciami;
  • vysvetliť správne poradie otvorenia, kontroly formátu, získania dát a zatvorenia schránky;
  • načítať text vo formáte CF_UNICODETEXT cez GetClipboardData a GlobalLock;
  • rozpoznať situáciu, keď schránku nemožno otvoriť alebo neobsahuje požadovaný formát.

Prepojenie

V hodinách 25–26 sme vytvorili Win32 projekt, okno a nastavili MSVC build. Teraz použijeme ďalšiu skupinu funkcií systému Windows. Ide o čítanie textu z reálnej schránky, nie o webovú simuláciu.

Čo sa deje pri čítaní textu?

1 · OtvorOpenClipboard
2 · Over formátCF_UNICODETEXT
3 · Získaj a skopírujGetClipboardData
4 · Uvoľni prístupGlobalUnlock, CloseClipboard

Windows môže schránku používať naraz len obmedzený počet operácií. Ak ju otvorila iná aplikácia, OpenClipboard môže zlyhať. Po úspešnom otvorení ju vždy zatvor cez CloseClipboard, aj keď sa neskôr nepodarí získať dáta.

Formát je súčasť dát

Schránka neobsahuje iba „text“; dáta sú dostupné v jednom alebo viacerých formátoch. CF_UNICODETEXT označuje nulou ukončený text Unicode. Preto používame varianty API s W a typ wchar_t. Ak formát chýba, napríklad preto, že bola skopírovaná iba bitmapa, textová aplikácia ho nemá načítať ako reťazec.

Kto vlastní pamäť?

GetClipboardData vráti handle na dáta spravované schránkou. Na chvíľu ich sprístupníme cez GlobalLock a obsah skopírujeme do vlastnej premennej std::wstring. Handle zo schránky neuvoľňujeme cez GlobalFree; po použití ho odomkneme a schránku zatvoríme.

Úplný príklad: zobrazenie skopírovaného textu

Skopíruj najprv obyčajný testovací text, napríklad Win32 schránka – žiaci 4. ročníka. Program obsah schránky zobrazí v dialógu. Pri cvičení nepoužívaj heslá ani osobné údaje.

#define UNICODE
#define _UNICODE
#include <windows.h>
#include <string>

int WINAPI wWinMain(HINSTANCE, HINSTANCE, PWSTR, int)
{
    if (!OpenClipboard(nullptr)) {
        MessageBoxW(nullptr, L"Schránku sa nepodarilo otvoriť.",
                    L"Čítanie schránky", MB_OK | MB_ICONWARNING);
        return 1;
    }

    if (!IsClipboardFormatAvailable(CF_UNICODETEXT)) {
        CloseClipboard();
        MessageBoxW(nullptr, L"Schránka neobsahuje text Unicode.",
                    L"Čítanie schránky", MB_OK | MB_ICONINFORMATION);
        return 0;
    }

    HANDLE data = GetClipboardData(CF_UNICODETEXT);
    if (data == nullptr) {
        CloseClipboard();
        MessageBoxW(nullptr, L"Text sa nepodarilo získať.",
                    L"Čítanie schránky", MB_OK | MB_ICONWARNING);
        return 1;
    }

    const wchar_t* lockedText =
        static_cast<const wchar_t*>(GlobalLock(data));
    if (lockedText == nullptr) {
        CloseClipboard();
        MessageBoxW(nullptr, L"Text sa nepodarilo sprístupniť.",
                    L"Čítanie schránky", MB_OK | MB_ICONWARNING);
        return 1;
    }

    // Skopíruj údaje, kým je pamäť zo schránky zamknutá.
    const std::wstring text(lockedText);
    GlobalUnlock(data);
    CloseClipboard();

    MessageBoxW(nullptr, text.c_str(), L"Text zo schránky",
                MB_OK | MB_ICONINFORMATION);
    return 0;
}

Zostavenie a spustenie – MSVC v143

  1. Ulož súbor ako citac_schranky.cpp a otvor Developer Command Prompt for VS 2022.
  2. Zostav: cl /nologo /std:c++17 /EHsc /W4 /DUNICODE /D_UNICODE /Fe:citac_schranky.exe citac_schranky.cpp /link /SUBSYSTEM:WINDOWS user32.lib kernel32.lib
  3. V inej aplikácii označ a skopíruj neškodný testovací text.
  4. Spusti citac_schranky.exe; dialóg zobrazí text alebo vysvetlí, prečo sa nedal načítať.

Závislosti: OpenClipboard, GetClipboardData a MessageBoxW sú z Windows User32, preto linkujeme User32.lib. GlobalLock a GlobalUnlock sú funkcie Kernel32, preto pripájame aj Kernel32.lib. Samostatnú knižnicu GDI tento príklad nepoužíva.

Poznámka k vlastníctvu: OpenClipboard(nullptr) je tu použité iba na čítanie. Pri budúcom zápise je dôležité otvoriť schránku s platným oknom vlastníka pred vyprázdnením a vložením dát.

Typické chyby

  • Zabudnuté CloseClipboard: pri každom úspešnom otvorení musí nasledovať zatvorenie.
  • Nesprávny formát CF_TEXT: starší jednobajtový text nezodpovedá našej Unicode ukážke.
  • Uvoľňovanie cudzej pamäte: handle vrátený zo schránky nepatrí aplikácii; iba ho zamkni, skopíruj text, odomkni a zatvor schránku.
  • Práca s ukazovateľom po zatvorení: najprv skopíruj text do vlastného std::wstring, až potom odomkni.
  • Iná aplikácia práve používa schránku: zobraz zrozumiteľnú správu a skús to znovu neskôr.

Praktická úloha: čítač textu zo schránky

Cieľ: načítať text Unicode z Windows schránky a bezpečne ho zobraziť.

Predpoklady: Windows 10/11, MSVC v143, Windows SDK, VS Code, základné C++ a projekt z hodín 25–26.

  1. Skopíruj neškodný text obsahujúci slovenskú diakritiku.
  2. Ulož a zostav ukážkový program presným príkazom MSVC.
  3. Spusti program a zapíš, či zobrazil text alebo hlásenie o chýbajúcom formáte.
  4. Spusť ho s prázdnou schránkou alebo po skopírovaní obrázka a over ošetrenie situácie.
  5. Na papieri označ, kedy sa schránka otvorí a zatvorí a kedy sa text skopíruje do vlastnej premennej.

Očakávaný výsledok: text zobrazí správne diakritiku; ak textový formát nie je dostupný, program zobrazí vysvetľujúcu správu a skončí.

Kritériá (5 b): správna detekcia formátu (1), úspešné získanie a uzamknutie dát (1), vlastná kópia pred odomknutím (1), zatvorenie schránky vo všetkých vetvách (1), správne zostavenie a vysvetlenie výsledku (1).

  • Základná: spusti ukážku s krátkym obyčajným textom.
  • Rozširujúca: skús text s diakritikou a viacerými riadkami; opíš, ako sa správa dialóg.
  • Náročnejšia: navrhni, ako sa dá text vložiť do vlastného editovacieho poľa bez toho, aby ukazovateľ zo schránky prežil CloseClipboard.

Samostatná výzva: doplň do svojho zápisníka tabuľku troch stavov: schránku neotvorím, formát chýba, text sa úspešne načíta; ku každému napíš reakciu programu.

Zhrnutie: 6 poznatkov

  1. Schránka Windows prenáša údaje medzi aplikáciami vo formátoch.
  2. OpenClipboard môže zlyhať; po každom úspešnom otvorení musí nasledovať CloseClipboard.
  3. IsClipboardFormatAvailable(CF_UNICODETEXT) overí dostupnosť textu Unicode.
  4. GetClipboardData vráti handle spravovaný schránkou, nie pamäť na uvoľnenie našou aplikáciou.
  5. GlobalLock dočasne sprístupní údaje; pred odomknutím ich skopíruj do vlastného reťazca.
  6. Win32 kód zostavujeme na Windows cez MSVC a podľa volaných API linkujeme User32.lib a Kernel32.lib.

Učiteľská časť · odpovede, hodnotenie a podpora

Kontrolné odpovede: CF_UNICODETEXT je formát nulou ukončeného textu Unicode. Po úspešnom otvorení sa schránka musí zatvoriť aj pri chýbajúcom formáte. Handle spravuje schránka; aplikácia ho neuvoľňuje. Obsah treba skopírovať, kým je pamäť sprístupnená cez GlobalLock.

Interaktívna kontrola: správna je A. Uzavretie zdroja je potrebné aj na chybovej vetve.

Hodnotenie: 5 bodov podľa kritérií praktickej úlohy. Zostavenie cez MSVC sa vyžaduje; ak zariadenie blokuje schránku alebo build prostredie, uznaj správnu diagnostiku a trasovanie vetiev.

Podpora: poskytnúť diagram so štyrmi krokmi a nechať žiaka zvýrazniť všetky návraty po úspešnom otvorení. Pri práci s ukazovateľmi vysvetliť najskôr rozdiel medzi handle a adresou dát.

Poznámky a povinné vedomosti, ktoré si zapamätáš z hodiny

  • Text Unicode v schránke zisťujem ako CF_UNICODETEXT.
  • Poradie čítania: otvoriť, overiť formát, získať dáta, zamknúť, skopírovať, odomknúť a zatvoriť.
  • Po úspešnom otvorení schránku zatvorím aj pri chybe alebo chýbajúcom formáte.
  • Handle vrátený z GetClipboardData neuvoľňujem; obsah si skopírujem do vlastného reťazca.
  • Pri testovaní schránky používam iba neškodné údaje.
