Návrh spoločného rozhrania

Dohodni, čo rôzne typy vedia urobiť, a pracuj s nimi jednotne

4. ročník SPŠ · C++ príprava pre Win32

Polymorfizmus je najužitočnejší, keď program potrebuje pracovať s rôznymi typmi cez rovnakú dohodu. Navrhneme spoločné rozhranie „vypíšte sa“ pre objekty, ktoré sa inak líšia: študenta aj knihu.

Rozhranie určuje schopnosť, nie vnútornú podobnosť objektov
Začiatok hodiny: skontrolujte pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívajte. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážete:

  • z požiadavky navrhnúť jednoduchú spoločnú operáciu;
  • vysvetliť abstraktnú triedu a čistú virtuálnu metódu;
  • implementovať spoločné rozhranie vo viacerých nesúvisiacich triedach;
  • použiť referenciu na rozhranie a jednu funkciu pre rôzne typy objektov.

Prepojenie s hodinou 13

Minule sme prekryli virtuálnu metódu v triedach Student a Ucitel. Teraz rozšírime nápad: spoločná operácia nemusí znamenať, že typy patria do tej istej reálnej kategórie. Kniha aj študent môžu podporiť operáciu „vypíšte stručný záznam“.

Rozhranie opisuje, čo používateľ objektu môže požadovať. Každá konkrétna trieda rozhodne, ako operáciu vykoná.

Čistá virtuálna metóda

class Vypisovatelny {
public:
    virtual void vypis() const = 0;
};
  • virtual povoľuje polymorfné volanie.
  • = 0 označuje čistú virtuálnu metódu: základná trieda iba vyžaduje operáciu, jej telo neposkytuje.
  • Trieda s aspoň jednou čistou virtuálnou metódou je abstraktná; nemožno vytvoriť jej priamu inštanciu.
  • Odvodená konkrétna trieda musí metódu implementovať, ak má byť sama vytvoriteľná.

Ukážka v C++17

#include <iostream>
#include <string>

class Vypisovatelny {
public:
    virtual void vypis() const = 0;
};

class Student : public Vypisovatelny {
private:
    std::string meno;
public:
    Student(const std::string& hodnota) : meno(hodnota) {}
    void vypis() const override {
        std::cout << "Student: " << meno << std::endl;
    }
};

class Kniha : public Vypisovatelny {
private:
    std::string nazov;
public:
    Kniha(const std::string& hodnota) : nazov(hodnota) {}
    void vypis() const override {
        std::cout << "Kniha: " << nazov << std::endl;
    }
};

void vypisuj(const Vypisovatelny& polozka) {
    polozka.vypis();
}

int main() {
    Student student("Jana Novakova");
    Kniha kniha("Tajomny ostrov");
    vypisuj(student);
    vypisuj(kniha);
}

Výsledok: funkciu vypisuj napíšeme raz. Zavolá spoločnú operáciu cez referenciu Vypisovatelny&; virtuálne volanie potom spustí implementáciu študenta alebo knihy.

Novinka v zápise: konštruktor inicializuje súkromný text pri vytvorení objektu; dvojbodka a zápis meno(hodnota) sú inicializačný zoznam. V tejto ukážke je to najkratší spôsob, ako vytvoriť objekt s počiatočným názvom. Neskôr sa ku konštruktorom vrátime podrobnejšie.

Zostavenie a spustenie – MSVC

  1. Uložte kód ako rozhranie.cpp.
  2. Otvorte Developer Command Prompt for VS 2022 a prejdite do priečinka súboru.
  3. Zostavte: cl /std:c++17 /EHsc /W4 /Fe:rozhranie.exe rozhranie.cpp.
  4. Spustite rozhranie.exe; očakávaj jeden riadok pre študenta a jeden pre knihu.

Konzolový príklad používa štandardné C++, nie Win32 API, a nepotrebuje samostatné systémové knižnice.

Čo patrí do rozhrania?

  • Operácia, ktorú potrebujú používatelia spoločného typu.
  • Jasný názov a rovnaký význam vo všetkých implementáciách.
  • Čo najmenej detailov o vnútorných dátach konkrétnych tried.

Čomu sa vyhnúť?

  • Nevkladaj do rozhrania nesúvisiace operácie iba preto, že sú triedy v jednej hierarchii.
  • Nevytváraj abstraktnú základnú triedu, ak ju nikto nebude používať polymorfne.
  • Nezamieňaj spoločné rozhranie s rovnakou implementáciou.
  • Objekt abstraktnej triedy vytvoriť nemožno; vytvárajú sa konkrétne odvodené objekty.

Interaktívna kontrola

Čo znamená virtual void vypis() const = 0; v triede Vypisovatelny?

Vyberte odpoveď:

Praktická úloha: spoločný výpis

Cieľ: navrhnúť rozhranie a implementovať ho pre dve odlišné triedy.

Predpoklady: dedičnosť, virtuálne metódy, prekrytie a referencia na základný typ.

  1. Navrhnite abstraktnú triedu Oznamitelny s čistou virtuálnou metódou oznam().
  2. Odvoď triedy Student a Kniha; každá vypíše vlastný stručný text.
  3. Napíšte funkciu, ktorá prijme referenciu const Oznamitelny& a zavolá oznam().
  4. Vytvorte objekty oboch typov a odovzdajte ich tej istej funkcii.
  5. Vysvetlite, prečo obe triedy môžu implementovať rozhranie bez vzťahu „študent je kniha“.

Očakávaný výsledok: jedna funkcia obslúži oba objekty cez spoločnú dohodu.

Kritériá (5 b): čistá virtuálna metóda (1), implementácie (2), spoločná funkcia/ref (1), vysvetlenie účelu rozhrania (1).

  • Základná: doplňte jednu odvodenú triedu a jej implementáciu.
  • Rozširujúca: pridajte tretiu triedu, napríklad oznam o termíne.
  • Náročnejšia: navrhnite, ktoré operácie by tvorili spoločné rozhranie pre rôzne ovládacie prvky v budúcej aplikácii.

Zhrnutie: 6 poznatkov

  1. Rozhranie určuje, akú operáciu objekty sľubujú.
  2. Čistá virtuálna metóda sa zapisuje s = 0.
  3. Trieda s čistou virtuálnou metódou je abstraktná a priamo sa neinštanciuje.
  4. Konkrétne odvodené triedy implementujú požadovanú operáciu cez override.
  5. Funkcia môže prijímať referenciu na rozhranie a pracovať s rôznymi typmi.
  6. Spoločné rozhranie združuje schopnosť, nie nevyhnutne podobné údaje.

Kontrolné otázky

  1. Čo znamená = 0 pri virtuálnej metóde?
  2. Prečo nemožno vytvoriť objekt triedy Vypisovatelny?
  3. Čo musí urobiť konkrétna odvodená trieda?
  4. Ako funkcia vypisuj pracuje s knihou aj študentom?
Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: = 0 označuje čistú virtuálnu metódu bez implementácie v základnej triede; trieda je abstraktná; konkrétna trieda prekryje metódu s rovnakým podpisom; funkcia prijíma referenciu na základný typ a virtuálne volanie zvolí implementáciu konkrétneho objektu.

Interaktívna kontrola: správna je B. Rozlišuj „abstraktnú základnú triedu nemožno vytvoriť“ od „odvodené objekty nemožno vytvoriť“.

Hodnotenie: 5 bodov podľa kritérií. Uznaj aj iný zmysluplný návrh spoločnej operácie, ak má pre obe triedy rovnaký význam.

Podpora: poskytnúť hotový skelet abstraktnej triedy a doplniť iba názov metódy a jednu implementáciu. Konštruktor vysvetli ako počiatočné nastavenie objektu a inicializačný zoznam ako spôsob naplnenia súkromného člena.

Poznámky a povinné vedomosti, ktoré si zapamätáte z hodiny

  • Spoločné rozhranie opisuje operácie, ktoré musí konkrétny typ poskytnúť.
  • Čistá virtuálna metóda má tvar virtual ... = 0;.
  • Abstraktnú triedu priamo neinštanciu­jem; vytváram jej konkrétny odvodený typ.
  • Referenciou na rozhranie môžem jednotne pracovať s rôznymi implementáciami.
