Kopírovanie, vkladanie a formáty schránky

Vlož vlastný Unicode text a bezpečne odovzdaj pamäť systému

4. ročník SPŠ · Natívne Win32 C++ · MSVC v143

Minule sme text zo schránky čítali. Dnes do nej vložíme vlastný text a overíme, že sa dá vložiť do inej aplikácie. Zameriame sa na dôležitý rozdiel: po úspešnom odovzdaní pamäte cez SetClipboardData ju vlastní systém Windows.

platné okno → OpenClipboard → EmptyClipboard → SetClipboardData → CloseClipboard
Začiatok hodiny: skontrolujte pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívajte. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážete:

  • opísať poradie krokov pri zápise textu do schránky;
  • vytvoriť pohyblivý blok pamäte pre formát CF_UNICODETEXT;
  • vysvetliť, kedy smie aplikácia zavolať GlobalFree a kedy vlastníctvo preberá Windows;
  • overiť vloženie skopírovaného textu do inej aplikácie a pomenovať rozdiel medzi textovými formátmi.

Prepojenie s hodinou 27

V hodine 27 sme použili OpenClipboard, GetClipboardData a GlobalLock na prečítanie Unicode textu. Teraz pripravíme vlastný blok pamäte a vložíme ho do schránky, aby ho mohla čítať iná aplikácia.

Zápis textu krok za krokom

1 · Pripravte handle oknaplatný HWND vlastníka
2 · VyprázdniteEmptyClipboard
3 · Vložte formát a dátaSetClipboardData
4 · OdovzdajteCloseClipboard

Pri zapisovaní otvorte schránku s platným handle okna. Po úspešnom OpenClipboard(hwnd) zavolajte EmptyClipboard; tým sa toto okno stane vlastníkom. Až potom pridajte dáta cez SetClipboardData. Pri neúspechu vloženia pamäť uvoľnite Vy; pri úspechu už patrí systému.

Dôležité: nezapisuj do schránky s OpenClipboard(nullptr) a potom nevolaj EmptyClipboard. Bez okna vlastníka môže SetClipboardData zlyhať.

Formát určuje interpretáciu

CF_UNICODETEXT je nulou ukončený text v UTF-16, ktorý bežné moderné aplikácie Windows vedia prijať. Starší CF_TEXT reprezentuje text v jednobajtovej znakovej sade a môže stratiť alebo zmeniť znaky mimo nej. Program môže publikovať viac formátov, od najbohatšieho po jednoduchšie náhradné; dnešný príklad publikuje iba Unicode text.

Prenos vlastníctva

Schránkové dáta sa alokujú cez GlobalAlloc(GMEM_MOVEABLE, ...). Ak SetClipboardData uspeje, systém prevezme handle: aplikácia ho už nesmie meniť ani uvoľňovať. Ak zlyhá, vlastníctvo zostáva aplikácii a musí zavolať GlobalFree. V oboch prípadoch po otvorení zavri schránku.

Úplný príklad: vložte text do schránky

Program vloží krátky testovací text a zobrazí pokyn, aby si ho vyskúšal vložiť do Poznámkového bloku. Ako vlastnícke okno použije skryté štandardné okno triedy STATIC; neskôr túto úlohu prirodzene prevezme hlavné okno aplikácie.

#define UNICODE
#define _UNICODE
#include <windows.h>
#include <cstring>

int WINAPI wWinMain(HINSTANCE instance, HINSTANCE, PWSTR, int)
{
    constexpr wchar_t text[] = L"Win32 API – kopírovanie textu: žltý žeriav";
    const SIZE_T bytes = sizeof(text); // zahŕňa aj nulový znak

    HWND owner = CreateWindowExW(
        0, L"STATIC", L"Vlastník schránky", WS_POPUP,
        0, 0, 0, 0, nullptr, nullptr, instance, nullptr);
    if (owner == nullptr) {
        MessageBoxW(nullptr, L"Nepodarilo sa vytvoriť okno vlastníka.",
                    L"Kopírovanie", MB_OK | MB_ICONERROR);
        return 1;
    }

    if (!OpenClipboard(owner)) {
        DestroyWindow(owner);
        MessageBoxW(nullptr, L"Schránka sa používa. Skús to znova.",
                    L"Kopírovanie", MB_OK | MB_ICONWARNING);
        return 1;
    }

    if (!EmptyClipboard()) {
        CloseClipboard();
        DestroyWindow(owner);
        MessageBoxW(nullptr, L"Schránku sa nepodarilo pripraviť.",
                    L"Kopírovanie", MB_OK | MB_ICONERROR);
        return 1;
    }

    HGLOBAL memory = GlobalAlloc(GMEM_MOVEABLE, bytes);
    if (memory == nullptr) {
        CloseClipboard();
        DestroyWindow(owner);
        MessageBoxW(nullptr, L"Nepodarilo sa alokovať pamäť.",
                    L"Kopírovanie", MB_OK | MB_ICONERROR);
        return 1;
    }

    void* locked = GlobalLock(memory);
    if (locked == nullptr) {
        GlobalFree(memory); // SetClipboardData ešte neprevzal handle
        CloseClipboard();
        DestroyWindow(owner);
        MessageBoxW(nullptr, L"Pamäť sa nepodarilo sprístupniť.",
                    L"Kopírovanie", MB_OK | MB_ICONERROR);
        return 1;
    }
    std::memcpy(locked, text, bytes);
    GlobalUnlock(memory);

    HANDLE result = SetClipboardData(CF_UNICODETEXT, memory);
    if (result == nullptr) {
        GlobalFree(memory); // pri chybe ostáva vlastníkom naša aplikácia
        CloseClipboard();
        DestroyWindow(owner);
        MessageBoxW(nullptr, L"Text sa nepodarilo vložiť do schránky.",
                    L"Kopírovanie", MB_OK | MB_ICONERROR);
        return 1;
    }

    // Úspech: memory teraz spravuje Windows; neuvoľňujeme ho.
    CloseClipboard();
    DestroyWindow(owner);
    MessageBoxW(nullptr, L"Text je skopírovaný. Vlož ho do Poznámkového bloku (Ctrl+V).",
                L"Kopírovanie", MB_OK | MB_ICONINFORMATION);
    return 0;
}

Zostavenie a spustenie – MSVC v143

  1. Uložte kód ako zapis_do_schranky.cpp a otvorte Developer Command Prompt for VS 2022.
  2. Zostavte: cl /nologo /std:c++17 /EHsc /W4 /DUNICODE /D_UNICODE /Fe:zapis_do_schranky.exe zapis_do_schranky.cpp /link /SUBSYSTEM:WINDOWS user32.lib kernel32.lib
  3. Spustite EXE. Po hlásení otvorte Poznámkový blok alebo iné textové pole a stlačte Ctrl+V.
  4. Overte, že sa vloží celý text vrátane diakritiky.

Závislosti: schránka a dialógy používajú User32.lib; pamäťové funkcie GlobalAlloc, GlobalLock, GlobalFree používajú Kernel32.lib. Nepoužívame GDI.

Štandardné ovládacie prvky a vloženie

Natívne editovacie ovládacie prvky Windows už podporujú bežné príkazy kopírovať, vystrihnúť a vložiť cez klávesové skratky a príkazy editácie. Spracovanie vlastného WM_PASTE alebo tlačidiel formulára bude užitočné neskôr, keď sa naučíme vytvárať ovládacie prvky. Dnes kontrolujeme výsledok vložením do inej aplikácie.

Čo sa stane pri chybe?

  • Pred SetClipboardData zlyhá alokácia: zavri schránku; neexistuje handle na uvoľnenie.
  • GlobalLock zlyhá: uvoľnite vlastný blok pomocou GlobalFree.
  • SetClipboardData zlyhá: handle zostal náš, preto ho uvoľnite.
  • SetClipboardData uspeje: Windows prevezme handle a neskôr ho uvoľní.

Predpoklady: Windows 10/11, MSVC v143, Windows SDK, VS Code a hodina 27.

  1. Zostavte program príkazom MSVC z tejto lekcie.
  2. Spustite ho, prečítajte hlásenie a vložte text do Poznámkového bloku.
  3. Overte slová s diakritikou a interpunkciou.
  4. V kóde vyznač vetvu úspechu a vetvu zlyhania SetClipboardData; v každej urč, kto vlastní pamäť.
  5. Zapíšte, čo sa stane so starým obsahom schránky po úspešnom EmptyClipboard.

Očakávaný výsledok: text sa vloží nezmenený; po úspešnom odovzdaní aplikácia neuvoľní pamäť handle.

Kritériá (5 b): build funguje (1), text sa vloží do inej aplikácie (1), diakritika je správna (1), žiak vysvetlí úspešnú zmenu vlastníka pamäte (1), rozlíši chybovú vetvu a uvoľnenie (1).

  • Základná: zostavte a vyskúšajte daný text.
  • Rozširujúca: zmeňte konštantu na vlastný bezpečný text a overte jeho vloženie.
  • Náročnejšia: načrtni, ako by aplikácia mohla poskytovať aj textový náhradný formát pre staršiu aplikáciu; vysvetlite, prečo by bolo treba správne skonvertovať obsah.

Samostatná výzva: doplňte postupnú kontrolnú tabuľku: vytvorenie vlastníka, otvorenie, vyprázdnenie, alokácia, uzamknutie, zápis nulového zakončenia, odomknutie, odovzdanie handle, zatvorenie.

Zhrnutie: 7 poznatkov

  1. Pri zápise treba schránku otvoriť s platným oknom vlastníka.
  2. EmptyClipboard odstráni predchádzajúci obsah a priradí vlastníctvo schránky danému oknu.
  3. Text pre CF_UNICODETEXT musí obsahovať aj ukončovací nulový znak.
  4. Blok pre SetClipboardData alokujem cez GlobalAlloc(GMEM_MOVEABLE, ...).
  5. Ak vloženie zlyhá, aplikácia stále vlastní handle a uvoľní ho cez GlobalFree.
  6. Po úspechu preberá handle systém; aplikácia ho už neuvoľňuje.
  7. Vloženie otestujem v inej aplikácii a overím správnosť diakritiky.

Učiteľská časť · odpovede, hodnotenie a podpora

Kontrolné odpovede: okno je potrebné na získanie vlastníctva pri EmptyClipboard; po úspechu SetClipboardData vlastní handle systém; aplikácia uvoľňuje pamäť iba vtedy, ak sa jej nepodarilo odovzdať handle; nulový znak ukončuje textový reťazec, ktorý iná aplikácia číta.

Interaktívna kontrola: správna je B. Po úspešnom volaní vlastníctvo prechádza na Windows a aplikácia nesmie blok uvoľniť ani meniť.

Hodnotenie: 5 bodov podľa kritérií úlohy. Nehodnoť bezpečné správanie aplikácie pri chybe ako zlyhanie žiaka; vyžaduj však, aby vedel odlíšiť vlastníctvo pred a po odovzdaní.

Podpora: použi dva farebné stĺpce „vlastní program“ a „vlastní Windows“. Žiak presúva handle do druhého stĺpca až po úspešnom SetClipboardData.

Poznámky a povinné vedomosti, ktoré si zapamätáte z hodiny

  • Pri zápise otvorím schránku s platným oknom vlastníka, vyprázdnim ju a vložím formát.
  • Text CF_UNICODETEXT je nulou ukončený Unicode reťazec.
  • Použijem pohyblivú pamäť cez GlobalAlloc(GMEM_MOVEABLE, ...).
  • Po úspechu SetClipboardData vlastní pamäť Windows; po neúspechu ju uvoľním ja.
  • Schránku zatvorím po skončení práce a vloženie overím v inej aplikácii.
