Súborový vstup a výstup

Ulož textové údaje do súboru a načítaj ich späť

4. ročník SPŠ · C++ príprava pre Win32

Premenné v pamäti zaniknú po skončení programu. Ak majú údaje zostať zachované, môžeme ich zapísať do súboru. V C++ na textové súbory použijeme streamy z hlavičky <fstream>.

Otvoriť → skontrolovať → čítať alebo zapisovať → zavrieť
Začiatok hodiny: skontrolujte pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívajte. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážete:

  • rozlíšiť úlohu tried std::ofstream a std::ifstream;
  • otvoriť textový súbor na zápis a čítanie a skontrolovať úspech;
  • zapísať a načítať údaje po riadkoch;
  • vysvetliť, kde program hľadá relatívnu cestu a čo znamená prepísanie súboru.

Prepojenie s hodinou 21

Pri konzolovej komunikácii sme používali streamy cin a cout. Streamy súborov sa používajú podobne, no ich dáta prichádzajú zo súboru alebo sa doň ukladajú.

Typický postup

1 · Otvortev režime čítania/zápisu
2 · Skontrolujteči stream funguje
3 · Prenes dátariadky alebo hodnoty
4 · Ukončistream sa bezpečne zavrie

Pri bežnom lokálnom súbore sa stream po opustení svojho rozsahu automaticky zavrie. Pri chybe otvorenia treba oznámiť problém, nie predstierať úspešný zápis.

Zápis: std::ofstream

#include <fstream>

std::ofstream vystup("data.txt");
if (!vystup) {
    // súbor sa nepodarilo otvoriť
}
vystup << "Prvy riadok" << std::endl;

Predvolené otvorenie na zápis vytvorí súbor alebo prepíše jeho existujúci obsah. Ak chceme pripisovať na koniec, použijeme režim std::ios::app.

Čítanie: std::ifstream

#include <fstream>
#include <string>

std::ifstream vstup("data.txt");
std::string riadok;
while (std::getline(vstup, riadok)) {
    // spracuj načítaný riadok
}

Podmienka slučky je úspešná, kým sa riadok načíta. Po otvorení overte, že súbor existuje a je čitateľný.

Úplná ukážka: zápis a následné čítanie

#include <fstream>
#include <iostream>
#include <string>

int main() {
    {
        std::ofstream vystup("student.txt");
        if (!vystup) {
            std::cerr << "Nepodarilo sa otvorit subor na zapis." << std::endl;
            return 1;
        }
        vystup << "101" << std::endl;
        vystup << "Jana Novakova" << std::endl;
        vystup << "IV.A" << std::endl;
        if (!vystup) {
            std::cerr << "Zapis do suboru zlyhal." << std::endl;
            return 1;
        }
    } // vystupny stream sa zavrie pred citanim

    std::ifstream vstup("student.txt");
    if (!vstup) {
        std::cerr << "Nepodarilo sa otvorit subor na citanie." << std::endl;
        return 1;
    }

    std::string id;
    std::string meno;
    std::string trieda;
    if (!std::getline(vstup, id) ||
        !std::getline(vstup, meno) ||
        !std::getline(vstup, trieda)) {
        std::cerr << "Subor nema ocakavany format." << std::endl;
        return 1;
    }

    std::cout << "Nacitany zaznam: " << id << " - "
              << meno << " (" << trieda << ")" << std::endl;
}

Výsledok: program vytvorí student.txt v pracovnom priečinku programu, zapíše tri riadky, otvorí ho na čítanie a vypíše načítaný záznam. ID je zatiaľ text; parsovanie číselných polí môžeme doplniť neskôr.

Formát súboru: jednoduchá textová dohoda – prvý riadok ID, druhý meno, tretí trieda. Pri viacerých záznamoch by sme potrebovali jasný oddeľovač alebo štruktúrovanejší formát.

Zostavenie a spustenie – MSVC

  1. Uložte kód ako subory.cpp.
  2. Otvorte Developer Command Prompt for VS 2022 a prejdite do priečinka, kde chcete vytvoriť student.txt.
  3. Zostavte: cl /std:c++17 /EHsc /W4 /Fe:subory.exe subory.cpp.
  4. Spustite subory.exe a pozrite si vytvorený textový súbor v tom istom pracovnom priečinku.

Je to konzolový príklad štandardného C++, nie Win32 API. Nepotrebuje Windows SDK ani samostatné systémové knižnice.

Relatívna cesta

Cesta student.txt je relatívna k aktuálnemu pracovnému priečinku procesu. V IDE to nemusí byť vždy priečinok, v ktorom leží zdrojový kód. Ak súbor neviete nájsť, overte nastavený pracovný priečinok.

Čítanie riadkov a stav streamu

  • Skontrolujte stream hneď po otvorení.
  • Kontroluj aj zápis, ak je dôležité vedieť, či sa údaje uložili.
  • getline zachová medzery v mene a načíta jeden riadok.
  • Počet a poradie riadkov sú súčasťou formátu, ktorý program očakáva.

Interaktívna kontrola

Čo sa pri predvolenom std::ofstream("student.txt") stane, ak súbor už existuje?

Vyberte odpoveď:

Praktická úloha: uloženie krátkeho záznamu

Cieľ: uložiť jednoduché údaje do textového súboru a načítať ich späť.

Predpoklady: std::string, streamy konzoly, podmienky a getline.

  1. Zapíšte ID, celé meno a triedu študenta do súboru ziak.txt, každý údaj na samostatný riadok.
  2. Skontrolujte úspešné otvorenie aj výsledok zápisu.
  3. Otvorte súbor pomocou std::ifstream a načítaj tri riadky.
  4. Vypíšte údaje na konzolu a overte ich porovnaním so zdrojovým záznamom.
  5. Vyskúšajte spustiť program z iného pracovného priečinka a vysvetlite, kam sa súbor vytvorí.

Očakávaný výsledok: údaje sa uložia a načítajú späť; pri chýbajúcom súbore program zobrazí chybu.

Kritériá (5 b): správny zápis (1), kontrola otvorenia/zápisu (1), čítanie troch riadkov (1), zhodný výpis (1), vysvetlenie cesty (1).

  • Základná: doplňte zápis a čítanie jedného textového riadka.
  • Rozširujúca: pridajte druhý záznam a použite režim std::ios::app, aby sa pripísal na koniec.
  • Náročnejšia: navrhnite formát pre viac záznamov a pravidlo, ako rozoznať koniec jedného záznamu.

Podpora: pracuj krok po kroku s jedným riadkom. Nech žiak najprv overí, že súbor existuje po zápise, až potom doplní čítanie a ďalšie polia.

Poznámky a povinné vedomosti, ktoré si zapamätáte z hodiny

  • ofstream slúži na zápis; ifstream na čítanie.
  • Vždy overím, či sa súbor podarilo otvoriť a či operácia prebehla úspešne.
  • Predvolený zápis prepíše súbor; režim ios::app pripisuje na koniec.
  • Relatívna cesta sa počíta od pracovného priečinka programu.
