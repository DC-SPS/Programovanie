Orientácia v prostredí a hlavné menu

Spoznaj pracovnú plochu VS Code a úlohu jednotlivých vývojových nástrojov

4. ročník SPŠ · C++ · Windows 10/11

Visual Studio Code je editor a pracovné prostredie. Samotný editor však nie je kompilátor. Pri natívnom Win32 C++ projekte použijeme aj MSVC a Windows SDK. Dnes si zmapujeme, kde sú súbory, editor, terminál a pomocné nástroje.

Editor ≠ kompilátor ≠ Windows SDK
Začiatok hodiny: skontroluj pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívaj. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážeš:

  • otvoriť projektový priečinok a nájsť súbor v Exploreri;
  • pomenovať hlavné oblasti používateľského rozhrania VS Code;
  • vysvetliť rozdiel medzi editorom, kompilátorom a Windows SDK;
  • určiť, ktorý terminál alebo prostredie treba použiť pri MSVC.

Upresnenie názvu hodiny

„Hlavné menu“ v tejto hodine znamená orientáciu v menu a pracovnom prostredí Visual Studio Code. Nejde o menu Win32 aplikácie, ktoré neskôr vytvoríme ako súčasť používateľského rozhrania.

  • Menu ponúka skupiny príkazov, napríklad File a View.
  • Activity Bar prepína pohľady, napríklad Explorer, Search a Extensions.
  • Explorer zobrazuje súbory a priečinky otvoreného workspace.
  • Editor je hlavná plocha na úpravu súborov.
  • Panel môže zobrazovať terminál, výstup alebo chyby.
  • Status Bar zobrazuje stavové informácie o otvorenom súbore a prostredí.

Tri časti vývojového prostredia

  • VS Code: otvára a upravuje zdrojové súbory; ponúka terminál a pohľady na projekt.
  • MSVC: kompilátor a linker, ktoré preložia a zostavia C++ program.
  • Windows SDK: hlavičky a knižnice potrebné na volanie Windows API.

VS Code môže koordinovať zostavenie, no príslušný kompilátor a SDK musia byť nainštalované a správne dostupné.

Terminál a MSVC

Integrovaný terminál VS Code je príkazový riadok otvorený v pracovnom priečinku. Jeho otvorenie samo osebe nezaručí, že MSVC nájde kompilátor, hlavičky a knižnice.

Na tomto kurze použijeme Developer Command Prompt/Developer PowerShell alebo nakonfigurovaný VS Code task, ktorý zdedí pripravené prostredie MSVC. Bežný PowerShell nemusí mať potrebné cesty nastavené.

Orientácia v otvorenom projekte

  1. V menu vyber File → Open Folder… a otvor priečinok projektu, nie iba jeden zdrojový súbor.
  2. V Exploreri rozbaľ priečinky a nájdi súbor s príponou .cpp.
  3. Otvor ho v Editore a pozri sa na kartu súboru a stavový riadok.
  4. Otvor integrovaný terminál cez menu Terminal → New Terminal alebo skratkou Ctrl+`; všimni si jeho aktuálny priečinok.
  5. Pomocou Command Palette (Ctrl+Shift+P) vyhľadaj príkaz View: Toggle Terminal alebo Preferences: Open Settings, ale nastavenia projektu nemeň bez pokynu.

Workspace je priečinok alebo skupina priečinkov otvorená vo VS Code. Pracuj v správnom workspace, aby si vedel/a, kde sú zdroje aj vytvorené výstupy.

Rozloženie a dostupné položky sa môžu mierne líšiť podľa verzie a rozšírení. Ak nevieš nájsť príkaz, vyhľadaj ho cez Command Palette.

Interaktívna kontrola

Otvoril/a si VS Code v bežnom PowerShelli, ale príkaz cl nie je rozpoznaný. Ktorý záver je najvhodnejší?

Vyber odpoveď:

Praktická úloha: nájdi jednotlivé časti

Cieľ: zorientovať sa v otvorenom kurze a určiť, kam patrí každý pracovný krok.

Predpoklady: počítač s VS Code; na túto úlohu netreba zostavovať C++ program.

  1. Otvori kurzový priečinok 04_Win32_API vo VS Code cez File → Open Folder.
  2. V Exploreri nájdi struktura.html a priečinok lekcie.
  3. Otvor jednu lekciu a ukáž editor, kartu súboru a stavový riadok.
  4. Otvor integrovaný terminál a nájdi aktuálny pracovný priečinok.
  5. Ukáž, kde by si hľadal/a nastavenia alebo príkaz, ktorý nevieš nájsť.
  6. Na papier alebo do poznámok priraď úlohy: úprava zdroja, výber súboru, zobrazenie chyby, kompilácia.

Očakávaný výsledok: žiak nájde súbor aj priečinok, rozpozná kľúčové oblasti VS Code a vysvetlí, že kompilátor je samostatný nástroj.

Kritériá (5 b): otvorený správny priečinok (1), nájdené súbory (1), pomenované oblasti (1), vysvetlený terminál (1), rozlíšený VS Code/MSVC/SDK (1).

  • Základná: podľa učiteľských pokynov otvor Explorer a konkrétny súbor.
  • Rozširujúca: otvor Command Palette a nájdi príkaz na zobrazenie terminálu.
  • Náročnejšia: vysvetli, ako zlá voľba workspace alebo pracovného priečinka môže viesť k nenájdeniu súboru či výstupnej aplikácie.

Zhrnutie: 6 poznatkov

  1. VS Code je editor a pracovné prostredie, nie kompilátor C++.
  2. Explorer zobrazuje obsah otvoreného workspace.
  3. Editor slúži na čítanie a úpravu súborov; Panel môže obsahovať terminál a výstup.
  4. Command Palette pomáha nájsť príkazy podľa názvu.
  5. MSVC kompiluje a linkuje; Windows SDK poskytuje podporu Windows API.
  6. Na zostavenie MSVC potrebuje pripravené vývojové prostredie, nie iba ľubovoľný terminál.

Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: VS Code upravuje a organizuje projekt, ale zostavenie vykonáva kompilátor; Explorer zobrazuje súbory, Editor upravuje obsah; SDK poskytuje Windows hlavičky a knižnice; príkaz cl nemusí byť na PATH a premenné pre hlavičky/linker nemusia byť pripravené.

Interaktívna kontrola: správna je B. Nech žiak rozlíši chýbajúce nastavenie prostredia od chyby zdrojového kódu.

Hodnotenie: 5 bodov podľa praktických kritérií. Úloha nevyžaduje vlastnú konfiguráciu buildu; tá bude obsahom ďalšej hodiny.

Podpora: používaj veľké označené snímky alebo priamo premietnuté okno VS Code. Nechaj žiaka vykonať jeden krok naraz a pomenuj oblasti farbou na pracovnom liste.

Poznámky a povinné vedomosti, ktoré si zapamätáš z hodiny

  • VS Code je editor; MSVC je kompilátor/linker; Windows SDK poskytuje rozhrania Windows.
  • Projekt otvorím ako priečinok/workspace a súbory hľadám v Exploreri.
  • Terminál je príkazový riadok otvorený v pracovnom priečinku.
  • Pre MSVC použijem pripravené MSVC prostredie alebo nakonfigurovaný task.

Nadväznosť: hodina 24 sa venuje nastaveniam, zostaveniu a spusteniu programu v pripravenom prostredí.
