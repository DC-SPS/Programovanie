Rozdelenie programu na funkcie

Každá funkcia má pomenovanú úlohu a program ich skladá do celku

4. ročník SPŠ · C++ príprava pre Win32

Program býva ľahšie čitateľný, keď každá časť rieši jednu zrozumiteľnú úlohu. Funkcie umožňujú dať týmto častiam mená, odovzdať im potrebné údaje a vrátiť výsledky. Hlavná funkcia potom ukazuje celkový postup.

Rozdeľ úlohu → pomenuj kroky → spoj ich v main
Začiatok hodiny: skontroluj pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívaj. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážeš:

  • rozdeliť jednoduchý problém na menšie pomenované činnosti;
  • navrhnúť funkcie s jasnou zodpovednosťou;
  • prepojiť prototypy, definície, parametre a návratové hodnoty;
  • vysvetliť, ako rozdelenie na funkcie zlepšuje čitateľnosť a opätovné použitie.

Prepojenie s hodinou 17

Už vieme napísať prototyp a odovzdať funkcii argumenty. Teraz namiesto jednej dlhej časti vytvoríme niekoľko menších funkcií, ktoré spolu vyriešia celú úlohu.

Príklad: vyhodnotenie bodov

Program má overiť, či je počet získaných bodov platný, vypočítať percentá a zobraziť výsledok. Každá činnosť sa stane samostatnou funkciou.

Ukážka v C++17

#include <iostream>

bool platnyPocet(int body, int maximum);
double percenta(int body, int maximum);
void vypisVysledok(double hodnota);

int main() {
    int body{42};
    int maximum{50};

    if (platnyPocet(body, maximum)) {
        double vysledok = percenta(body, maximum);
        vypisVysledok(vysledok);
    } else {
        std::cout << "Neplatny pocet bodov" << std::endl;
    }
}

bool platnyPocet(int body, int maximum) {
    return body >= 0 && body <= maximum;
}

double percenta(int body, int maximum) {
    return 100.0 * body / maximum;
}

void vypisVysledok(double hodnota) {
    std::cout << "Vysledok: " << hodnota << "%" << std::endl;
}

Hlavná funkcia koordinuje: main nastaví údaje, zavolá validáciu, podľa výsledku rozhodne a odovzdá výpočet funkcii na výpis. Detail každej činnosti je oddelený.

Dôležitá poznámka: vo funkcii percenta sa používa 100.0, aby výpočet prebiehal s desatinným typom a neprebiehalo celočíselné delenie. Funkciu voláme iba po overení, že maximum je kladné v tomto zadaní (50).

Zostavenie a spustenie – MSVC

  1. Ulož kód ako rozdelenie.cpp.
  2. Otvor Developer Command Prompt for VS 2022 a prejdi do priečinka súboru.
  3. Zostav: cl /std:c++17 /EHsc /W4 /Fe:rozdelenie.exe rozdelenie.cpp.
  4. Spusti rozdelenie.exe; očakávaj percentuálny výsledok 84 %.

Konzolový príklad používa štandardné C++, nie Win32 API, a nepotrebuje samostatné systémové knižnice.

Dobrá funkcia má jasnú úlohu

  • Názov napovie, čo funkcia robí.
  • Parametre sú údaje, ktoré potrebuje na prácu.
  • Návratový typ vyjadruje, aký výsledok poskytne.
  • Funkcia má byť dostatočne malá, aby sa dala pochopiť samostatne.

Vyhni sa zbytočnému deleniu

  • Nevytváraj funkciu pre každý jednotlivý riadok bez dôvodu.
  • Vyhni sa nejasným menám ako spracuj1.
  • Neopakuj tú istú logiku na viacerých miestach; zváž jednu spoločnú funkciu.
  • Drž hlavnú funkciu ako prehľad krokov, nie ako celý detail riešenia.

Interaktívna kontrola

Program má opakovane kontrolovať, či vstupné body ležia medzi 0 a maximom. Ktorá funkcia má najjasnejšiu zodpovednosť?

Vyber odpoveď:

Praktická úloha: výsledok testu

Cieľ: rozdeliť vyhodnotenie testu na aspoň tri jasne pomenované funkcie.

Predpoklady: parametre, návratové hodnoty, prototypy, podmienka a výpis.

  1. Naplánuj funkciu na kontrolu rozsahu bodov.
  2. Naplánuj funkciu na výpočet percent.
  3. Naplánuj funkciu na zobrazenie výsledku.
  4. V main zavolaj kroky v správnom poradí.
  5. Pre neplatný vstup zobraz chybové hlásenie a výpočet nevykonaj.

Očakávaný výsledok: program je rozdelený na funkcie s čitateľnými názvami a predvídateľným tokom údajov.

Kritériá (5 b): rozdelenie na úlohy (1), prototypy (1), vhodné parametre/návraty (1), koordinácia v main (1), ošetrenie neplatných údajov (1).

  • Základná: doplň definície podľa pripravených prototypov.
  • Rozširujúca: pridaj funkciu, ktorá podľa percent určí slovné hodnotenie.
  • Náročnejšia: uprav návrh tak, aby funkcia na výpočet vedela bezpečne reagovať aj na nulové maximum.

Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: funkcie pomenúvajú čiastkové úlohy, znižujú opakovanie a zlepšujú čitateľnosť; hlavička obsahuje návratový typ, názov a parametre; main koordinuje validáciu, výpočet a výpis; validácia zabraňuje vykonaniu výpočtu s neplatnými údajmi.

Interaktívna kontrola: správna je A, pretože názov, návratový typ a parametre jasne vyjadrujú zodpovednosť.

Hodnotenie: 5 bodov podľa kritérií úlohy. Prijmi odlišné rozdelenie, ak každá funkcia má jasnú úlohu a vstupné hodnoty sú bezpečne ošetrené.

Podpora: použi kartičky „over“, „vypočítaj“, „vypíš“; ku každej doplň parameter a návratový typ. Začni hotovými prototypmi a nechaj žiaka dopísať volania v main.

Poznámky a povinné vedomosti, ktoré si zapamätáš z hodiny

  • Program delím na funkcie podľa samostatných činností.
  • Dobrá funkcia má jasný názov a zodpovednosť.
  • Funkcie prijímajú parametre a môžu vracať výsledok.
  • Hlavná funkcia môže koordinovať celkový postup.
