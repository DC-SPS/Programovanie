Zapuzdrenie dát a rozhranie triedy

Chráň stav objektu a povoľ zmeny cez jasne určené operácie

4. ročník SPŠ · C++ príprava pre Win32

Doteraz sme k atribútom pristupovali priamo. Pri väčšom programe však nechceme, aby každý kus kódu mohol nastaviť ľubovoľnú hodnotu. Zapuzdrenie skryje vnútorné údaje a poskytne verejné metódy, ktoré kontrolujú povolené zmeny.

Vnútorné údaje súkromné · operácie jasne verejné
Začiatok hodiny: skontrolujte pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívajte. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážete:

  • vysvetliť rozdiel medzi verejnou a súkromnou časťou triedy;
  • určiť, prečo sa atribút nemá vždy meniť priamym priradením;
  • navrhnúť verejné metódy, ktoré chránia jednoduchú podmienku objektu;
  • vysvetliť, ako používateľ triedy pracuje cez jej verejné rozhranie.

Motivácia: platný záznam

Ak je ID študenta kladné a meno nesmie byť prázdne, priama zmena ľubovoľným miestom programu môže vytvoriť chybný záznam. Trieda môže chrániť tieto pravidlá tým, že skryje atribúty a skontroluje hodnoty pri zmene.

Nadväznosť: v hodine 10 sme videli, že obsluha udalosti môže zavolať metódu. Teraz vytvoríme rozhranie, ktorým sa taká obsluha bezpečne opiera o objekt.

Verejná a súkromná časť

private – vnútro objektuČleny sú prístupné priamo iba metódam triedy (a jej priateľom, ktoré dnes neriešime). Vonkajší kód ich nemôže svojvoľne meniť.
public – rozhranieČleny sú dostupné používateľovi triedy. Verejné metódy ponúkajú operácie, ktoré trieda povoľuje.

V C++ členy triedy sú predvolene súkromné. Po návestí public: sú verejné, kým sa nepridá iné návestie prístupu.

Ukážka: kontrolovaný objekt Student

#include <iostream>
#include <string>

class Student {
private:
    int id{};
    std::string meno;

public:
    bool nastavId(int noveId) {
        if (noveId <= 0) {
            return false;
        }
        id = noveId;
        return true;
    }

    bool nastavMeno(const std::string& noveMeno) {
        if (noveMeno.empty()) {
            return false;
        }
        meno = noveMeno;
        return true;
    }

    void vypis() const {
        std::cout << id << " - " << meno << '\n';
    }
};

int main() {
    Student student{};
    student.nastavId(101);
    student.nastavMeno("Jana Novakova");
    student.vypis();

    if (!student.nastavId(-5)) {
        std::cout << "Neplatne ID\n";
    }
}

Čo chráni trieda? Vonkajší kód nemôže napísať student.id = -5;, pretože id je súkromné. Musí zavolať nastavId, ktoré záporné číslo odmietne a ponechá doterajšiu hodnotu. Návratová hodnota true/false oznamuje, či sa zmena podarila.

Rozhranie tvoria verejné metódy nastavId, nastavMeno a vypis. Volajúci vie, čo môže od objektu požadovať, bez priamej manipulácie s jeho vnútornými dátami.

Zostavenie a spustenie – MSVC

  1. Uložte kód ako student_private.cpp.
  2. Otvorte Developer Command Prompt for VS 2022 a prejdite do priečinka súboru.
  3. Zostavte: cl /std:c++17 /EHsc /W4 /Fe:student_private.exe student_private.cpp.
  4. Spustite student_private.exe; očakávaj platný záznam a hlásenie o odmietnutom ID.

Ide o konzolový príklad štandardného C++, nie Win32 program. Nepotrebuje Windows API ani ďalšie systémové knižnice.

Prečo nenechať všetko verejné?

  • Verejné atribúty umožňujú porušiť pravidlá platného stavu.
  • Pri súkromných údajoch trieda kontroluje zmenu na jednom mieste.
  • Vnútornú reprezentáciu možno neskôr upraviť bez zmeny spôsobu používania.
  • Verejné rozhranie má byť malé a zrozumiteľné.

Pravidlo pre návrh

Skry to, čo má zostať pod kontrolou triedy. Sprístupni iba operácie, ktoré používateľ triedy potrebuje. Nepridávaj gettery a settery automaticky pre každý atribút; najprv sa pýtaj, akú bezpečnú operáciu objekt vyžaduje.

Interaktívna kontrola

Vyberte odpoveď:

Praktická úloha: platný záznam knihy

Cieľ: zapuzdriť atribúty knihy a umožniť iba platné zmeny.

Predpoklady: trieda, metódy, podmienka if a návratová hodnota bool.

  1. Vytvorte triedu Kniha so súkromnými atribútmi nazov a pocetStran.
  2. Verejnou metódou povoľ zmenu názvu iba vtedy, ak text nie je prázdny.
  3. Verejnou metódou povoľ počet strán iba vtedy, ak je kladný.
  4. Pridajte metódu na výpis stavu a vyskúšajte platné aj neplatné hodnoty.

Očakávaný výsledok: objekt odmietne prázdny názov a nekladný počet strán a zachová posledné platné hodnoty.

Kritériá (5 b): súkromné atribúty (1), verejné operácie (1), správna validácia (2), vysvetlenie rozhrania (1).

  • Základná: doplňte podmienku pre kladný počet strán.
  • Rozširujúca: vráťte výsledok zmeny ako bool a vypíšte potvrdenie alebo chybu.
  • Náročnejšia: navrhnite verejné metódy bez priameho setteru a zdôvodnite, ako udržia platný stav.

Zhrnutie: 6 poznatkov

  1. Zapuzdrenie skrýva vnútorný stav a sprístupňuje kontrolované operácie.
  2. private člen je priamo dostupný len v triede.
  3. public člen tvorí časť rozhrania pre používateľa triedy.
  4. Verejná metóda môže skontrolovať hodnotu pred zmenou atribútu.
  5. Neplatná požiadavka môže byť odmietnutá bez poškodenia stavu.
  6. Verejné rozhranie má obsahovať potrebné operácie, nie automaticky každý setter.

Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: private nie je priamo dostupné zvonka triedy, public áno; validácia chráni invariant kladného ID; bool oznamuje úspech alebo odmietnutie zmeny; setter netreba, ak používateľ nemá mať voľnú možnosť meniť údaj alebo existuje zmysluplnejšia operácia.

Interaktívna kontrola: správna je B. Priamy prístup vyvolá chybu kompilácie; použijeme verejnú metódu.

Hodnotenie: 5 bodov podľa kritérií zadania. Za vhodnú validáciu považuj správne odmietnutie bez prepísania predchádzajúcej hodnoty.

Podpora: zvýrazni deklarácie pod private: a public: rôznymi farbami. Daj žiakovi doplniť jednu podmienku do pripraveného setteru skôr, než navrhne celú triedu.

Poznámky a povinné vedomosti, ktoré si zapamätáte z hodiny

  • private chráni vnútorné členy pred priamym prístupom zvonka triedy.
  • public tvorí rozhranie, cez ktoré objekt používame.
  • Verejná metóda môže kontrolovať hodnotu pred zmenou stavu.
  • Neplatnú zmenu odmietnem tak, aby objekt zachoval platný stav.
