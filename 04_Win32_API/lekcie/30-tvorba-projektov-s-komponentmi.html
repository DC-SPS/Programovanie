Prepojenie komponentov s logikou aplikácie

Od kliknutia na tlačidlo cez WM_COMMAND až po spracovanie vstupu

4. ročník SPŠ · Natívne Win32 C++ · MSVC v143

Na hodine 29 sme navrhli formulár z rodičovského okna, popisu, textového poľa a tlačidla. Teraz jeho prvky vytvoríme a prepojíme s logikou: rodič rozpozná oznámenie tlačidla, prečíta meno z poľa a zobrazí odpoveď.

BUTTON → WM_COMMAND → ID + BN_CLICKED → GetDlgItem → GetWindowTextW
Začiatok hodiny: skontroluj pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívaj. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážeš:

  • vytvoriť hlavné okno s podradeným prvkom EDIT a BUTTON;
  • priradiť ovládacím prvkom jedinečné ID;
  • rozpoznať správu WM_COMMAND podľa ID a kódu BN_CLICKED;
  • získať handle prvku a bezpečne prečítať jeho text do premennej C++.

Prepojenie v kurze

Hodina 29 bola o skladbe komponentov. Dnes preskúmame ich spoluprácu v udalostne riadenej aplikácii. V nasledujúcich hodinách sa podrobnejšie zameriame na okno a formulár; tento príklad je malý model toku od ovládacieho prvku po logiku.

Tok udalosti

1 · Vstupžiak zadá meno
2 · Udalosťklikne tlačidlo
3 · OznámenieWM_COMMAND
4 · RozpoznanieID + BN_CLICKED
5 · Logikaprečíta a reaguje

Ovládací prvok pošle oznámenie rodičovskému oknu. V správe WM_COMMAND obsahuje nízky word wParam ID prvku, vysoký word oznamovací kód a lParam handle ovládacieho prvku. Pri tlačidle kontrolujeme obe hodnoty; samotné ID by nestačilo na rozlíšenie rôznych oznamovacích správ.

Oddelíme vrstvy

  • Win32 rozhranie: CreateWindowExW vytvorí editovacie pole a tlačidlo; GetDlgItem nájde pole podľa ID.
  • Udalosť: WindowProc rozpozná WM_COMMAND, ID tlačidla a BN_CLICKED.
  • C++ logika: text sa uloží do lokálneho buffera; tu môže aplikácia overiť, či je meno prázdne, a vytvoriť odpoveď.
  • Výstup: MessageBoxW zobrazí výsledok. Neskôr môžeme aktualizovať ovládací prvok alebo aplikačný model.

Prečo sú ID dôležité?

Viaceré ovládacie prvky posielajú oznámenia tej istej procedúre rodiča. ID je ich stabilný identifikátor v rámci rodičovského okna. Každému prvku, ktorý bude logika rozlišovať, priraď jedinečné ID; handle získaj cez GetDlgItem alebo použi lParam oznámenia.

Nie každý WM_COMMAND vznikol kliknutím na tlačidlo. Preto overuj identifikátor a kód BN_CLICKED.

Úplný príklad: pozdrav z textového poľa

#define UNICODE
#define _UNICODE
#include <windows.h>
#include <vector>
#include <string>
#include <cstddef>

constexpr wchar_t CLASS_NAME[] = L"FormularSKomponentmi";
constexpr int ID_EDIT_MENO = 1001;
constexpr int ID_BUTTON_POZDRAV = 1002;

LRESULT CALLBACK WindowProc(HWND hwnd, UINT message,
                            WPARAM wParam, LPARAM lParam)
{
    switch (message) {
    case WM_CREATE: {
        const auto* create = reinterpret_cast<LPCREATESTRUCTW>(lParam);
        HINSTANCE instance = create->hInstance;

        CreateWindowExW(0, L"STATIC", L"Meno:",
            WS_CHILD | WS_VISIBLE,
            20, 22, 70, 24, hwnd, nullptr, instance, nullptr);

        HWND edit = CreateWindowExW(WS_EX_CLIENTEDGE, L"EDIT", L"",
            WS_CHILD | WS_VISIBLE | WS_TABSTOP | ES_AUTOHSCROLL,
            95, 18, 230, 28, hwnd,
            reinterpret_cast<HMENU>(static_cast<INT_PTR>(ID_EDIT_MENO)),
            instance, nullptr);

        HWND button = CreateWindowExW(0, L"BUTTON", L"Pozdraviť",
            WS_CHILD | WS_VISIBLE | WS_TABSTOP | BS_PUSHBUTTON,
            95, 58, 120, 32, hwnd,
            reinterpret_cast<HMENU>(static_cast<INT_PTR>(ID_BUTTON_POZDRAV)),
            instance, nullptr);

        if (edit == nullptr || button == nullptr) return -1;
        return 0;
    }

    case WM_COMMAND:
        if (LOWORD(wParam) == ID_BUTTON_POZDRAV &&
            HIWORD(wParam) == BN_CLICKED) {
            HWND edit = GetDlgItem(hwnd, ID_EDIT_MENO);
            if (edit == nullptr) {
                MessageBoxW(hwnd, L"Textové pole sa nenašlo.",
                    L"Chyba", MB_OK | MB_ICONERROR);
                return 0;
            }

            int length = GetWindowTextLengthW(edit);
            if (length == 0) {
                MessageBoxW(hwnd, L"Najprv zadaj meno.",
                    L"Chýba vstup", MB_OK | MB_ICONINFORMATION);
                return 0;
            }

            std::vector<wchar_t> name(static_cast<std::size_t>(length) + 1);
            int copied = GetWindowTextW(edit, name.data(),
                                        static_cast<int>(name.size()));
            if (copied == 0) {
                MessageBoxW(hwnd, L"Meno sa nepodarilo prečítať.",
                    L"Chyba čítania", MB_OK | MB_ICONWARNING);
                return 0;
            }

            std::wstring greeting = L"Ahoj, ";
            greeting.append(name.data(), static_cast<std::size_t>(copied));
            greeting += L"!";
            MessageBoxW(hwnd, greeting.c_str(), L"Pozdrav",
                        MB_OK | MB_ICONINFORMATION);
            return 0;
        }
        break;

    case WM_DESTROY:
        PostQuitMessage(0);
        return 0;
    }
    return DefWindowProcW(hwnd, message, wParam, lParam);
}

int WINAPI wWinMain(HINSTANCE instance, HINSTANCE, PWSTR, int show)
{
    WNDCLASSEXW wc{};
    wc.cbSize = sizeof(wc);
    wc.lpfnWndProc = WindowProc;
    wc.hInstance = instance;
    wc.hCursor = LoadCursorW(nullptr, IDC_ARROW);
    wc.hbrBackground = GetSysColorBrush(COLOR_WINDOW);
    wc.lpszClassName = CLASS_NAME;
    if (!RegisterClassExW(&wc)) return 1;

    HWND hwnd = CreateWindowExW(0, CLASS_NAME, L"Pozdrav z formulára",
        WS_OVERLAPPEDWINDOW, CW_USEDEFAULT, CW_USEDEFAULT, 380, 170,
        nullptr, nullptr, instance, nullptr);
    if (hwnd == nullptr) return 1;

    ShowWindow(hwnd, show);
    UpdateWindow(hwnd);
    MSG msg{};
    BOOL result;
    while ((result = GetMessageW(&msg, nullptr, 0, 0)) > 0) {
        TranslateMessage(&msg);
        DispatchMessageW(&msg);
    }
    return result == -1 ? 1 : static_cast<int>(msg.wParam);
}

Zostavenie a spustenie – MSVC v143

  1. Ulož ako formular_udalosti.cpp a otvori Developer Command Prompt for VS 2022 s Windows SDK.
  2. Zostav: cl /nologo /std:c++17 /EHsc /W4 /DUNICODE /D_UNICODE /Fe:formular_udalosti.exe formular_udalosti.cpp /link /SUBSYSTEM:WINDOWS user32.lib
  3. Spusti formular_udalosti.exe, zadaj meno a klikni na tlačidlo; skús tiež kliknutie s prázdnym vstupom.

Závislosť: funkcie okna, ovládacích prvkov, textu a správ poskytuje User32.lib. Vektor a reťazec sú súčasťou štandardnej knižnice C++; ďalšiu systémovú knižnicu nepotrebujeme.

Typické chyby

  • Rodič nemá WS_CHILD alebo handle hlavného okna: prvok sa nevytvorí ako dieťa.
  • ID tlačidla sa nezhoduje s kontrolou v WM_COMMAND: kliknutie sa ignoruje.
  • Kontroluješ iba LOWORD(wParam): rovnaká hodnota môže označovať inú notifikáciu.
  • Text čítaš do príliš malého buffera: použi GetWindowTextLengthW a rezervuj ešte znak pre terminátor.
  • Vrátiš hodnotu z WindowProc pre správu, ktorú nespracúvaš: ostatné správy odovzdaj DefWindowProcW.

Zhrnutie: 6 poznatkov

  1. Ovládacie prvky sú podradené okná hlavného formulára.
  2. Každý prvok, ktorý rozlišujeme, dostane jedinečné ID.
  3. Rodič dostáva oznámenia tlačidiel cez WM_COMMAND.
  4. LOWORD(wParam) obsahuje ID a HIWORD(wParam) kód oznámenia.
  5. GetDlgItem nájde dieťa podľa ID; GetWindowTextLengthW a GetWindowTextW načítajú jeho text.
  6. Neznáme správy odovzdávam DefWindowProcW.

Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: ID označuje konkrétny prvok; BN_CLICKED označuje typ jeho oznámenia. GetDlgItem vráti HWND dieťaťa. Dĺžka umožní alokovať buffer s miestom navyše na nulový terminátor. Ostatné správy delegujeme cez DefWindowProcW.

Interaktívna kontrola: správna je A. Pri tlačidle kontrolujeme zdroj (ID) aj oznamovací kód.

Hodnotenie: 5 bodov podľa praktických kritérií. Pri nefunkčnom školskom toolchaine uznaj presnú diagnostiku, ale kódové kroky musí žiak vedieť vysvetliť.

Podpora: pre žiakov, ktorí potrebujú pomoc, zvýrazni na tabuli tri hodnoty v správe: ID v LOWORD, kód v HIWORD a HWND v lParam. Daj im tabuľku s hodnotami a nech vyznačia, ktorý riadok spustí pozdrav.

Poznámky a povinné vedomosti, ktoré si zapamätať z hodiny

  • Kliknutie tlačidla oznámi podradený prvok rodičovi cez WM_COMMAND.
  • LOWORD(wParam) obsahuje ID prvku a HIWORD(wParam) jeho oznamovací kód, napríklad BN_CLICKED.
  • Handle ovládacieho prvku získam cez GetDlgItem a text cez GetWindowTextW.
  • Buffer pre text musí mať miesto aj na nulový ukončovací znak.
  • Správy, ktoré aplikácia nespracuje, odovzdám DefWindowProcW.
