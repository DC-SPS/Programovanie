Konzolový vstup a výstup

Čítaj údaje od používateľa a zobraz výsledky pomocou C++ streamov

4. ročník SPŠ · C++ príprava pre Win32

Konzolový program komunikuje s používateľom prostredníctvom vstupu a výstupu. Streamy std::cin, std::cout a std::cerr umožňujú načítať hodnoty, zobraziť výsledok a oznámiť chybu.

Vyzvi používateľa → načítaj → overte → zobraz
Začiatok hodiny: skontrolujte pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívajte. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážete:

  • rozlíšiť úlohu std::cin, std::cout a std::cerr;
  • načítať číselnú hodnotu a celý textový riadok;
  • ošetriť neúspešné načítanie čísla;
  • vysvetliť rozdiel medzi operator>> a std::getline.

Nadväznosť

Už vieme používať funkcie, štruktúry a typy. Vstup používateľa naplní premenné; výstup pomôže ukázať výsledok. Na hodine 22 sa pozrieme na prácu so súbormi.

Tri streamy pre konzolu

std::cinštandardný vstup
std::coutbežný výstup
std::cerrchybové hlásenia
Operátory>> číta · << vypisuje

Vkladací operátor << posiela hodnoty do výstupného streamu. Vyťažovací operátor >> načítava hodnotu zo vstupu a zvyčajne preskočí úvodné medzery.

Načítanie podľa typu

int pocet{};
std::cin >> pocet;

Pri číselnom vstupe sa text prevedie na zodpovedajúci typ. Ak používateľ zadá neplatné dáta, stream prejde do chybového stavu. Kontroluj výsledok načítania.

Celý textový riadok

std::string meno;
std::getline(std::cin, meno);

getline načíta celý riadok vrátane vnútorných medzier. Použite ho pre mená alebo názvy, ktoré môžu obsahovať viac slov.

Ukážka: načítanie bodov a mena

#include <iostream>
#include <string>

int main() {
    int body{};
    std::string meno;

    std::cout << "Zadaj pocet bodov: ";
    if (!(std::cin >> body)) {
        std::cerr << "Chyba: zadaj cele cislo." << std::endl;
        return 1;
    }

    std::cout << "Zadaj cele meno: ";
    std::getline(std::cin >> std::ws, meno);

    std::cout << "Zaznam: " << meno
              << ", bodov " << body << std::endl;
}

Prečo používame std::ws? Po načítaní čísla cez >> zostane vo vstupnom buffri znak nového riadka. std::ws pred getline odstráni úvodné biele znaky, aby sa meno nenačítalo ako prázdny zvyšok riadka. Toto je vhodné, ak vedúce medzery v mene nepotrebujeme zachovať.

Overenie vstupu: podmienka if (!(std::cin >> body)) zachytí vstup, ktorý sa nedá načítať ako celé číslo. Program vypíše chybu na std::cerr a skončí s nenulovým návratovým kódom.

Zostavenie a spustenie – MSVC

  1. Uložte kód ako konzola.cpp.
  2. Otvorte Developer Command Prompt for VS 2022 a prejdite do priečinka súboru.
  3. Zostavte: cl /std:c++17 /EHsc /W4 /Fe:konzola.exe konzola.cpp.
  4. Spustite konzola.exe, zadajte napríklad 42 a potom Jana Novakova.

Konzolový príklad používa štandardné C++, nie Win32 API. Nepotrebuje Windows SDK ani samostatné systémové knižnice.

Tipy na čitateľný výstup

  • Najprv vysvetlite, čo používateľ má zadať.
  • Pridajte jednotky alebo význam pri číselnom výsledku.
  • Používajte std::endl alebo znak nového riadka na oddelenie riadkov.
  • Chyby oddeľ cez std::cerr, bežný výsledok vypisuj cez std::cout.

Časté chyby

  • Použitie >> pre celé meno: načíta iba prvé slovo.
  • Predpoklad, že sa číslo vždy načíta úspešne.
  • Volanie getline hneď po >> bez ošetrenia zvyšného riadka.
  • Výpis chybového hlásenia ako keby išlo o bežný výsledok.

Predpoklady: premenné, int, std::string, podmienka a výpis.

  1. Načítaj celé číslo ako ID a skontrolujte, či sa čítanie podarilo.
  2. Načítaj meno aj s medzerami.
  3. Vypíšte údaje vo formáte „ID: … | Meno: …“.

  • Rozširujúca: načítaj aj počet bodov a skontrolujte, že je v rozsahu 0 až 100.
  • Náročnejšia: navrhnite, ako umožniť opakovať vstup po chybe; na túto hodinu stačí pseudokód.

Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: getline používame pre celý riadok alebo text s medzerami; cerr je štandardný chybový výstup; neúspešný stav znamená, že čítanie sa nepodarilo alebo narazilo na problém; po operátore >> ostal znak nového riadka, ktorý môže getline okamžite spotrebovať.

Interaktívna kontrola: správna je B; getline načíta celý riadok vrátane medzier.

Hodnotenie: 5 bodov podľa kritérií úlohy. Oceň správne ošetrenie chyby a zrozumiteľný prompt.

Podpora: predveď vstup „Jana Nováková“ cez oba spôsoby. Na tabuľu zakresli, čo zo vstupného riadka spotrebuje >> a čo zostane pre getline.

Poznámky a povinné vedomosti, ktoré si zapamätáte z hodiny

  • std::cin načítava, std::cout vypisuje a std::cerr oznamuje chyby.
  • >> číta hodnoty podľa typu; getline načíta celý textový riadok.
  • Kontrolujem, či vstupné operácie prebehli úspešne.
  • Po číselnom vstupe ošetrím zvyšný riadok pred použitím getline.
