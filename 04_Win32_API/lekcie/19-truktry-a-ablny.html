Štruktúry a používateľské dátové typy

Spoj súvisiace hodnoty do jedného zmysluplného záznamu

4. ročník SPŠ · C++ príprava pre Win32

Samostatné premenné mena, ID a triedy môžu patriť k jednej osobe, no ľahko ich omylom pomiešame. Štruktúra definuje nový používateľský dátový typ, ktorý tieto súvisiace hodnoty zoskupí do jedného celku.

Jeden záznam = jeden objekt so súvisiacimi členmi
Začiatok hodiny: skontroluj pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívaj. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážeš:

  • vysvetliť účel kľúčového slova struct;
  • definovať vlastnú štruktúru s vhodne typovanými členmi;
  • vytvoriť a inicializovať dve inštancie a pristupovať k členom cez bodku;
  • rozlíšiť použitie štruktúry na zoskupenie údajov od triedy s riadeným rozhraním.

Prepojenie s predchádzajúcimi témami

Vytvárali sme triedy a objekty pre model študenta. Štruktúra tiež definuje používateľský typ. V C++ sú členy struct predvolene verejné; pri class sú predvolene súkromné. Dnes sa sústredíme na jednoduché záznamy údajov.

Od samostatných premenných k jednému záznamu

TypStudent
Členyid · meno · trieda
Inštanciakonkrétny študent

Členy majú vopred určené názvy a typy. Inštancia každej štruktúry uchováva vlastné hodnoty.

Ukážka v C++17

#include <iostream>
#include <string>

struct Student {
    int id{};
    std::string meno;
    std::string trieda;
};

int main() {
    Student studentA{101, "Jana Novakova", "IV.A"};
    Student studentB{102, "Peter Kral", "IV.B"};

    std::cout << studentA.id << " - " << studentA.meno
              << " (" << studentA.trieda << ")" << std::endl;
    std::cout << studentB.id << " - " << studentB.meno
              << " (" << studentB.trieda << ")" << std::endl;

    studentA.trieda = "IV.B"; // mení sa iba studentA
}

Čítanie definície: struct Student { ... }; vytvorí nový typ. Každý člen má svoj typ. Zložené zátvorky v Student studentA{...} inicializujú členy v poradí, v akom sú definované.

Prístup k členom: bodka vyberá člen konkrétnej premennej. Priradenie studentA.trieda = "IV.B"; nemení inštanciu studentB.

Zostavenie a spustenie – MSVC

  1. Ulož kód ako student_struct.cpp.
  2. Otvor Developer Command Prompt for VS 2022 a prejdi do priečinka súboru.
  3. Zostav: cl /std:c++17 /EHsc /W4 /Fe:student_struct.exe student_struct.cpp.
  4. Spusti student_struct.exe; očakávaj dva riadky s rôznymi záznamami.

Ide o konzolový príklad štandardného C++, nie Win32 aplikáciu. Nepotrebuje Windows API ani samostatné systémové knižnice.

Kedy štruktúru použiť?

  • Keď viac hodnôt opisuje jeden záznam alebo vec.
  • Keď chceš údaje odovzdať funkcii ako jeden celok.
  • Keď každý objekt potrebuje rovnaké pomenované členy.
  • Keď model potrebuje byť jednoduchý a priamo čitateľný.

struct a class

  • Obe definujú používateľský typ a môžu obsahovať členy aj metódy.
  • V struct sú členy predvolene verejné.
  • V class sú členy predvolene súkromné.
  • Vyber podľa zámeru: jednoduchý záznam alebo typ s dôrazom na riadené rozhranie.

Zhrnutie: 6 poznatkov

  1. struct definuje používateľský zložený dátový typ.
  2. Jeho členy združujú súvisiace údaje jedného záznamu.
  3. Každá inštancia uchováva vlastné hodnoty.
  4. Člen premennej vyberáme bodkou, napríklad studentA.meno.
  5. Hodnoty možno inicializovať v poradí definovaných členov.

Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: nový používateľský dátový typ; členy spolu opisujú jeden záznam a znižujú riziko pomýlenia hodnôt; bodka vyberá člena konkrétnej inštancie; v struct sú členy predvolene public a v class private.

Interaktívna kontrola: správna je A. Nech žiak ukáže, ktorá časť výrazu pomenúva objekt a ktorá jeho člen.

Hodnotenie: 5 bodov podľa kritérií úlohy. Uznaj iné vhodné členy, ak zodpovedajú evidencii knihy a majú primeraný typ.

Podpora: daj žiakovi najprv kartičky hodnôt, ktoré treba zoskupiť, potom kostru struct s doplnenými typmi. Prácu s poľami a ukazovateľmi nechaj na neskoršie témy.

Poznámky a povinné vedomosti, ktoré si zapamätáš z hodiny

  • struct definuje vlastný dátový typ, ktorý spája súvisiace členy.
  • Každá inštancia štruktúry má vlastné hodnoty.
  • K členu inštancie pristupujem operátorom bodky.
  • Členy struct sú predvolene verejné; členy class predvolene súkromné.
