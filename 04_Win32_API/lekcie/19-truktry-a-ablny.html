Štruktúry v C++ a Win32 API

Spojíme súvisiace údaje do vlastného typu a pozrieme sa, ako ich rovnakým spôsobom odovzdáva Windows.

Začíname kontrolou pracoviska: Po príchode do učebne si skontroluj svoje miesto, lavicu, stoličku a pridelený počítač s príslušenstvom. Každé poškodenie, chýbajúcu časť alebo inú závadu ihneď oznám vyučujúcemu. Stručný súhrn zistených nedostatkov pošli vyučujúcemu správou cez EduPage. Poškodené alebo nebezpečné zariadenie nepoužívaj.

Ciele hodiny

Po hodine dokážeš vysvetliť účel struct, vytvoriť vlastnú štruktúru, pracovať s jej členmi pomocou . a ->, vytvoriť pole záznamov a rozpoznať, ako Win32 API používa štruktúry na výmenu údajov s Windows.

1. Prečo potrebujeme štruktúry?

Pri evidencii žiaka patria meno, vek, trieda a priemer k jednej osobe. Samostatné premenné sa dajú ľahko pomýliť a pri viacerých žiakoch sa program rýchlo stane neprehľadným. Štruktúra vytvorí nový dátový typ, ktorého členy spolu opisujú jeden záznam.

#include <iostream>
#include <string>

struct Ziak {
    std::string meno;
    int vek;
    std::string trieda;
    double priemer;
};

int main() {
    Ziak ziak{"Jana Nováková", 17, "3.A", 1.8};
    std::cout << ziak.meno << " – " << ziak.trieda
              << ", priemer " << ziak.priemer << '\n';
}
structDefinuje používateľský zložený dátový typ.
ZiakNázov nového typu, podľa ktorého vytvárame záznamy.
ziak.menoBodkou vyberieme konkrétny člen premennej.

2. Pole štruktúr a porovnanie s Pythonom

Ak potrebujeme viac záznamov, môžeme použiť pole alebo kontajner. Nasledujúca ukážka používa pole pevnej veľkosti, ktoré už poznáš:

Ziak ziaci[] = {
    {"Peter", 17, "3.A", 1.8},
    {"Jana", 18, "4.B", 1.4},
    {"Martin", 17, "3.A", 2.1}
};

for (const Ziak& ziak : ziaci) {
    std::cout << ziak.meno << " (" << ziak.trieda << ")\n";
}

3. Ukazovateľ na štruktúru

Ak máme adresu štruktúry, cez ukazovateľ pristupujeme k jej členom operátorom ->. Tento zápis je skratkou pre dereferenciu a bodku.

Ziak ziak{"Peter", 17, "3.A", 1.8};
Ziak* ukazatel = &ziak;

std::cout << ukazatel->meno << '\n';
// Ekvivalentný zápis:
std::cout << (*ukazatel).meno << '\n';
ziak – údaje v pamäti← adresa →ukazatel – ukazuje na ziak

4. Kde štruktúry používa Win32 API?

Win32 API je rozhranie, cez ktoré program komunikuje s operačným systémom Windows. Funkcie API prijímajú a vracajú skupiny súvisiacich údajov v štruktúrach.

ŠtruktúraČo opisuje
POINTSúradnice bodu x a y.
RECTHranice obdĺžnika: left, top, right, bottom.
WNDCLASSEXWVlastnosti triedy okna a funkciu, ktorá obsluhuje správy.
MSGJednu správu z frontu udalostí Windows.
PAINTSTRUCTÚdaje potrebné pri vykresľovaní obsahu okna.

Inicializácia okna: vlastná štruktúra aj štruktúra Windows

Štruktúru inicializujeme na nuly, nastavíme jej veľkosť a vyplníme hodnoty, ktoré Windows potrebuje. Funkcia CreateWindowExW potom dostane parametre na vytvorenie konkrétneho okna.

WNDCLASSEXW triedaOkna{};
triedaOkna.cbSize = sizeof(triedaOkna);
triedaOkna.lpfnWndProc = WindowProc;
triedaOkna.hInstance = hInstance;
triedaOkna.hCursor = LoadCursorW(nullptr, IDC_ARROW);
triedaOkna.hbrBackground = reinterpret_cast<HBRUSH>(
    static_cast<INT_PTR>(COLOR_WINDOW + 1));
triedaOkna.lpszClassName = L"MojeOkno";

if (!RegisterClassExW(&triedaOkna)) {
    return 1;
}

HWND okno = CreateWindowExW(
    0, triedaOkna.lpszClassName, L"Moja aplikácia",
    WS_OVERLAPPEDWINDOW, CW_USEDEFAULT, CW_USEDEFAULT,
    640, 400, nullptr, nullptr, hInstance, nullptr);

WNDCLASSEXW opisuje druh okna, zatiaľ čo HWND je identifikátor vytvoreného okna. Štruktúry Win32 API nie sú dekorácia: sú dohodnutým formátom údajov medzi aplikáciou a systémom.

Správy a vykresľovanie

Windows oznamuje udalosti správami. Premenná MSG uchováva jednu správu; pri správe WM_PAINT použijeme štruktúru PAINTSTRUCT.

MSG sprava{};
BOOL vysledok;
while ((vysledok = GetMessageW(&sprava, nullptr, 0, 0)) > 0) {
    TranslateMessage(&sprava);
    DispatchMessageW(&sprava);
}
if (vysledok == -1) {
    // Nastala chyba pri čítaní frontu správ.
}

// Vo funkcii WindowProc:
case WM_PAINT: {
    PAINTSTRUCT vykreslenie{};
    HDC kontext = BeginPaint(okno, &vykreslenie);
    const wchar_t text[] = L"Ahoj z Win32 API";
    TextOutW(kontext, 20, 20, text, lstrlenW(text));
    EndPaint(okno, &vykreslenie);
    return 0;
}
Windows vytvorí správu→MSG→front správ→WindowProc→reakcia programu

Praktické úlohy

A · Evidencia žiakov · základná

Vytvor struct Ziak s menom, vekom, triedou a priemerom. Vytvor aspoň tri záznamy, vypíš ich cyklom a nájdi najlepší priemer.

Očakávaný výsledok: údaje každého žiaka zostanú v jednom zázname; program správne vypíše všetky mená a vyberie najnižší priemer.

B · Geometria · stredná

Vytvor štruktúru Obdlznik s rozmermi a funkcie na výpočet obvodu a obsahu. Vypočítaj výsledky pre tri rôzne obdĺžniky.

Očakávaný výsledok: funkcie dostávajú štruktúru alebo jej konštantný odkaz a vracajú správne číselné hodnoty.

C · Win32 súradnice · rozšírená

Vytvor dva body typu POINT a vypočítaj rozdiel ich súradníc. Vysvetli, prečo ide o typ poskytnutý Windows a ako sa k členom pristupuje.

Očakávaný výsledok: súradnice sú nastavené a čítané cez .; žiak vysvetlí členy x a y.

Zhrnutie

struct spája pomenované členy do jedného používateľského typu. K členom premennej pristupujeme cez bodku, k členom ukazovateľa cez šípku. Win32 API používa vlastné štruktúry ako WNDCLASSEXW, MSG a PAINTSTRUCT na výmenu údajov medzi aplikáciou a Windows.
