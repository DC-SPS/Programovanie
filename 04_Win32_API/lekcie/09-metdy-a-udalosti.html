Metódy a spracovanie udalostí

Operácie objektu a reakcia programu na to, čo sa stane

4. ročník SPŠ · C++ príprava pre Win32

Objekt uchováva svoj stav a metóda predstavuje operáciu, ktorú nad týmto stavom vykonáme. Používateľské rozhranie zasa vytvára udalosti, napríklad kliknutie. Dnes spojíme tieto myšlienky na malom modeli študenta a rozlíšime obyčajné volanie metódy od skutočného spracovania udalosti v GUI.

Metóda = operácia objektu · udalosť = oznámenie, že sa niečo stalo
Začiatok hodiny: skontrolujte pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívajte. Stručný súhrn pošli cez EduPage podľa pokynov.

Na konci hodiny dokážete:

  • rozlíšiť metódu od samostatnej funkcie;

  • vytvoriť a zavolať jednoduchú metódu, ktorá zmení stav objektu.

Prepojenie s minulou hodinou

V hodine 8 sme menili atribúty viacerých študentov priamym priradením. Metóda nám umožní pomenovať operáciu, ktorá patrí k objektu a môže používať alebo meniť jeho stav.

Od kliknutia k zmene stavu

1 · Udalosťpoužívateľ klikne
2 · Reakciaprogram rozpozná akciu
3 · Metódazavolá operáciu objektu
4 · Nový stavúdaje sa aktualizujú

V skutočnom GUI operačný systém a framework doručujú programu udalosti. Program rozhodne, čo s nimi urobiť. V dnešnom konzolovom príklade iba priamo zavoláme metódu; tento riadok simulujúci akciu ešte nie je udalosť Windows.

Metóda a funkcia

  • Samostatná funkcia sa volá menom, napríklad vypisStudenta(...).
  • Metóda je deklarovaná v triede a voláme ju cez objekt, napríklad student.zmenTriedu(...).
  • Metóda môže pracovať s atribútmi konkrétnej inštancie.
  • Metóda môže stav meniť alebo ho iba čítať a vypísať.

Udalosť a obsluha

  • Udalosť je oznámenie o akcii alebo zmene, napríklad kliknutie či stlačenie klávesu.
  • Obsluha udalosti je kód, ktorý program vykoná pri tejto udalosti.
  • Obsluha môže zavolať metódu objektu, aktualizovať údaje a vyžiadať nové zobrazenie.
  • Metóda sama osebe udalosť nevytvára; sú to súvisiace, ale odlišné pojmy.

Ukážka v C++17

#include <iostream>
#include <string>

class Student {
public:
    std::string meno;
    std::string trieda;

    void zmenTriedu(const std::string& novaTrieda) {
        trieda = novaTrieda;
    }

    void vypis() const {
        std::cout << meno << " - " << trieda << '\n';
    }
};

int main() {
    Student student{};
    student.meno = "Jana Novakova";
    student.trieda = "IV.A";

    student.vypis();
    // Simulované rozhodnutie programu po používateľskej akcii:
    student.zmenTriedu("IV.B");
    student.vypis();
}

Výstup: najprv Jana v IV.A, potom Jana v IV.B. Metóda zmenTriedu dostane nový text a zmení atribút objektu, na ktorom bola zavolaná. vypis() const iba číta stav, preto je označená ako nemeníca objekt.

Dôležité rozlíšenie: komentár o používateľskej akcii iba vysvetľuje budúce zapojenie. V tomto príklade metódu volá priamo main; žiadne tlačidlo ani Win32 udalosť tu ešte nie sú.

Zostavenie a spustenie – MSVC

  1. Uložte kód ako metody.cpp.
  2. Otvorte Developer Command Prompt for VS 2022 a prejdite do priečinka súboru.
  3. Zostavte: cl /std:c++17 /EHsc /W4 /Fe:metody.exe metody.cpp.
  4. Spustite: metody.exe a porovnajte riadky pred a po zmene triedy.

Je to konzolový príklad štandardného C++, nie Win32 program. Nepotrebuje Windows API ani samostatné systémové knižnice.

Interaktívna kontrola

V GUI používateľ klikne na tlačidlo „Zmeniť triedu“. Ktoré tvrdenie správne odlišuje udalosť od metódy?

Vyberte odpoveď:

Praktická úloha: metóda na zmenu stavu

Cieľ: vytvoriť metódu, ktorá aktualizuje jeden objekt, a navrhnúť udalosť, ktorá by ju v GUI vyvolala.

Predpoklady: trieda, atribúty a viacero objektov.

  1. Vytvorte triedu Kniha s atribútmi názov a dostupnosť.
  2. Pridajte metódu nastavDostupnost(bool dostupna).
  3. Vytvorte dve knihy; zmeňte dostupnosť iba prvej cez metódu a vypíšte obe.
  4. Navrhnite text tlačidla, ktorého kliknutie by túto metódu mohlo vyvolať.
  5. Vysvetlite rozdiel medzi kliknutím, obsluhou kliknutia a metódou knihy.

Očakávaný výsledok: metóda zmení len volanú inštanciu; žiak správne označí udalosť a jej možnú reakciu.

Kritériá (5 b): správne atribúty (1), metóda s parametrom (1), správna zmena stavu (1), samostatnosť druhej inštancie (1), rozlíšenie udalosti a metódy (1).

  • Základná: doplňte telo metódy podľa ukážky.
  • Rozširujúca: pridajte metódu na vypísanie stavu bez jeho zmeny.
  • Náročnejšia: rozpíšte pseudokód obsluhy kliknutia od prijatia udalosti až po zobrazenie aktualizovaných údajov.

Zhrnutie: 6 poznatkov

  1. Metóda je operácia deklarovaná v triede a volaná cez objekt.
  2. Metóda môže čítať alebo meniť stav konkrétnej inštancie.
  3. Udalosť oznamuje, že nastala akcia alebo zmena.
  4. Obsluha udalosti je kód, ktorý na ňu reaguje.
  5. Obsluha môže zavolať metódu; metóda a udalosť nie sú to isté.
  6. Dnešná konzolová ukážka metódu volá priamo a nespracúva udalosť Windows.

Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: napríklad student.vypis(); udalosť je oznámenie o akcii, napríklad kliknutí; obsluha môže zavolať metódu a aktualizovať stav; priame volanie z main nie je udalosť, pretože ho vykoná program priamo.

Interaktívna kontrola: správna je B. Zdôrazni sled: používateľská akcia → udalosť → obsluha → prípadné volanie metódy.

Hodnotenie: 5 bodov podľa kritérií praktickej úlohy. V tejto hodine sa nevyžaduje skutočná implementácia GUI udalosti.

Podpora: daj žiakom kartičky „kliknutie“, „obsluha“, „metóda“, „zmena hodnoty“ a nech ich zoradia. Pri kóde farebne odlíš metódu triedy od riadku, ktorý ju volá.

Poznámky a povinné vedomosti, ktoré si zapamätáte z hodiny

  • Metóda je operácia triedy volaná cez konkrétny objekt.
  • Metóda môže meniť stav objektu.
  • Udalosť oznamuje akciu; jej obsluha rozhodne, čo program vykoná.
  • Obsluha udalosti môže zavolať metódu, ale udalosť a metóda sú odlišné pojmy.
