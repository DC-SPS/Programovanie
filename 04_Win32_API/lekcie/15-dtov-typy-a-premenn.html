Premenné, konštanty a základné typy

Vyber typ, ktorý zodpovedá údajom, a označ hodnoty, ktoré sa nemajú meniť

4. ročník SPŠ · C++ príprava pre Win32

Program pracuje s rôznymi údajmi: menom, počtom záznamov, priemerom či stavom aktivity. Dátový typ určuje, akú hodnotu premenná uchováva a aké operácie s ňou dávajú zmysel. Konštanta vyjadruje, že hodnota sa po inicializácii nemá meniť.

Premenná = pomenovaná hodnota · typ = pravidlá pre hodnotu
Začiatok hodiny: skontroluj pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívaj. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážeš:

  • vysvetliť, čo je premenná a akú úlohu má dátový typ;
  • vybrať vhodný základný typ pre celé číslo, reálne číslo, znak, pravdivostnú hodnotu a text;
  • deklarovať, inicializovať a zmeniť premennú v C++;
  • použiť const pre hodnotu, ktorá sa po inicializácii nemá meniť.

Prepojenie s objektmi

V triede Student sme používali int pre ID a std::string pre meno. Dobrý model závisí od toho, či jednotlivé typy zodpovedajú významu údajov.

Rozsahy a presnosť typov budeme rozoberať ďalej. Zatiaľ sa sústreď na význam a správny výber typu.

Deklarácia, inicializácia a zmena hodnoty

int pocet;          // deklarácia: premenná vznikne
pocet = 24;         // priradenie: dostane hodnotu
int rocnik{4};      // deklarácia a inicializácia
rocnik = 3;         // platná zmena premennej
const int hodin = 45; // konštanta: hodnotu už nemeníme
  • Deklarácia oznamuje názov a typ premennej.
  • Inicializácia jej dáva počiatočnú hodnotu pri vytvorení.
  • Priradenie nastaví alebo zmení hodnotu existujúcej premennej.
  • Konštanta musí dostať hodnotu pri vytvorení a po nej ju program nesmie zmeniť.

Preferuj inicializáciu hneď pri deklarácii. Nezačínaj s neznámou hodnotou, ak ju môžeš nastaviť okamžite.

Ukážka: údaje študenta

#include <iostream>
#include <string>

int main() {
    const int studentId{101};
    std::string meno{"Jana Novakova"};
    int rocnik{4};
    double priemer{1.8};
    bool aktivny{true};
    char skupina{'A'};

    rocnik = 5; // premennú môžeme zmeniť

    std::cout << "ID: " << studentId << std::endl;
    std::cout << "Meno: " << meno << std::endl;
    std::cout << "Rocnik: " << rocnik << std::endl;
    std::cout << "Priemer: " << priemer << std::endl;
    std::cout << "Aktivny: " << aktivny << std::endl;
    std::cout << "Skupina: " << skupina << std::endl;
}

Prečo je ID konštanta? V tomto krátkom príklade ho po vytvorení záznamu nemeníme. V inom programe môže byť ID pridelené neskôr; typ a mutabilita sa volia podľa pravidiel konkrétnej aplikácie.

Zostavenie a spustenie – MSVC

  1. Ulož kód ako typy.cpp.
  2. Otvor Developer Command Prompt for VS 2022 a prejdi do priečinka súboru.
  3. Zostav: cl /std:c++17 /EHsc /W4 /Fe:typy.exe typy.cpp.
  4. Spusti typy.exe a sleduj, ako sa líši výpis jednotlivých typov.

Toto je konzolový príklad štandardného C++, nie Win32 aplikácia. Nepotrebuje Windows API ani samostatné systémové knižnice.

Vyber typ podľa významu

  • Počet študentov → celé číslo.
  • Priemer známok → číslo s desatinnou časťou.
  • Je študent aktívny? → pravdivostná hodnota.
  • Meno → textový reťazec.
  • Označenie jednej skupiny → jeden znak, ak je to naozaj iba jeden znak.

Názvy a čitateľnosť

  • Použi názov, ktorý vysvetľuje význam, napríklad pocetStudentov.
  • Dodrž jednotný štýl pomenovania v celom príklade.
  • Typy C++ odlišujú veľké a malé písmená: bool nie je Bool.
  • Textové hodnoty píš do úvodzoviek, znak do apostrofov.

Interaktívna kontrola

Potrebujeme uchovať informáciu „študent má aktívny účet“. Ktorý typ najlepšie vyjadruje dve možné hodnoty aktívny/neaktívny?

Vyber odpoveď:

Praktická úloha: záznam študenta

Cieľ: vybrať typy a vytvoriť čitateľný výpis zmiešaných údajov.

Predpoklady: premenné, priradenie, výpis cez std::cout.

  1. Deklaruj ID ako konštantu a inicializuj ho celým číslom.
  2. Vytvor premenné pre meno, triedu, priemer a aktívny stav.
  3. Pre každú premennú vyber typ podľa významu.
  4. Vypíš všetky údaje a zmeň jednu nekonštantnú hodnotu.
  5. Skús priradiť inú hodnotu do konštanty a vysvetli, prečo to kompilátor odmietne; chybný riadok potom odstráň.

Očakávaný výsledok: program vypíše záznam a správne používa typy aj konštantu.

Kritériá (5 b): vhodné typy (2), inicializácia (1), správne použitie const (1), čitateľný výpis (1).

  • Základná: doplň typy do pripraveného vzoru.
  • Rozširujúca: pridaj počet vymeškaných hodín a vysvetli výber typu.
  • Náročnejšia: nájdi v modeli údaj, ktorý sa po inicializácii nemá meniť, a obháj použitie const.

Zhrnutie: 6 poznatkov

  1. Premenná má názov, typ a aktuálnu hodnotu.
  2. Typ vyberáme podľa významu údajov, ktoré uchovávame.
  3. int je na celé čísla, double na čísla s desatinnou časťou.
  4. bool má hodnoty true a false; std::string uchováva text.
  5. Inicializácia nastaví počiatočnú hodnotu; priradenie môže premennú zmeniť.
  6. const označí hodnotu, ktorú program po inicializácii nesmie meniť.

Kontrolné otázky

  1. Aký je rozdiel medzi deklaráciou a inicializáciou?
  2. Ktorý typ použiješ pre pravdivostný stav?
  3. Prečo nemožno po inicializácii meniť konštantu?
  4. Aký je rozdiel medzi zápisom 'A' a "Ahoj"?
Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: deklarácia oznamuje názov a typ; inicializácia zároveň dáva počiatočnú hodnotu. Pre pravdivostný stav použijeme bool. Konštanta chráni hodnotu pred neúmyselnou zmenou. 'A' je znak, "Ahoj" je textový reťazec.

Interaktívna kontrola: správna je A (bool), pretože stav má dve pravdivostné možnosti.

Hodnotenie: 5 bodov podľa kritérií úlohy. Pri výbere int pre zjednodušený priemer si vyžiadaj zdôvodnenie; zvyčajne vhodnejší je double.

Podpora: použi kartičky „celé číslo“, „desatinné číslo“, „áno/nie“, „jeden znak“, „text“ a nechaj ich spárovať s typmi pred zápisom kódu.

Poznámky a povinné vedomosti, ktoré si zapamätáš z hodiny

  • Každá premenná má typ, názov a aktuálnu hodnotu.
  • Typ vyberám podľa významu údaja.
  • Inicializácia dáva počiatočnú hodnotu; priradenie mení nekonštantnú premennú.
  • const používam, keď sa hodnota po inicializácii nemá meniť.
