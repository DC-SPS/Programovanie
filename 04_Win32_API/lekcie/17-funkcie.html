Parametre, návratové hodnoty a prototypy

Odovzdaj funkcii údaje a prevezmi výsledok jej práce

4. ročník SPŠ · C++ príprava pre Win32

Funkcia pomáha pomenovať opakovateľnú operáciu. Parametre odovzdajú údaje do funkcie, návratová hodnota pošle výsledok späť a prototyp oznámi kompilátoru podpis funkcie ešte pred jej definíciou.

Vstup → spracovanie → výsledok
Začiatok hodiny: skontrolujte pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívajte. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážete:

  • určiť názov, návratový typ a parametre funkcie;
  • odlíšiť parameter od argumentu pri volaní;
  • vytvoriť prototyp a zodpovedajúcu definíciu funkcie;
  • uložiť a použiť návratovú hodnotu funkcie.

Prepojenie s kurzom

V udalostne riadenom programe obsluha udalosti často zavolá pomocnú funkciu. Dobre pomenovaná funkcia zjednoduší čítanie kódu aj neskoršie rozdelenie aplikácie na časti.

V zápise int sucet(int a, int b); je int návratový typ, sucet názov a a, b parametre. Pri volaní sucet(3, 4) sú čísla 3 a 4 argumenty.

Prototyp (deklarácia)

Prototyp obsahuje návratový typ, názov a typy parametrov, ale nemá telo. Bodkočiarka ho ukončuje.

int sucet(int prve, int druhe);

Umiestni ho pred prvé použitie funkcie, napríklad pred main.

Definícia

Definícia pridá telo medzi zložené zátvorky a určí, čo funkcia vykoná.

int sucet(int prve, int druhe) {
    return prve + druhe;
}

Podpis definície musí zodpovedať prototypu. Pri návratovom type void funkcia neposkytuje hodnotu.

Ukážka: súčet bodov

#include <iostream>

int sucetBodov(int test, int projekt); // prototyp

int main() {
    int vysledok = sucetBodov(18, 24); // argumenty
    std::cout << "Spolu bodov: " << vysledok << std::endl;
}

int sucetBodov(int test, int projekt) { // definícia, parametre
    return test + projekt;
}

Tok údajov: hodnoty 18 a 24 sa stanú hodnotami parametrov test a projekt. Funkcia spočíta výsledok a return odovzdá hodnotu späť volajúcemu. Výsledok uložíme do premennej vysledok.

Prototyp umožní zavolať funkciu v main, hoci jej definícia je nižšie v súbore.

Parameter a argument

  • Parameter je pomenovaná premenná v hlavičke funkcie.
  • Argument je konkrétna hodnota alebo výraz odovzdaný pri volaní.
  • Poradie argumentov musí zodpovedať poradiu parametrov.
  • Typy argumentov musia byť kompatibilné s typmi parametrov.

Čo zabezpečí návratový typ?

  • int znamená, že funkcia vráti celé číslo.
  • double môže vrátiť číslo s desatinnou časťou.
  • bool môže oznámiť úspech alebo neúspech.
  • void znamená, že funkcia nevracia hodnotu.

Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: prototyp oznamuje kompilátoru názov, návratový typ a typy parametrov; parameter je v definícii, argument sa odovzdáva pri volaní; return vracia hodnotu a ukončuje vykonanie funkcie; pre funkciu bez návratovej hodnoty použijeme void.

Interaktívna kontrola: správna je B; 45 a 9 sú argumenty, ktoré sa priradia parametrom sucet a pocet.

Hodnotenie: 5 bodov podľa kritérií úlohy. Kontroluj zhodu prototypu a definície aj to, že návratový výsledok žiak použil.

Podpora: farebne označ návratový typ, názov, parametre a argumenty. Daj žiakovi vyplniť prototyp zo šablóny skôr, než napíše celé telo funkcie.

Poznámky a povinné vedomosti, ktoré si zapamätáte z hodiny

  • Prototyp deklaruje funkciu pred jej použitím.
  • Parametre sú pomenované vstupy; argumenty sú hodnoty pri volaní.
  • Návratový typ určuje typ výsledku funkcie.
  • return odovzdá výsledok volajúcemu.
