Dedičnosť a opätovné použitie kódu

Spoločné vlastnosti do základnej triedy, špecifické vlastnosti do odvodenej

4. ročník SPŠ · C++ príprava pre Win32

Ak viac typov zdieľa rovnaké vlastnosti a správanie, niekedy ich môžeme zoskupiť do základnej triedy. Odvodená trieda zdedí jej verejné rozhranie a doplní svoje špecifiká. Dedičnosť použijeme iba vtedy, keď medzi typmi naozaj platí vzťah „je druhom“.

Osoba → Študent · spoločné údaje použijeme znovu
Začiatok hodiny: skontroluj pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívaj. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážeš:

  • vysvetliť pojmy základná a odvodená trieda;
  • rozpoznať vzťah „je druhom“ vhodný na dedičnosť;
  • v C++ vytvoriť jednoduchú odvodenú triedu s verejnou dedičnosťou;
  • uviesť prípad, keď dedičnosť vhodná nie je.

Prepojenie s hod. 11

Zapuzdrenie chráni vnútorné údaje a určuje rozhranie triedy. Dedičnosť vyjadruje vzťah medzi triedami a umožňuje odvodenému typu použiť verejné operácie základného typu. Súkromné údaje základnej triedy zostávajú skryté.

Model: osoba a študent

Osoba
meno · nastaviMeno() · vypisMeno()
↑ zdedí verejné rozhranie
Student

Učiteľ

Každý študent je osoba, no každá osoba nemusí byť študentom. Preto môže byť Student odvodený od Osoba. Údaje a operácie špecifické pre študenta zostávajú v triede Student.

Ukážka v C++17

#include <iostream>
#include <string>

class Osoba {
private:
    std::string meno;

public:
    void nastavMeno(const std::string& noveMeno) {
        meno = noveMeno;
    }

    void vypisMeno() const {
        std::cout << meno;
    }
};

class Student : public Osoba {
private:
    std::string trieda;

public:
    void nastavTriedu(const std::string& novaTrieda) {
        trieda = novaTrieda;
    }

    void vypisStudenta() const {
        vypisMeno();
        std::cout << " - " << trieda << '\n';
    }
};

int main() {
    Student ziak{};
    ziak.nastavMeno("Jana Novakova");
    ziak.nastavTriedu("IV.A");
    ziak.vypisStudenta();
}

Čítanie zápisu: Student : public Osoba znamená, že Student verejne dedí od Osoba. Objekt ziak môže použiť verejnú metódu nastavMeno základnej triedy aj svoje vlastné metódy. Súkromný atribút meno však nie je priamo prístupný v Student; základná trieda ho používa cez svoje metódy.

Dôležité: verejná dedičnosť zachováva vzťah „Student je Osoba“. V tejto lekcii nepoužívame virtuálne funkcie ani polymorfné ukazovatele; tie patria do ďalších tém.

Zostavenie a spustenie – MSVC

  1. Ulož kód ako dedicnost.cpp.
  2. Otvor Developer Command Prompt for VS 2022 a prejdi do priečinka súboru.
  3. Zostav: cl /std:c++17 /EHsc /W4 /Fe:dedicnost.exe dedicnost.cpp.
  4. Spusti dedicnost.exe; očakávaj Jana Novakova - IV.A.

Konzolový príklad používa štandardné C++, nie Win32 API, a nepotrebuje samostatné systémové knižnice.

Kedy dedičnosť pomáha?

  • Odvodený typ je skutočne špecifickejší druh základného typu.
  • Viaceré triedy zdieľajú zmysluplnú sadu vlastností alebo operácií.
  • Spoločnú časť stačí udržiavať na jednom mieste.

Kedy ju nepoužiť?

  • Len preto, že dve triedy majú rovnaký textový atribút.
  • Keď vzťah „je druhom“ nie je pravdivý.
  • Keď trieda iba používa inú vec, napríklad študent má adresu, no nie je adresou.
  • Keď dedičnosť vytvorí zbytočne hlbokú alebo zložitú hierarchiu.

Ktorý vzťah je najvhodnejší kandidát na verejnú dedičnosť?

Vyber odpoveď:

Praktická úloha: Osoba a študent

Cieľ: navrhnúť spoločnú základnú triedu a doplniť špecifickú odvodenú triedu.

Predpoklady: triedy, private/public, metódy a jednoduchá validácia.

  1. Vytvor základnú triedu Osoba so súkromným menom a verejnou metódou na jeho nastavenie.
  2. Vytvor triedu Student, ktorá verejne dedí od Osoba.
  3. Pridaj študentský údaj, napríklad triedu, a metódu na výpis oboch častí.
  4. Vytvor objekt študenta a použi metódy oboch tried.
  5. Zakrúžkuj, ktoré riadky patria k spoločnej časti a ktoré k špecifickej.

Očakávaný výsledok: študentský objekt používa verejné rozhranie základnej triedy a vlastné operácie.

Kritériá (5 b): vhodný vzťah „je druhom“ (1), spoločný člen zapuzdrený (1), správna dedičnosť (1), špecifický údaj/metóda (1), výpis a vysvetlenie (1).

  • Základná: doplň hlavičku odvodenia a jeden atribút.
  • Rozširujúca: navrhni triedu Učiteľ odvodenú od Osoba s vlastným údajom.
  • Náročnejšia: porovnaj dedičnosť a samostatné triedy, ak dve nezávislé entity náhodou obsahujú rovnaký atribút.

Zhrnutie: 6 poznatkov

  1. Základná trieda obsahuje spoločné vlastnosti a rozhranie.
  2. Odvodená trieda zdedí verejné členy a pridá svoje špecifiká.
  3. Verejná dedičnosť vyjadruje vzťah „je druhom“.
  4. Súkromné členy základnej triedy zostanú skryté.
  5. Dedičnosť môže znížiť opakovanie spoločného kódu.
  6. Dedičnosť nepoužívam, ak je vzťah medzi typmi iba „má“ alebo „používa“.

Kontrolné otázky

  1. Ktorá trieda je v príklade základná?
  2. Prečo môže Student volať nastavMeno?
  3. Prečo nemôže priamo meniť private atribút meno?
  4. Aký je rozdiel medzi „študent je osoba“ a „študent má adresu“?
Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: Osoba; metóda nastavMeno je verejne zdedená; atribút je private v základnej triede a prístup k nemu má iba jej vlastné rozhranie; prvý je vzťah „je druhom“ vhodný na dedičnosť, druhý je vzťah „má“, ktorý zvyčajne modelujeme samostatným členom/objektom.

Interaktívna kontrola: správna je A. Daj žiakovi preveriť vetu „X je druh Y“; ak znie zmysluplne aj opačne iba v jednom smere, kandidát môže byť vhodný, ale treba skontrolovať potreby návrhu.

Hodnotenie: 5 bodov podľa kritérií praktickej úlohy. Dedičnosť nehodnoť ako povinnú voľbu, ak žiak obháji vhodnejší model bez nej.

Podpora: použite kartičky Osoba, Študent, Učiteľ, Adresa a vyznačte šípkou „je druhom“ alebo spojom „má“. Kód začnite hotovou základnou triedou.

Poznámky a povinné vedomosti, ktoré si zapamätáš z hodiny

  • Základná trieda obsahuje spoločnú časť; odvodená trieda dopĺňa špecifickú.
  • Zápis class Student : public Osoba vyjadruje verejnú dedičnosť.
  • Dedičnosť má vyjadrovať vzťah „je druhom“, nie iba podobné údaje.
  • Súkromné členy základnej triedy používam cez jej verejné rozhranie.

Nadväznosť: hodina 13 začne polymorfizmom, prekrývaním metód a rozdielnym správaním odvodených objektov.
