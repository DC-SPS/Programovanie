Vytvorenie prvého Win32 projektu

Zaregistruj triedu okna, vytvor okno a spusti správovú slučku

4. ročník SPŠ · Natívne Win32 C++ · MSVC v143

Po overení nástrojov vytvoríme minimálnu natívnu Windows aplikáciu. Zaregistrujeme vlastnú triedu okna, vytvoríme okno, zobrazíme ho a budeme spracúvať správy Windows.

wWinMain → RegisterClassExW → CreateWindowExW → message loop
Začiatok hodiny: skontrolujte pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívajte. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážete:

  • vysvetliť úlohu vstupného bodu wWinMain;
  • opísať, prečo sa registruje trieda okna ešte pred jeho vytvorením;
  • vytvoriť a zobraziť hlavné okno cez Unicode Win32 funkcie;
  • vysvetliť základ správovej slučky a úlohu procedúry okna.

Prepojenie

Na hodine 24 sme zostavili konzolový C++ program. Teraz voláme skutočné Windows API s hlavičkou Windows SDK. Tento projekt je GUI aplikáciou a používa vstupný bod wWinMain, nie main.

Životný cyklus prvého okna

1 · VstupwWinMain
2 · Registráciatrieda a WindowProc
3 · VytvorenieCreateWindowExW
4 · Správyslučka a procedúra

Trieda okna opisuje spoločné vlastnosti a procedúru, ktorá obsluhuje správy. Samotné okno vzniká až následným volaním CreateWindowExW.

Úplný minimálny program

#define UNICODE
#define _UNICODE
#include <windows.h>

constexpr wchar_t CLASS_NAME[] = L"PrveWin32Okno";

LRESULT CALLBACK WindowProc(
    HWND hwnd, UINT message, WPARAM wParam, LPARAM lParam)
{
    switch (message) {
    case WM_DESTROY:
        PostQuitMessage(0);
        return 0;
    }
    return DefWindowProcW(hwnd, message, wParam, lParam);
}

int WINAPI wWinMain(
    HINSTANCE hInstance, HINSTANCE, PWSTR, int nCmdShow)
{
    WNDCLASSEXW wc{};
    wc.cbSize = sizeof(wc);
    wc.lpfnWndProc = WindowProc;
    wc.hInstance = hInstance;
    wc.hCursor = LoadCursorW(nullptr, IDC_ARROW);
    wc.hbrBackground = GetSysColorBrush(COLOR_WINDOW);
    wc.lpszClassName = CLASS_NAME;

    if (!RegisterClassExW(&wc)) {
        return 1;
    }

    HWND hwnd = CreateWindowExW(
        0,
        CLASS_NAME,
        L"Moja prvá Win32 aplikácia",
        WS_OVERLAPPEDWINDOW,
        CW_USEDEFAULT, CW_USEDEFAULT, 640, 400,
        nullptr, nullptr, hInstance, nullptr);

    if (hwnd == nullptr) {
        return 1;
    }

    ShowWindow(hwnd, nCmdShow);
    UpdateWindow(hwnd);

    MSG message{};
    BOOL result;
    while ((result = GetMessageW(&message, nullptr, 0, 0)) > 0) {
        TranslateMessage(&message);
        DispatchMessageW(&message);
    }

    if (result == -1) {
        return 1;
    }
    return static_cast<int>(message.wParam);
}

Čo je dôležité: trieda okna má nastavenú procedúru WindowProc. Po prijatí WM_DESTROY zavoláme PostQuitMessage, aby sa správová slučka ukončila. Ostatné správy necháme na predvolené spracovanie cez DefWindowProcW.

Na začiatku ešte nekreslíme ani nepridávame ovládacie prvky. Cieľom je najprv dostať spoľahlivé prázdne okno.

Zostavenie a spustenie – MSVC v143

  1. Otvorte pracovný priečinok v VS Code z Developer Command Prompt for VS 2022 (alebo pripravte prostredie rovnocenným VS Code taskom).
  2. Uložte kód ako prve_okno.cpp.
  3. Zostavte presne týmto príkazom MSVC:
    cl /std:c++17 /EHsc /W4 /DUNICODE /D_UNICODE /Fe:prve_okno.exe prve_okno.cpp /link /SUBSYSTEM:WINDOWS user32.lib
  4. Spustite prve_okno.exe. Malo by sa zobraziť prázdne okno s titulkom „Moja prvá Win32 aplikácia“.
  5. Zatvorte okno tlačidlom X; aplikácia má skončiť.

Závislosť: použité funkcie okien a správ poskytuje User32.lib. Príklad nepoužíva GDI, preto zatiaľ nepridávame Gdi32.lib. Prepínač /SUBSYSTEM:WINDOWS vytvorí GUI program bez konzolového okna.

Toto je natívny Win32 program. Vyžaduje Windows, Windows SDK a pripravené prostredie MSVC. Bežný online kompilátor v Linuxe ho nezostaví ani nespustí.

Štyri kľúčové funkcie

  • RegisterClassExW zaregistruje vlastnosti triedy okna.
  • CreateWindowExW vytvorí konkrétnu inštanciu okna.
  • ShowWindow zobrazí okno.
  • GetMessageW, TranslateMessage a DispatchMessageW načítajú a doručia správy.

Procedúra okna

WindowProc prijíma identifikátor okna, kód správy a súvisiace parametre. Program obslúži iba správy, ktoré potrebuje; ostatné odovzdá Windows cez DefWindowProcW.

WM_DESTROY oznamuje zničenie okna. PostQuitMessage(0) vloží správu ukončenia do frontu pre hlavnú slučku.

Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: trieda opisuje správanie a procedúru, okno je konkrétna inštancia; Windows musí triedu poznať pred CreateWindowEx; WindowProc spracúva správy okna; PostQuitMessage vloží WM_QUIT, takže GetMessageW vráti 0 a slučka sa skončí.

Interaktívna kontrola: správna je A. Registrácia nepridáva okno na obrazovku; až CreateWindowExW vytvorí jeho inštanciu.

Hodnotenie: 5 bodov podľa kritérií praktickej úlohy. Ak sa program nezostaví pre nefunkčné školské prostredie, uznaj diagnostiku konkrétnej chyby.

Podpora: poskytnúť vytlačenú kostru s označenými fázami. Najprv spoločne vystopovať wWinMain a registráciu, až potom nechať žiaka čítať celý cyklus.

Poznámky a povinné vedomosti, ktoré si zapamätáte z hodiny

  • Vstupným bodom GUI programu je wWinMain.
  • Okno vytvorím až po registrácii jeho triedy.
  • Správy spracúva správová slučka a procedúra WindowProc.
  • WM_DESTROY → PostQuitMessage → koniec slučky.
  • Win32 ukážku zostavujem cez MSVC a Windows SDK na Windows.
