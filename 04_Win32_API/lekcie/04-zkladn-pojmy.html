Atribúty a stav objektu

Čo si objekt uchováva a ako jeho hodnoty opisujú aktuálny stav

4. ročník SPŠ · C++ príprava pre Win32

V minulej hodine sme vytvorili viac objektov rovnakej triedy. Teraz preskúmame ich atribúty: údaje, ktoré každý objekt uchováva samostatne. Súhrn aktuálnych hodnôt jeho atribútov nazývame stav objektu.

Od typu a inštancie k údajom a stavu
Začiatok hodiny: skontrolujte pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívajte. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážete:

  • vysvetliť pojmy atribút a stav objektu;
  • navrhnúť aspoň tri vhodné atribúty pre jednoduchý objekt;
  • v C++ priradiť a vypísať hodnoty atribútov dvoch inštancií;
  • opísať, ako priradenie novej hodnoty mení stav jedného objektu.

Motivácia: knižničná kniha

Kniha v evidencii má nemenný názov, počet strán a údaj o tom, či je práve vypožičaná. Ak sa kniha požičia, zmení sa jej stav. Iná kniha tej istej triedy má vlastný stav a jej údaje sa tým nemenia.

Nadväznosť: triedu Kniha poznáme ako opis; teraz sa sústredíme na hodnoty jej členov a na to, ako ich objekt nesie.

Atribút → aktuálna hodnota → stav

Atribútvypozicana
Hodnota terazfalse
Stav inštanciekniha je dostupná

Po výpožičke: false → true

  • Atribút (členská premenná) pomenúva druh údaja, ktorý patrí každému objektu danej triedy.
  • Hodnota atribútu je aktuálny údaj uložený v konkrétnej inštancii.
  • Stav objektu je súhrn aktuálnych hodnôt jeho atribútov.
  • Stav sa môže meniť počas behu programu. Zmena v jednej samostatnej inštancii nemení automaticky stav inej.

Ukážka v C++17

#include <iostream>
#include <string>

class Kniha {
public:
    std::string nazov;
    int pocetStran{};
    bool vypozicana{};
};

int main() {
    Kniha knihaA{};
    knihaA.nazov = "Tajomny ostrov";
    knihaA.pocetStran = 240;
    knihaA.vypozicana = false;

    Kniha knihaB{};
    knihaB.nazov = "Cesta domov";
    knihaB.pocetStran = 180;
    knihaB.vypozicana = true;

    knihaA.vypozicana = true; // zmenil sa stav knihyA

    std::cout << knihaA.nazov << ": " << knihaA.vypozicana << '\n';
    std::cout << knihaB.nazov << ": " << knihaB.vypozicana << '\n';
}

Predpokladaný výstup: oba riadky končia hodnotou 1, pretože bool sa bez ďalšieho formátovania vypíše ako 0 alebo 1. Prvý stav sa zmenil priradením true; druhá kniha bola vypožičaná už predtým a jej stav neovplyvnila zmena prvej.

Kniha knihaA{} vytvorí objekt a hodnotovo inicializuje jeho členy. Zložené zátvorky pri vytvorení pomáhajú predísť neúmyselne neinicializovaným číselným a logickým hodnotám.

Zostavenie a spustenie – MSVC

  1. Uložte kód ako knihy.cpp.
  2. Otvorte Developer Command Prompt for VS 2022 a prejdite do priečinka súboru.
  3. Zostavte: cl /std:c++17 /EHsc /W4 /Fe:knihy.exe knihy.cpp.
  4. Spustite: knihy.exe.

Je to konzolová ukážka štandardného C++, nie Win32 program. Používa štandardnú knižnicu; nevyžaduje Windows API ani samostatné systémové knižnice. Pre kompiláciu treba pripravené MSVC prostredie.

Ako vybrať atribúty?

  1. Pýtaj sa, aké informácie musí program o každom objekte uchovať.
  2. Vyberte údaje, ktoré patria ku každej jednotlivej inštancii.
  3. Zvoľte typ, ktorý zodpovedá hodnote: text, celé číslo, pravdivostná hodnota.
  4. Pri každej inštancii si vypíšte jej aktuálne hodnoty a skontrolujte, či dávajú zmysel.

Čomu sa vyhnúť?

  • Nepatria sem údaje, ktoré nesúvisia s každým objektom danej triedy.
  • Rovnaký názov atribútu neznamená zdieľanú hodnotu medzi objektmi.
  • Ak program mení viac atribútov, skontrolujte celý nový stav, nie len posledné priradenie.
  • Ukážka používa public pre jednoduchosť. Riadenie prístupu a zapuzdrenie rozoberieme neskôr.

Interaktívna kontrola

Vytvorili sme Kniha knihaA{} a Kniha knihaB{}. Obe mali vypozicana = false. Potom program vykonal knihaA.vypozicana = true;. Aký je výsledný stav?

Vyberte odpoveď:

Praktická úloha: stav študenta

Cieľ: opísať stav študenta tromi atribútmi a ukázať, že dve inštancie majú samostatné hodnoty.

Predpoklady: trieda a inštancia z hodiny 3, základné typy C++.

  1. Vytvorte triedu Student s atribútmi meno, rocnik a aktivny.
  2. Vytvorte dve inštancie s rôznymi hodnotami.
  3. Vypíšte všetky atribúty oboch inštancií.
  4. Zmeňte aktivny iba v jednej a vysvetlite, ako sa zmenil jej stav.

Očakávaný výsledok: dve čitateľné zostavy hodnôt; po priradení sa zmení iba vybraná inštancia.

Kritériá (5 b): zmysluplné atribúty a typy (2), správne vytvorené inštancie (1), výpis a zmena stavu (1), vysvetlenie nezávislosti (1).

  • Základná: vyplňte pripravenú triedu a jednu inštanciu podľa vzoru.
  • Rozširujúca: pridajte atribút s dátumom narodenia ako textom a vytvorte tretiu inštanciu.
  • Náročnejšia: vyberte vhodné atribúty pre záznam o knihe a vysvetlite, ktorý údaj sa môže meniť počas jej používania.

Zhrnutie: 6 poznatkov

  1. Atribút je členská premenná, ktorá uchováva údaj objektu.
  2. Každá inštancia má vlastnú aktuálnu hodnotu svojich atribútov.
  3. Stav objektu je súhrn hodnôt jeho atribútov v danom okamihu.
  4. Priradenie novej hodnoty môže zmeniť stav konkrétneho objektu.
  5. Samostatné inštancie sa navzájom automaticky nemenia.
  6. Pri vytváraní objektu používajte vhodnú inicializáciu, napríklad zložené zátvorky.

Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: atribút je členská premenná triedy; stav je súhrn aktuálnych hodnôt atribútov objektu; každá inštancia má vlastné hodnoty; priradenie mení atribút vypozicana objektu knihaA, nie druhého objektu.

Interaktívna kontrola: správna je B. Ak žiak vyberie A, nech ukáže v zápise obe mená objektov a vysvetlí, ktorú inštanciu priraďovací výraz pomenúva.

Hodnotenie: 5 bodov podľa kritérií úlohy. Pri návrhu atribútov prijmi rôzne voľby, ak patria ku každej inštancii a žiak vie vysvetliť ich typ.

Podpora: priprav tabuľku s riadkami pre inštancie a stĺpcami pre atribúty. Žiak do nej doplní hodnoty pred a po zmene a potom prevedie jeden riadok na priradenia v kóde.

Poznámky a povinné vedomosti, ktoré si zapamätáte z hodiny

  • Atribúty sú údaje uložené v jednotlivých objektoch.
  • Stav objektu je súhrn hodnôt jeho atribútov v danom okamihu.
  • Dve inštancie rovnakej triedy majú samostatné hodnoty atribútov.
  • Priradenie cez názov objektu a bodku mení zvolený atribút tejto inštancie.
