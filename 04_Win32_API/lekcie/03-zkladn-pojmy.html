Trieda, objekt a inštancia

Ako opísať typ veci a vytvoriť konkrétne hodnoty, s ktorými program pracuje

4. ročník SPŠ · C++ príprava pre Win32

Win32 aplikácia neskôr pracuje s oknami, ovládacími prvkami a stavom programu. Predtým si ujasníme základ objektového modelovania: trieda opisuje spoločný typ a objekt je konkrétna hodnota vytvorená podľa tohto opisu.

45 minút · najprv model dát, neskôr používateľské rozhranie
Začiatok hodiny: skontrolujte pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívajte. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážete:

  • vlastnými slovami vysvetliť pojem trieda, objekt a inštancia;
  • z dátového opisu určiť, ktoré vlastnosti patria do jednej triedy;
  • v C++ deklarovať jednoduchú triedu a vytvoriť dve samostatné inštancie;
  • predpovedať, ako zmena člena jedného objektu ovplyvní druhý objekt.

Predstava: plán a vyrobené kusy

Predstavte si technický výkres stoličky. Výkres opisuje spoločné vlastnosti, ale každá vyrobená stolička je konkrétny kus. V programe podobne trieda stanovuje, aké údaje a operácie daný typ môže mať; jednotlivé objekty majú vlastné hodnoty.

Prepojenie: z predchádzajúcich hodín poznáte premenné a typy. Trieda umožní zoskupiť súvisiace údaje a správanie do vlastného typu.

  • Trieda je definícia, ktorá určuje členy a prípadne operácie objektov daného typu.
  • Objekt je konkrétna entita v programe vytvorená podľa typu; v tomto úvode budeme slovami objekt a inštancia označovať túto konkrétnu hodnotu.
  • Inštancia zdôrazňuje, že konkrétny objekt vznikol vytvorením podľa triedy.
  • Dva objekty rovnakej triedy majú rovnakú štruktúru členov, ale každý si uchováva vlastné hodnoty.

Ukážka v C++17

#include <iostream>
#include <string>

class Student {
public:
    std::string meno;
    int rocnik;
};

int main() {
    Student studentA;
    studentA.meno = "Jana";
    studentA.rocnik = 4;

    Student studentB;
    studentB.meno = "Peter";
    studentB.rocnik = 3;

    std::cout << studentA.meno << " - rocnik " << studentA.rocnik << '\n';
    std::cout << studentB.meno << " - rocnik " << studentB.rocnik << '\n';
}

Čítanie kódu: class Student definuje nový typ. studentA a studentB sú dve inštancie. Bodka vyberá člena konkrétneho objektu: studentA.meno. Priradenie do studentA.rocnik nemení studentB.rocnik.

Poznámka k tejto hodine: ide o krátky konzolový príklad štandardného C++, nie o Win32 aplikáciu. GUI a Windows API prídu neskôr.

Zostavenie a spustenie – MSVC

  1. Uložte kód ako student.cpp.
  2. Otvoriť Developer Command Prompt for VS 2022 a prejsť do priečinka súboru.
  3. Spustiť cl /std:c++17 /EHsc /W4 /Fe:student.exe student.cpp.
  4. Spustiť vytvorený súbor príkazom student.exe.

Tento príklad používa štandardnú knižnicu C++; nepotrebuje Win32 API ani samostatnú Windows systémovú knižnicu. Kompilátor MSVC však musí byť nainštalovaný a pripravený v Developer Command Prompt.

Postup modelovania

  1. Určite, aké veci program eviduje (napríklad študentov).
  2. Vyberte údaje, ktoré majú všetky tieto veci (meno, ročník).
  3. Pomenujte triedu podľa typu veci.
  4. Vytvorte konkrétne objekty a priraďte im rozdielne hodnoty.
  5. Skontrolujte, či zmena jedného objektu neovplyvnila druhý.

Časté nedorozumenia

  • Trieda nie je jeden konkrétny študent, ale opis typu.
  • Objekty rovnakej triedy nemusia mať rovnaké hodnoty.
  • Názov člena sám o sebe nie je hodnota; každá inštancia má svoj členský priestor.
  • Verejné členy používame v úvodnej ukážke pre jednoduchosť; vhodné zapuzdrenie budeme riešiť v ďalších hodinách.

Interaktívna kontrola

V kóde sú vytvorené studentA a studentB z triedy Student. Zmeníme studentA.rocnik z 4 na 2. Čo bude platiť pre studentB.rocnik?

Praktická úloha: Kniha

Cieľ: navrhnúť triedu pre jednoduchú evidenciu kníh a vytvoriť dve odlišné inštancie.

Predpoklady: premenné, základné typy a priraďovanie hodnôt v C++.

  1. Určite aspoň dva spoločné údaje knihy (napr. názov a počet strán).
  2. Napíšte definíciu class Kniha s verejnými členmi pre tento prvý príklad.
  3. V main vytvorte knihaA a knihaB; priraďte im rozdielne hodnoty.
  4. Vypíšte aspoň jeden údaj z každej knihy a ústne vysvetlite, čo je trieda a čo inštancia.

Očakávaný výsledok: dve samostatné hodnoty typu Kniha s rozdielnymi údajmi.

Kritériá (5 b): vhodná trieda a členy (2), dve správne vytvorené inštancie (1), rozdielne priradené hodnoty (1), zrozumiteľné vysvetlenie pojmov (1).

  • Základná: doplňte chýbajúce názvy členov a priradenia do pripraveného vzoru.
  • Rozširujúca: pridajte tretí údaj a tretiu knihu.
  • Náročnejšia: navrhnite triedu Student pre neskoršiu evidenciu a zdôvodnite, ktoré údaje patria ku každému študentovi.

Zhrnutie: 6 poznatkov

  1. Trieda je definícia vlastného typu.
  2. Objekt je konkrétna hodnota tohto typu; nazývame ho aj inštancia.
  3. Inštancie rovnakej triedy majú rovnaké deklarované členy.
  4. Každý objekt uchováva svoje vlastné hodnoty členov.
  5. Člen objektu vyberáme operátorom bodky, napríklad studentA.meno.
  6. Triedy nám pomôžu modelovať dáta aplikácie ešte pred tvorbou okna.

Kontrolné otázky

  1. Čím sa líši trieda od objektu?
  2. Koľko inštancií triedy Student môže program vytvoriť?
  3. Čo označuje výraz studentB.meno?
  4. Ak zmeníme člena jedného samostatného objektu, čo sa stane s druhým?
Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: trieda je opis/definícia typu, objekt je konkrétna hodnota; možno vytvoriť ľubovoľný počet inštancií podľa dostupnej pamäte a pravidiel programu; studentB.meno je člen meno konkrétnej inštancie studentB; zmena člena samostatného objektu sama osebe nemení člen druhého objektu.

Interaktívna kontrola: správna je možnosť B. Po odpovedi sa opýtaj, kde v zápise je vidieť názov objektu a kde názov jeho člena.

Hodnotenie: 5 bodov podľa kritérií praktickej úlohy. Uznaj alternatívne zmysluplné vlastnosti knihy, ak sú spoločné pre všetky inštancie danej triedy.

Podpora: použi papierové kartičky „trieda Kniha“ a dve konkrétne kartičky kníh s rôznymi hodnotami. Kód nechaj najprv doplniť podľa vzoru; pri potrebe pomoci zvýrazni v odlišných farbách typ, názvy objektov a ich členy.

Poznámky a povinné vedomosti, ktoré si zapamätáte z hodiny

  • Trieda definuje vlastný typ a jeho členy.
  • Objekt/inštancia je konkrétna hodnota vytvorená podľa triedy.
  • Dve inštancie rovnakej triedy majú rovnaké členy, ale vlastné hodnoty.
  • Člen objektu vyberám bodkou, napríklad studentA.meno.

Nadväznosť: hodina 4 pokračuje základnými pojmami a zameria sa na atribúty a stav objektu.
