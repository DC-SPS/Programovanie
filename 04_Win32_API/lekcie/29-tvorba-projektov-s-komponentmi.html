Tvorba projektov s komponentmi

Zostavíme jednoduchý formulár z ovládacích prvkov a prepojíme ho s kódom aplikácie.

Začíname kontrolou pracoviska: Po príchode do učebne si skontrolujte svoje miesto, lavicu, stoličku a pridelený počítač s príslušenstvom. Každé poškodenie, chýbajúcu časť alebo inú závadu ihneď oznám vyučujúcemu. Stručný súhrn zistených nedostatkov pošli vyučujúcemu správou cez EduPage. Poškodené alebo nebezpečné zariadenie nepoužívajte.

Ciele hodiny

Na konci hodiny dokážete:

  • vymenovať aspoň tri komponenty jednoduchého formulára a opísať ich účel;
  • označiť hlavné okno ako rodiča a ovládacie prvky ako podradené okná;
  • navrhnúť formulár pre zadanie mena a triedy vrátane tried ovládacích prvkov a ich ID;
  • vysvetliť, ako CreateWindowExW vytvorí podradený prvok a ako rodič rozpozná kliknutie cez WM_COMMAND.

Zaradenie: po prvej Win32 aplikácii a príprave projektu začíname Modul 04. Dnes navrhujeme skladbu rozhrania; na hodine 30 ju prepojíme s logikou.

1. Čo je komponent?

Komponent je viditeľná alebo funkčná časť používateľského rozhrania, s ktorou používateľ pracuje. Vo formulári môžeme mať popis, textové pole, tlačidlo či rozbaľovací zoznam. Komponent má vlastnosti (napr. text, veľkosť a polohu), identifikátor a správanie pri udalosti.

Vo Win32 API je ovládací prvok samostatné podradené okno. Hlavné okno je jeho rodič. Funkcia CreateWindowExW vytvorí hlavné okno aj jednotlivé prvky; parameter hWndParent určuje rodiča.

3. Ako vznikne komponent v kóde?

Pri vytváraní prvku nastavujeme jeho triedu, text, štýly a rodičovské okno. Každému prvku, ktorého udalosť chceme spracovať, dáme vlastný identifikátor.

constexpr int ID_EDIT_MENO = 1001;
constexpr int ID_BUTTON_POZDRAV = 1002;

// V obsluhe správy WM_CREATE; hwnd je hlavné okno.
HINSTANCE hInstance = reinterpret_cast(lParam)->hInstance;
CreateWindowExW(
    0, L"STATIC", L"Meno:",
    WS_CHILD | WS_VISIBLE,
    20, 20, 80, 24,
    hwnd, nullptr, hInstance, nullptr);

CreateWindowExW(
    WS_EX_CLIENTEDGE, L"EDIT", L"",
    WS_CHILD | WS_VISIBLE | WS_TABSTOP | ES_AUTOHSCROLL,
    105, 18, 190, 28,
    hwnd, reinterpret_cast<HMENU>(static_cast<INT_PTR>(ID_EDIT_MENO)),
    hInstance, nullptr);

CreateWindowExW(
    0, L"BUTTON", L"Pozdraviť",
    WS_CHILD | WS_VISIBLE | WS_TABSTOP | BS_PUSHBUTTON,
    105, 58, 110, 32,
    hwnd, reinterpret_cast<HMENU>(static_cast<INT_PTR>(ID_BUTTON_POZDRAV)),
    hInstance, nullptr);

L"EDIT" a L"BUTTON"

Názov triedy určuje druh štandardného ovládacieho prvku.

WS_CHILD | WS_VISIBLE

Prvok je podradený oknu a po vytvorení ho Windows zobrazí.

Identifikátor

Pomocou ID neskôr zistíme, ktorý prvok vyvolal udalosť.

4. Kliknutie je správa

Keď používateľ klikne na tlačidlo, rodičovské okno dostane správu WM_COMMAND. Z wParam prečítame identifikátor a typ udalosti. Následne získame text z poľa a zobrazíme odpoveď.

case WM_COMMAND:
    if (LOWORD(wParam) == ID_BUTTON_POZDRAV &&
        HIWORD(wParam) == BN_CLICKED) {
        wchar_t meno[128]{};
        GetWindowTextW(GetDlgItem(hwnd, ID_EDIT_MENO), meno, 128);
        MessageBoxW(hwnd, meno, L"Ahoj!", MB_OK | MB_ICONINFORMATION);
        return 0;
    }
    break;
Používateľ klikne→WM_COMMAND→Kontrola ID→Prečítanie vstupu→Výsledok

5. Založenie projektu

  1. Vo VS Code vytvorte priečinok projektu a súbor main.cpp.
  2. Vložte úplnú kostru okna z hodiny 25. Do WM_CREATE vložte ukážku vytvorenia prvkov; do WM_COMMAND vložte ukážku obsluhy kliknutia. Doplňte include <windows.h> a konštanty ID v globálnom rozsahu.
  3. Vytváranie detí prebieha pri WM_CREATE; použitie WS_CHILD vyžaduje neprázdne rodičovské okno.
  4. Zostavte v Developer Command Prompt for VS 2022 (MSVC v143): cl /nologo /std:c++17 /EHsc /W4 /DUNICODE /D_UNICODE /Fe:formular.exe main.cpp /link /SUBSYSTEM:WINDOWS user32.lib
  5. Spustite formular.exe vo Windows a overte, že rodičovské okno obsahuje popis, textové pole a tlačidlo. Po kliknutí má spracovanie závisieť od ID tlačidla.

Platforma: tento Win32 kód potrebuje Windows SDK a spúšťa sa vo Windows. Zostavovací príkaz je pre MSVC; MinGW-w64 má odlišnú syntax a nie je týmto príkazom pokrytý. Použité funkcie okien a správ poskytuje User32.lib.

Pre učiteľa: orientačné odpovede a bodovanie
  1. Komponent je časť používateľského rozhrania; napríklad popis, textové pole, tlačidlo alebo výberový zoznam.
  2. Rodičovské okno obsahuje ovládacie prvky; podradený prvok je samostatné okno vložené do rodiča.
  3. ID jednoznačne identifikuje ovládací prvok, aby aplikácia vedela, odkiaľ prišla správa.
  4. WM_COMMAND; pri tlačidle kontrolujeme BN_CLICKED.
  5. Win32 kód potrebuje Windows hlavičky, knižnice a systém; štandardný online kompilátor beží v inom prostredí.

Odporúčanie: 1 bod za každú odpoveď. Pri praktickej úlohe možno hodnotiť návrh, správne triedy ovládacích prvkov, identifikátory a reakciu na kliknutie (4 body).

Podpora: pre žiakov, ktorí potrebujú pomoc, najprv spoločne označte rodiča a deti v náčrte. Potom priraďte triedy STATIC, EDIT a BUTTON; až nakoniec dopĺňajte číselné ID.

Interaktívna kontrola

Do ktorého parametra CreateWindowExW patrí handle hlavného okna, keď vytvárame podradené tlačidlo?

Vyberte odpoveď:

Zhrnutie: 6 poznatkov

  1. Formulár skladá hlavné okno a podradené ovládacie prvky.
  2. Popis, textové pole a tlačidlo sú štandardné triedy STATIC, EDIT a BUTTON.
  3. CreateWindowExW vytvorí prvok s určenou triedou, štýlom, rozmermi a rodičom.
  4. WS_CHILD označuje podradené okno a rodičovský handle mu určí kontajner.
  5. ID tlačidla umožní aplikácii rozlíšiť, ktorý prvok poslal oznámenie.
  6. Kliknutie tlačidla sa rodičovi oznamuje správou WM_COMMAND s kódom BN_CLICKED.

Poznámky a povinné vedomosti, ktoré si zapamätať z hodiny

  • Formulár Win32 tvorí hlavné rodičovské okno a podradené ovládacie prvky.
  • Štandardné triedy prvkov zahŕňajú STATIC, EDIT, BUTTON a COMBOBOX.
  • Podradený prvok vytvorím cez CreateWindowExW so štýlom WS_CHILD a handle rodiča.
  • Jedinečné ID ovládacieho prvku používam na rozpoznanie jeho oznámenia v WM_COMMAND.
  • Pri tlačidle overujem ID a kód oznámenia BN_CLICKED.
