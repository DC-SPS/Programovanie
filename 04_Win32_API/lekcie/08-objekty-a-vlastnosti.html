Práca s viacerými objektmi

Rovnaká trieda, samostatné inštancie a rozdielne hodnoty

4. ročník SPŠ · C++ príprava pre Win32

Väčšina užitočných programov pracuje s viacerými záznamami rovnakého typu. Dnes vytvoríme viac objektov triedy Student, porovnáme ich údaje a zistíme, ako zmena jednej inštancie ovplyvní ostatné.

Od jednotlivého objektu k malej evidencii
Začiatok hodiny: skontrolujte pracovisko a počítač; závadu ihneď oznám vyučujúcemu. Poškodené alebo nebezpečné zariadenie nepoužívajte. Stručný súhrn pošli cez EduPage podľa pokynov.

Ciele hodiny

Na konci hodiny dokážete:

  • vytvoriť viacero inštancií jednej triedy;
  • priradiť každej inštancii vlastný stav a vypísať ho;
  • predpovedať, ktorá hodnota sa zmení po priradení cez konkrétny objekt;
  • vysvetliť, prečo jedinečný identifikátor pomáha rozlíšiť záznamy.

Prepojenie a motivácia

V hodine 7 sme sledovali životný cyklus jedného lokálneho objektu. Evidencia študentov však potrebuje pracovať s celou skupinou. Každý študent má rovnaké druhy údajov, no ich hodnoty sú odlišné.

Model: tri objekty rovnakého typu

studentAid: 101 · Jana · IV.A
studentBid: 102 · Peter · IV.B
studentCid: 103 · Lucia · IV.A

Každý objekt má rovnaké atribúty z triedy Student, ale uchováva vlastné hodnoty. Názov premennej pred bodkou určuje, s ktorou inštanciou pracujeme.

Ukážka v C++17

#include <iostream>
#include <string>

class Student {
public:
    int id{};
    std::string meno;
    std::string trieda;
};

int main() {
    Student studentA{};
    studentA.id = 101;
    studentA.meno = "Jana Novakova";
    studentA.trieda = "IV.A";

    Student studentB{};
    studentB.id = 102;
    studentB.meno = "Peter Kral";
    studentB.trieda = "IV.B";

    studentA.trieda = "IV.B"; // menime iba studentA

    std::cout << studentA.id << ": " << studentA.meno
              << " - " << studentA.trieda << '\n';
    std::cout << studentB.id << ": " << studentB.meno
              << " - " << studentB.trieda << '\n';
}

Očakávaný výstup:

101: Jana Novakova - IV.B
102: Peter Kral - IV.B

Obe inštancie po zmene uvádzajú IV.B, ale z odlišných dôvodov: studentA sme zmenili, studentB malo túto hodnotu od začiatku. Priradenie studentA.trieda = ... neodkazuje na studentB.

Zostavenie a spustenie – MSVC

  1. Uložte kód ako viac_studentov.cpp.
  2. Otvorte Developer Command Prompt for VS 2022 a prejdite do priečinka súboru.
  3. Zostavte: cl /std:c++17 /EHsc /W4 /Fe:viac_studentov.exe viac_studentov.cpp.
  4. Spustite: viac_studentov.exe a porovnajte oba riadky.

Ide o konzolový príklad štandardného C++, nie Win32 program. Nepotrebuje Windows API ani samostatné systémové knižnice.

Jedinečný identifikátor

Dve osoby môžu mať rovnaké meno. Číselné id umožní aplikácii odlíšiť ich záznamy aj pri rovnakom texte mena.

  • Identifikátor patrí ku konkrétnemu objektu.
  • V rámci evidencie má byť jedinečný.
  • Ostatné atribúty opisujú ďalšie vlastnosti objektu.

Počet objektov a opakovanie kódu

Dnes vytvárame inštancie jednotlivo, aby bolo jasné, že každá má samostatný stav. Ak ich bude veľa, nechceme opakovať desiatky deklarácií; kolekcie preberieme neskôr, keď budú na ne pripravené potrebné C++ témy.

V tejto lekcii si zapamätaj hlavne model: veľa objektov môže pochádzať z jednej triedy.

Interaktívna kontrola

Po vytvorení dvoch inštancií vykonáme studentA.trieda = "IV.C";. Čo platí pre studentB.trieda, ak pred priradením mala hodnotu "IV.B"?

Vyberte odpoveď:

Praktická úloha: malá skupina

Cieľ: vytvoriť a porovnať tri samostatné objekty rovnakej triedy.

Predpoklady: trieda, atribúty, inicializácia, priradenie a výpis v C++.

  1. Použite triedu Student s atribútmi id, meno a trieda.
  2. Vytvorte tri inštancie s odlišnými ID a menami.
  3. Vypíšte ich záznamy po jednom.
  4. Zmeňte triedu iba druhému študentovi a overte, že ostatní sa nezmenili.
  5. Vysvetlite, prečo ID a meno plnia odlišnú úlohu.

Očakávaný výsledok: tri čitateľné záznamy a správne vysvetlená zmena iba jednej inštancie.

Kritériá (5 b): tri objekty (1), vlastné hodnoty (1), správny výpis (1), zmena jediného objektu (1), vysvetlenie ID (1).

  • Základná: vytvorte dva objekty podľa vzoru a zmeňte jeden údaj.
  • Rozširujúca: pridajte štvrtý objekt s rovnakým menom ako spolužiak, ale iným ID.
  • Náročnejšia: opíšte, ako by sa táto evidencia dala rozdeliť na skupiny podľa triedy bez straty identifikácie študentov.

Zhrnutie: 6 poznatkov

  1. Jedna trieda môže vytvoriť mnoho inštancií.
  2. Každá inštancia má vlastné hodnoty svojich atribútov.
  3. Člen vyberáme cez názov konkrétneho objektu a bodku.
  4. Zmena atribútu jedného objektu automaticky nemení druhý.
  5. Jedinečný identifikátor odlíši záznamy s rovnakým menom.
  6. Pri veľkom počte objektov sa neskôr oplatí použiť kolekciu.

Kontrolné otázky

  1. Môžu dve inštancie rovnakej triedy mať rôzne hodnoty?
  2. Ktorý objekt sa mení vo výraze studentA.trieda = "IV.C";?
  3. Prečo nie je meno vždy dostatočný identifikátor?
  4. Čo zlepšíme kolekciou pri veľkom počte objektov?
Učiteľská časť · odpovede, hodnotenie a podpora

Odpovede: áno; mení sa objekt studentA; mená sa môžu opakovať alebo meniť; kolekcia umožní zoskupiť a spracovať viac objektov bez opakovania samostatných premenných.

Interaktívna kontrola: správna je B. Nech žiak ukáže výraz pred bodkou a pomenuje inštanciu.

Hodnotenie: 5 bodov podľa kritérií úlohy. Pri záznamoch akceptuj rôzne realistické mená a triedy.

Podpora: používaj tabuľku, v ktorej každý riadok predstavuje objekt a každý stĺpec atribút. Pri zmene vyfarbi iba jednu bunku a prepoj ju s priradením v kóde.

Poznámky a povinné vedomosti, ktoré si zapamätáte z hodiny

  • Z jednej triedy môžem vytvoriť viac inštancií.
  • Každá inštancia uchováva svoje vlastné hodnoty atribútov.
  • Výraz s názvom objektu pred bodkou pracuje s vybranou inštanciou.
  • Identifikátor pomáha rozlíšiť záznamy s rovnakým menom.

Nadväznosť: hodina 9 sa začne témou metód a ukáže, ako objektom priradiť súvisiace operácie.
