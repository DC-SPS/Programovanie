Kurz Gitu · Prednáška 01

01 Úvod – v znamení verzovania kódu

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Vysvetlíte, prečo projekt potrebuje históriu verzií a aké problémy rieši verzovanie.

Teoretický základ a koncepty

Verzovanie zaznamenáva vývoj projektu tak, aby bolo možné zistiť, čo sa zmenilo, kedy a prečo. Záložné kópie pomenované „final2“ sú krehké: neukazujú rozdiely ani spoľahlivo nespoja prácu viacerých ľudí. Git vytvára pomenované commity a umožňuje porovnávať či obnovovať stav projektu.

Praktické príkazy

ÚčelPríkaz
Začnite históriu v existujúcom priečinku
git init
Pozrite zmeny
git status
Zobrazte históriu
git log --oneline --decorate

Samostatná úloha

Vytvorte súbor poznamky.txt, uložte prvú verziu a potom zmeňte jednu vetu. Porovnajte stav pred a po uložení ďalšieho commitu.
