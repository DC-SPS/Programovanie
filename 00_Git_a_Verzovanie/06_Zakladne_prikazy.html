06 Základné príkazy – init, add, commit

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Vytvoríte lokálny repozitár a zaznamenáte prvý commit.

Teoretický základ a koncepty

`git init` vytvorí skrytý priečinok `.git` s metadátami. `git add` vyberá obsah do staging area. `git commit` vytvorí trvalý bod v histórii z pripravených zmien. Commit spravidla obsahuje jednu logickú zmenu a stručnú správu v rozkazovacom spôsobe.

Praktické príkazy

ÚčelPríkaz
Vytvorte priečinok a repozitár
mkdir moj-projekt
cd moj-projekt
git init
Skontrolujte stav
git status
Pripravte súbor
git add README.md
Uložte zmenu
git commit -m "Pridaj README"
Overte commit
git log --oneline

Samostatná úloha

Vytvorte README.md s názvom projektu, inicializujte Git, pridajte súbor a uložte prvý commit. Potom doplňte druhý odsek do samostatného commitu.
