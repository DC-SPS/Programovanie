17 git log a história

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Prehľadáte históriu, zobrazíte rozdiely a zistíte pôvod zmien.

Teoretický základ a koncepty

Každý commit má identifikátor, rodičov, autora, čas a snapshot stromu projektu. `git log` umožňuje históriu filtrovať podľa vetvy, autora, času a cesty. `git show` zobrazí obsah commitu; `git blame` ukáže poslednú zmenu jednotlivých riadkov, nie nevyhnutne osobu zodpovednú za celú funkciu.

Praktické príkazy

ÚčelPríkaz
Stručná história všetkých vetiev
git log --oneline --graph --decorate --all
Zobrazte konkrétny commit
git show HEAD
História súboru
git log --oneline -- README.md
Zmeny konkrétneho autora
git log --author="Meno" --oneline
Pôvod riadkov
git blame README.md

Samostatná úloha

Vyhľadajte commit, ktorý zmenil zvolený súbor, a zobrazte jeho diff. Pomocou `git log -- path` obmedzte históriu na daný súbor.
