Kurz Gitu · Prednáška 19

19 README.md a Markdown

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Napíšete čitateľný README s návodom, požiadavkami, použitím a licenciou.

Teoretický základ a koncepty

README predstavuje projekt a často sa zobrazuje na úvodnej stránke repozitára. Markdown používa nadpisy, odkazy, zoznamy, obrázky a kódové bloky. Návod má uvádzať potrebné nástroje a konkrétne príkazy; tajné údaje do README nepatria.

Praktické príkazy

ÚčelPríkaz
Vytvorte súbor
New-Item README.md
Zobrazte zmenu
git diff -- README.md
Pripravte a commitnite dokumentáciu
git add README.md
git commit -m "Doplň README projektu"

Samostatná úloha

Napíšte README s názvom, účelom, požiadavkami, krokmi inštalácie a spustenia, príkladom použitia a odkazom na licenciu.
