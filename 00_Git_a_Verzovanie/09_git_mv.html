Kurz Gitu · Prednáška 09

09 git mv

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Premenujete alebo presuniete sledovaný súbor a uložíte zmenu.

Teoretický základ a koncepty

`git mv` presunie súbor a pripraví zmenu na commit. Git ukladá snapshoty, nie samostatný záznam „premenovanie“; pri porovnávaní Git zvyčajne rozpozná presun podľa podobnosti obsahu. Rovnaký výsledok dosiahnete presunom v správcovi súborov a následným `git add` a odstránením pôvodnej cesty.

Praktické príkazy

ÚčelPríkaz
Premenujte súbor
git mv stary-nazov.txt novy-nazov.txt
Skontrolujte pripravené zmeny
git status
Zobrazte zmenu názvu
git diff --staged --summary
Uložte zmenu
git commit -m "Premenuj dokumentáciu"

Samostatná úloha

Premenujte súbor v repozitári cez `git mv`, skontrolujte stav a vytvorte commit. Porovnajte s manuálnym presunom a `git add -A`.
