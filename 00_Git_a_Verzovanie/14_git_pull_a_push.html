Kurz Gitu · Prednáška 14

14 git pull a git push

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Bezpečne prijmete vzdialené zmeny a odošlete svoje commity na server.

Teoretický základ a koncepty

`git push` posiela lokálne commity do vzdialeného repozitára. `git pull` najprv fetchnutím získa zmeny a potom ich integruje (merge alebo rebase podľa nastavenia). Pred pushom si overte vetvu a remote; pri odmietnutom push najprv stiahnite a integrujte vzdialené zmeny.

Praktické príkazy

ÚčelPríkaz
Prvý push vetvy a nastavenie upstreamu
git push -u origin main
Ďalší push
git push
Aktualizácia s fast-forward merge
git pull --ff-only
Stiahnite bez integrácie
git fetch origin

Samostatná úloha

Dve pracovné kópie toho istého repozitára upravte nezávisle. Z prvej pushnite zmenu, v druhej použite pull, vytvorte ďalší commit a pushnite ho.
