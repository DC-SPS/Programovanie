Kurz Gitu · Prednáška 12

12 Čo je to GitHub

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Vysvetlíte vzťah medzi lokálnym Gitom, GitHubom, remote a autentifikáciou SSH.

Teoretický základ a koncepty

GitHub je hosting a kolaboračná platforma pre Git repozitáre. `origin` je bežný názov remote, nie špeciálne kľúčové slovo. SSH kľúč umožňuje autentifikáciu bez zadávania hesla pri každom príkaze; privátny kľúč nikdy nezdieľajte ani neukladajte do repozitára.

Praktické príkazy

ÚčelPríkaz
Skontrolujte remote
git remote -v
Pridajte remote
git remote add origin git@github.com:uzivatel/projekt.git
Vygenerujte SSH kľúč (Ed25519)
ssh-keygen -t ed25519 -C "vy@example.com"
Otestujte pripojenie
ssh -T git@github.com

Samostatná úloha

Vytvorte na GitHube prázdny repozitár bez generovaného README a prepojte ho s lokálnym projektom. Do účtu vložte iba obsah verejného kľúča `.pub`.
