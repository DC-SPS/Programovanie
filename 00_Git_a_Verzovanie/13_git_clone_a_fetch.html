13 git clone a git fetch

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Naklonujete repozitár a stiahnete nové vzdialené commity bez ich automatického zlúčenia.

Teoretický základ a koncepty

`git clone` vytvorí lokálnu pracovnú kópiu repozitára vrátane histórie a nastaví remote. `git fetch` aktualizuje vzdialené sledovacie vetvy, napríklad `origin/main`, ale nemení vašu aktuálnu vetvu ani pracovné súbory. Po fetchnutí môžete rozdiely skontrolovať a rozhodnúť o zlúčení.

Praktické príkazy

ÚčelPríkaz
Naklonujte repozitár
git clone https://github.com/uzivatel/projekt.git
Stiahnite informácie zo všetkých remote vetiev
git fetch --all
Zobrazte lokálne a vzdialené vetvy
git branch -a
Porovnajte vetvy
git log --oneline HEAD..origin/main

Samostatná úloha

Naklonujte školský repozitár. Po vytvorení nového commitu na serveri spustite `git fetch` a pozrite si rozdiel oproti `origin/main`.
