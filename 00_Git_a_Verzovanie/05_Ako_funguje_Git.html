Kurz Gitu · Prednáška 05

05 Ako funguje Git

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Opíšete rozdiel medzi pracovným stromom, staging area, lokálnym repozitárom a remote.

Teoretický základ a koncepty

`git status` porovnáva pracovné súbory, staging a posledný commit. `git add` uloží do stagingu aktuálny obsah vybraných súborov. Commit zaznamená pripravený snapshot. Remote je pomenovaná adresa iného repozitára; `fetch` prinesie jeho objekty a odkazy bez automatickej zmeny pracovných súborov.

Praktické príkazy

ÚčelPríkaz
Pracovný strom oproti stagingu
git diff
Staging oproti poslednému commitu
git diff --staged
Pripravte zmenu
git add nazov-suboru
Zobrazte remote
git remote -v
Zobrazte stav
git status

Samostatná úloha

Upravte dva súbory, pridajte iba jeden pomocou `git add`. Pomocou `git diff` a `git diff --staged` ukážte, v ktorej zóne je každá zmena.
