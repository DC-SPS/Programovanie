Kurz Gitu · Prednáška 16

16 Súbor .gitignore

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Nastavíte ignorovanie dočasných súborov a bezpečne ošetríte už sledovaný obsah.

Teoretický základ a koncepty

`.gitignore` obsahuje vzory ciest, ktoré Git nemá ponúkať ako nesledované zmeny. Typicky ignoruje build výstupy, cache a lokálne nastavenia. Ignorovanie neplatí spätne pre súbor, ktorý už Git sleduje; citlivý súbor odstráňte z indexu a prípadne okamžite vymeňte uniknutý kľúč.

Praktické príkazy

ÚčelPríkaz
Ukážka pravidiel
.env
*.log
/build/
!build/README.md
Zistite, ktoré pravidlo ignoruje cestu
git check-ignore -v .env
Odstráňte sledovaný súbor iba z indexu
git rm --cached .env

Samostatná úloha

Pridajte `.gitignore` pre logy a priečinok build. Overte ho cez `git check-ignore -v`. Nevkladajte do cvičenia reálne heslo alebo token.
