Kurz Gitu

Git zaznamenáva históriu zmien v projekte. Prejdite si najprv stručný ťahák a potom lekcie z video playlistu.

Náplň kurzu

  • Čo je Git a aký je rozdiel oproti vzdialenému repozitáru (GitHub).
  • Základný cyklus: git status, git add, git commit, git log.
  • Vetvy (branching) a zlučovanie zmien (merging).
  • Riešenie merge konfliktov.
  • Súbor .gitignore na ignorovanie dočasných súborov.

Ťahák príkazov Gitu

Otvoriť úplný ťahák príkazov od autora kurzu

Skontrolujte stav a históriu

git status
git log --oneline

Pripravte zmeny a vytvorte commit

git add nazov-suboru
git commit -m "Popis zmeny"

Vytvorte a prepnite sa na vetvu

git switch -c nova-vetva
git branch

Pracujte so vzdialeným repozitárom

git remote -v
git pull
git push

Nastavte meno a e-mail pre commity

git config --global user.name "Vaše meno"
git config --global user.email "ty@example.com"

Pozor: príkazy ako git reset --hard môžu natrvalo odstrániť neuložené zmeny. Používajte ich iba vtedy, keď presne viete, čo robia.
