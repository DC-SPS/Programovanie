Kurz Gitu · Prednáška 07

07 Commity a Vim

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Napíšete zrozumiteľnú správu commitu a bezpečne opustíte editor Vim.

Teoretický základ a koncepty

Ak spustíte `git commit` bez `-m`, Git otvorí predvolený textový editor. Vime napíšete správu po stlačení `i` (insert), uložíte a ukončíte cez `Esc`, `:wq`, Enter. Zrušenie editácie: `Esc`, `:q!`, Enter. Editor možno zmeniť na VS Code.

Praktické príkazy

ÚčelPríkaz
Commit so správou
git commit -m "Oprav výpočet ceny"
Nastavte VS Code ako editor
git config --global core.editor "code --wait"
Otvorenie editora pre commit
git commit

Samostatná úloha

Vykonajte skúšobný commit bez `-m`. Ak sa otvorí Vim, napíšte správu postupom i → text → Esc → :wq → Enter. V prípade potreby použite `:q!` na odchod bez uloženia.
