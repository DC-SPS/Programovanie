Kurz Gitu · Prednáška 11

11 git merge

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Zlúčite dokončenú vetvu do cieľovej vetvy a overíte výsledok.

Teoretický základ a koncepty

Merge spojí históriu dvoch vetiev. Najprv sa prepnite na vetvu, ktorá má zmenu prijať; potom zlučte zdrojovú vetvu. Git môže vytvoriť fast-forward alebo merge commit. Zlučovanie môže zlyhať, ak sú súbory v konflikte; vtedy treba konflikt vyriešiť a merge dokončiť.

Praktické príkazy

ÚčelPríkaz
Prepnite sa na cieľovú vetvu
git switch main
Zlúčte zmenu
git merge nova-funkcia
Skontrolujte históriu
git log --oneline --graph --decorate --all
Odstráňte zlúčenú vetvu
git branch -d nova-funkcia

Samostatná úloha

Vytvorte vetvu, urobte v nej commit a zlúčte ju do main. V grafe histórie ukážte, ktoré commity sú v oboch vetvách.
