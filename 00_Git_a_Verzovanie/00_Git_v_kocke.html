Kurz Gitu · Prednáška 00

00 Git v kocke

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Pochopíte, ako zmena prejde z pracovného priečinka do commitu a následne na GitHub.

Teoretický základ a koncepty

Git sleduje obsah súborov. Working Directory je priečinok, v ktorom pracujete; Staging Area je výber zmien pre nasledujúci commit; Local Repository uchováva commity a vetvy; Remote Repository je vzdialená kópia, napríklad na GitHube.

Vizuálna schéma toku dát

Working Directory          Staging Area          Local Repository          Remote Repository
(pracovné súbory)          (výber zmien)          (commity a vetvy)          (GitHub)
      │                         │                        │                       │
      ├──── git add ───────────>│                        │                       │
      │                         ├──── git commit ───────>│                       │
      │                         │                        ├──── git push ────────>│
      │                         │                        │<──── git fetch/pull ──┤

Samostatná úloha

Vytvorte súbor, skontrolujte stav, pridajte ho do staging area a uložte commit. Potom si v logu overte, že commit existuje.
