Kurz Gitu · Prednáška 02

02 Čo je to Git

Informatika s Mišom · verzovanie kódu

Cieľ prednášky

Rozlíšite Git, systém správy verzií a hostingovú službu GitHub.

Teoretický základ a koncepty

Git je distribuovaný systém správy verzií. Každý klon repozitára obsahuje históriu a môže vytvárať commity aj bez siete. GitHub je služba, ktorá hostí vzdialené Git repozitáre a pridáva spoluprácu cez pull requesty, issues a oprávnenia. Git funguje aj bez GitHubu.

Praktické príkazy

ÚčelPríkaz
Zistite verziu Gitu
git --version
Zobrazte nastavenia
git config --list --show-origin
Vytvorte lokálny repozitár
git init

Samostatná úloha

Bez pripojenia na internet inicializujte repozitár a vytvorte commit. Vysvetlite, prečo na tento krok GitHub netreba.
