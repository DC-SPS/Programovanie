Jednodoskové počítače a ich operačný systém · 45 minút

1. Čo porovnávame?

0 – 5 min

MCU – Microcontroller Unit – je mikrokontrolér.

SBC je celá doska počítača. MCU je druh integrovaného obvodu, ktorý môže byť súčasťou vývojovej dosky.

V praxi porovnávame napríklad:

  • Arduino Uno s ATmega328P,
  • vývojovú dosku ESP32,
  • Raspberry Pi s Linuxom.

Raspberry Pi Pico je doska s mikrokontrolérom, nie rovnaká kategória zariadenia ako Raspberry Pi 4 alebo Pi 5.

Rozhodujú požiadavky projektu.

3. Časovanie a prevádzka

17 – 27 min

MCU

Hardvérové časovače a periférie umožňujú presné meranie alebo generovanie impulzov.

Program môže byť jednoduchý a mať dobre analyzovateľné časovanie.

SBC s Linuxom

Procesor môže byť rýchly, ale používateľský program zdieľa systém s inými procesmi.

Reakciu ovplyvňujú:

  • plánovanie,
  • ovládače,
  • systémová záťaž,
  • vstupno-výstupné operácie.

Vyššia frekvencia CPU nezaručuje menšie najhoršie oneskorenie.

Spotreba

MCU môže medzi meraniami spať a prebúdzať sa prerušením.

SBC musí pri bežnej prevádzke napájať zložitejší systém. Úsporné možnosti závisia od konkrétnej platformy.

4. Spoločné použitie

27 – 35 min

Príklad automatizovaného skleníka:

Snímače a akčné členy
          ↓
MCU: meranie a lokálna regulácia
          ↕
UART, USB alebo iné rozhranie
          ↕
SBC: databáza, web a vizualizácia

Výhody:

  • MCU zabezpečuje lokálne riadenie,
  • SBC spracúva históriu a používateľské rozhranie,
  • základné riadenie môže pokračovať aj pri reštarte SBC.

Musíme určiť, čo sa stane pri výpadku komunikácie a aké elektrické rozhranie použijeme.

6. Zápis

41 – 45 min

MCU integruje procesor, pamäť a periférie pre riadiace úlohy.

SBC je počítač na jednej doske, často s Linuxom.

MCU býva vhodný pre úsporné a časovo predvídateľné riadenie.

SBC býva vhodný pre sieťové služby, súbory a náročnejšie spracovanie.

Obe platformy môžu v jednom zariadení spolupracovať.

Zdroje na ďalšie štúdium

  • Raspberry Pi OS a Imager
  • Raspberry Pi – hardvér a GPIO
  • GPIO Zero – vstupné zariadenia
  • GPIO Zero – výstupné zariadenia
  • Linux GPIO character device API
  • Zastarané Linux sysfs GPIO API
  • systemd systemctl
  • Raspberry Pi – vzdialený prístup a SSH
