9.8 Spracovanie a ukladanie dát

IoT – architektúra, komunikácia a bezpečnosť · 45 minút

Praktické prostredie: Ukážky Wi-Fi na ESP32 možno spustiť v online simulátore. Príkazy pre broker a Raspberry Pi určené na lokálnu laboratórnu sieť spúšťajte len na zariadeniach, na ktoré máte oprávnenie. V príkladoch nepoužívajte skutočné heslá ani tokeny.

Ciele hodiny

Žiak má vedieť:

  • navrhnúť štruktúru merania,
  • vysvetliť validáciu údajov,
  • rozlíšiť CSV a databázu,
  • uložiť jednoduché meranie do SQLite,
  • rozpoznať chýbajúce údaje a duplicity.

1. Správa nie je história

0 – 5 min

Prenos protokolom ešte neznamená trvalé uloženie.

Typický reťazec:

Platforma: text

Príjem → dekódovanie → validácia → uloženie → analýza

Každý krok môže zlyhať a musí mať definovanú reakciu.

2. Čo má obsahovať záznam?

5 – 16 min

PoleÚloha
device_idIdentita zariadenia
measurement_idRozlíšenie záznamov a duplicít
measured_atČas vzniku merania, ak je známy
received_atČas prijatia
valueHodnota

qualityPlatnosť alebo kvalita

Čas vzniku a čas prijatia sa môžu líšiť, najmä po výpadku siete.

Používame jednoznačný časový formát a časové pásmo, napríklad UTC.

Validácia

Overujeme:

  • či správa obsahuje potrebné polia,
  • či sú typy správne,
  • či je hodnota konečná,
  • či je v prípustnom rozsahu,
  • či je známa jednotka,
  • či záznam nie je duplicitný.

Chýbajúcu teplotu nenahrádzame automaticky nulou. Nula môže byť platné meranie.

4. Praktická ukážka

25 – 36 min

Python má modul sqlite3 v štandardnej knižnici.

Platforma: python

import math
import sqlite3
from datetime import datetime, timezone

device_id = "ucebna01"
teplota = 23.6

if not math.isfinite(teplota):
    raise ValueError("Hodnota nie je konecna")

# Laboratórny rozsah pre toto konkrétne zadanie.
if not -20.0 <= teplota <= 60.0:
    raise ValueError("Hodnota mimo povoleneho rozsahu")

cas_prijatia = datetime.now(timezone.utc).isoformat()

spojenie = sqlite3.connect("merania.db")

try:
    with spojenie:
        spojenie.execute("""
            CREATE TABLE IF NOT EXISTS merania (
                id INTEGER PRIMARY KEY,
                received_at TEXT NOT NULL,
                device_id TEXT NOT NULL,
                temperature_c REAL NOT NULL
            )
        """)

        spojenie.execute("""
            INSERT INTO merania (
                received_at,
                device_id,
                temperature_c
            )
            VALUES (?, ?, ?)
        """, (cas_prijatia, device_id, teplota))

    riadky = spojenie.execute("""
        SELECT received_at, device_id, temperature_c
        FROM merania
        ORDER BY id DESC
        LIMIT 5
    """).fetchall()

    for riadok in riadky:
        print(riadok)

finally:
    spojenie.close()
Dokumentácia Raspberry Pi

Čo vysvetliť

  • CREATE TABLE vytvára tabuľku.
  • INSERT ukladá záznam.
  • SELECT číta údaje.
  • Parametre ? oddeľujú údaje od SQL príkazu.
  • Transakcia pomáha zabezpečiť ucelený zápis.
  • Čas v tejto ukážke je čas prijatia, nie čas zo snímača.

5. Agregácia a kvalita

36 – 41 min

Z množstva vzoriek môžeme vytvoriť:

  • priemer za minútu,
  • minimum a maximum,
  • počet platných meraní,
  • informáciu o výpadkoch.

Priemer bez počtu vzoriek môže byť zavádzajúci. Minúta s jedným meraním nie je rovnaká ako minúta so šesťdesiatimi.

Pri plánovaní úložiska riešime:

  • dobu uchovávania,
  • zálohovanie,
  • obnovu,
  • množstvo zápisov na médium.

6. Zápis

41 – 45 min

Prijaté údaje najprv dekódujeme a validujeme.

Záznam má obsahovať identitu, hodnotu, jednotku a časové informácie.

Chýbajúci údaj nie je automaticky nula.

CSV je jednoduchý formát, databáza umožňuje štruktúrované vyhľadávanie.

Duplicity, výpadky a zálohovanie sú súčasťou návrhu.
