8.3 Linux v embedded systémoch

Jednodoskové počítače a ich operačný systém · 45 minút

Platforma: Príkazy a príklady Python GPIO Zero sú určené pre Raspberry Pi s Raspberry Pi OS. Wokwi Raspberry Pi Pico simuluje mikrokontrolér Pico, nie Linuxový SBC; príkazy a GPIO Zero ukážky sa v ňom nespustia. GPIO používa 3,3 V; na piny nepripájajte 5 V.

8.3 Linux v embedded systémoch

Ciele hodiny

Žiak má vedieť:

  • rozlíšiť jadro Linuxu a distribúciu,
  • vysvetliť úlohu shellu,
  • použiť základné diagnostické príkazy,
  • vysvetliť význam používateľských oprávnení,
  • uviesť výhody a obmedzenia embedded Linuxu.

1. Linux a distribúcia

0 – 5 min

Linux je jadro operačného systému.

Distribúcia spája jadro s ďalšími nástrojmi, knižnicami a aplikáciami.

Príklady:

  • Raspberry Pi OS,
  • Debian,
  • Ubuntu.

2. Jadro a používateľský priestor

5 – 15 min

Aplikácie a služby
        ↓
Knižnice a systémové volania
        ↓
Jadro Linuxu a ovládače
        ↓
Hardvér

Jadro zabezpečuje napríklad:

  • plánovanie procesov,
  • správu pamäte,
  • prístup k zariadeniam,
  • sieťovú komunikáciu,
  • súborové systémy.

Aplikácie bežia v používateľskom priestore a k chráneným funkciám pristupujú cez systémové rozhrania.

Shell

Shell interpretuje príkazy používateľa. Bežným príkladom je Bash.

Terminál je prostredie, cez ktoré so shellom komunikujeme.

Žiaci zistia:

  1. názov počítača,
  2. používateľské meno,
  3. distribúciu,
  4. kapacitu RAM,
  5. voľné miesto na koreňovom súborovom systéme.

Otázka: Ukazuje df -h voľnú RAM?

Odpoveď: Nie. Na RAM použijeme napríklad free -h.

4. Oprávnenia a balíky

28 – 35 min

Bežný používateľ nemá meniť všetky systémové súbory.

sudo umožňuje oprávnenému používateľovi vykonať konkrétny príkaz s vyššími právami.

Nepoužívame sudo automaticky pri každom príkaze.

Na systémoch založených na Debiane:

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

sudo apt update

aktualizuje zoznam dostupných balíkov.

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

sudo apt upgrade

vykonáva aktualizácie nainštalovaných balíkov podľa pravidiel správcu balíkov.

Tieto operácie menia systém a počas výučby ich vykonávame podľa pokynov učiteľa.

5. Embedded Linux

35 – 41 min

Výhody:

  • ovládače,
  • sieťové služby,
  • súborové systémy,
  • množstvo vývojových nástrojov,
  • vzdialená správa.

Obmedzenia:

  • vyššie pamäťové nároky,
  • dlhší štart,
  • potreba aktualizácií,
  • zložitejšia správa,
  • bežná konfigurácia negarantuje tvrdé real-time požiadavky.

Minimalizované embedded systémy sa môžu zostavovať napríklad pomocou Buildroot alebo Yocto Project. Na úvod postačuje práca s hotovou distribúciou.

6. Zápis

41 – 45 min

Linux je jadro, distribúcia obsahuje aj ďalší softvér.

Shell umožňuje zadávať a vykonávať príkazy.

Jadro spravuje procesy, pamäť a zariadenia.

Vyššie oprávnenia používame iba na potrebné operácie.

Embedded Linux poskytuje rozsiahle služby, ale vyžaduje správu a dostatočné prostriedky.

Zdroje na ďalšie štúdium

  • Raspberry Pi OS a Imager
  • Raspberry Pi – hardvér a GPIO
  • GPIO Zero – vstupné zariadenia
  • GPIO Zero – výstupné zariadenia
  • Linux GPIO character device API
  • Zastarané Linux sysfs GPIO API
  • systemd systemctl
  • Raspberry Pi – vzdialený prístup a SSH
