2.4 Architektonické prístupy – RISC, CISC a ARM

Architektúra mikrokontroléra · 45 minút

Trvanie: 45 minút Nadväznosť: Inštrukčný cyklus a vnútorná stavba CPU.

Ciele hodiny

Žiak má vedieť:

  • vysvetliť pojem inštrukčná sada,
  • orientačne porovnať RISC a CISC,
  • rozlíšiť ISA a mikroarchitektúru,
  • správne zaradiť ARM, AVR, x86 a RISC-V,
  • vysvetliť, prečo samotné označenie RISC alebo CISC neurčuje výkon.

1. Inštrukčná sada

0 – 5 min

ISA – Instruction Set Architecture – opisuje programátorovi viditeľné vlastnosti procesora.

Zahŕňa napríklad:

  • inštrukcie a ich kódovanie,
  • registre,
  • dátové typy,
  • spôsoby adresovania,
  • pravidlá vykonávania.

Program pre jednu ISA nemožno všeobecne priamo spustiť na inej ISA.

Zdrojový program sa však môže preložiť pre viac platforiem, ak používa podporované a prenositeľné rozhrania.

2. RISC a CISC

5 – 17 min

RISC

Reduced Instruction Set Computer

Historicky kladie dôraz napríklad na:

  • pravidelnejšie inštrukcie,
  • veľa operácií nad registrami,
  • jednoduchšie spôsoby adresovania,
  • efektívnu realizáciu pipeline.

Mnohé RISC architektúry používajú princíp load/store:

  • osobitné inštrukcie prenášajú údaje medzi pamäťou a registrami,
  • aritmetika pracuje prevažne s registrami.

CISC

Complex Instruction Set Computer

Historicky sa spája napríklad s:

  • bohatšími spôsobmi adresovania,
  • zložitejšími inštrukciami,
  • často premenlivou dĺžkou inštrukcií.

Jedna inštrukcia môže vykonať viac činností.

Orientačné porovnanie

VlastnosťTypické RISC smerovanieTypické CISC smerovanie
Práca s operandmiDôraz na registreViac možností práce s pamäťou

PríkladyARM, RISC-V, AVRx86

Ide o orientačné charakteristiky, nie pravidlá platné bez výnimky.

RISC neznamená, že každá inštrukcia trvá jeden cyklus. CISC neznamená automaticky pomalý procesor.

3. ISA a mikroarchitektúra

17 – 26 min

ISA

Určuje, čo procesor navonok poskytuje programu.

Mikroarchitektúra

Určuje, ako je konkrétny procesor vnútorne realizovaný.

Môže zahŕňať:

  • pipeline,
  • cache,
  • výkonné jednotky,
  • predikciu skokov,
  • vykonávanie mimo poradia,
  • počet jadier.

Dva procesory môžu podporovať rovnakú ISA, ale mať výrazne odlišný výkon, spotrebu a časovanie.

Moderné procesory

Hranica RISC/CISC je menej ostrá než v jednoduchých učebnicových modeloch.

Napríklad moderné x86 procesory často interne rozkladajú inštrukcie na menšie mikrooperácie.

Výkon závisí aj od:

  • pamäte,
  • frekvencie,
  • kompilátora,
  • konkrétneho programu,
  • počtu jadier,
  • tepelných a energetických obmedzení.

4. Konkrétne rodiny

26 – 36 min

AVR

  • Rodina mikrokontrolérov s RISC architektúrou.
  • ATmega328P je 8-bitový AVR.
  • Používa sa na Arduino Uno R3.

Označenie 8-bitový neznamená, že nedokáže počítať so 16-bitovým číslom. Taký výpočet môže vyžadovať viac krokov.

ARM

ARM nie je tretia protikladná kategória k RISC a CISC. Označuje architektúry a súvisiace procesorové technológie s RISC pôvodom.

ProfilTypické zameranie
Cortex-MMikrokontroléry
Cortex-RČasovo náročné riadenie
Cortex-AAplikačné procesory, často s OS

Nie všetky jadrá v danom profile majú rovnaké funkcie.

Raspberry Pi 4 a Pi 5 používajú aplikačné procesory ARM. Raspberry Pi Pico používa mikrokontrolér; konkrétna architektúra závisí od modelu.

x86

Rodina ISA používaná najmä v mnohých osobných počítačoch a serveroch. Tradične sa zaraďuje medzi CISC.

RISC-V

Otvorená rodina špecifikácií ISA. Existujú rôzne základné varianty a rozšírenia.

Otvorenosť ISA neznamená, že každý čip alebo jeho implementácia musí byť otvorený hardvér.

ESP32

Rodina ESP32 používa podľa variantu rozdielne procesorové architektúry:

  • pôvodný ESP32: Xtensa,
  • ESP32-S3: Xtensa,
  • ESP32-C3 a ESP32-C6: RISC-V.

ESP32 preto nemožno všeobecne označiť ako ARM.

6. Overenie a zápis

41 – 45 min

ISA definuje inštrukcie a ďalšie programátorovi viditeľné vlastnosti procesora.

Mikroarchitektúra opisuje konkrétnu vnútornú realizáciu.

RISC a CISC sú architektonické prístupy s historicky odlišným zameraním.

ARM patrí k architektúram s RISC pôvodom.

AVR, ARM, x86, Xtensa a RISC-V nie sú navzájom zameniteľné ISA.

Výkon neurčuje iba frekvencia alebo označenie RISC/CISC.

Praktická ukážka: čítanie vstupu a riadenie LED

Úplný program skopírujte do online simulátora Arduino Uno. Simulátor predstavuje mikrokontrolér ATmega328P a umožňuje sledovať vykonávanie programu. Zapojte tlačidlo medzi pin 2 a GND.

Otvoriť online simulátor Arduino Uno (Wokwi)
const byte LED_PIN = LED_BUILTIN;
const byte BUTTON_PIN = 2;

void setup() {
    pinMode(LED_PIN, OUTPUT);
    pinMode(BUTTON_PIN, INPUT_PULLUP);
}

void loop() {
    const bool buttonPressed = digitalRead(BUTTON_PIN) == LOW;
    digitalWrite(LED_PIN, buttonPressed ? HIGH : LOW);
}
