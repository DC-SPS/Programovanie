5.5 PWM – princíp činnosti

Analógové a výkonové periférie · 45 minút

Bezpečnosť: Pri praktických ukážkach používajte iba nízke napätia. Motory, výkonové LED ani iné výkonové záťaže nepripájajte priamo na GPIO; použite vhodný výkonový ovládač. Každá prednáška je určená na 45 minút pre 3. ročník strednej školy.

Trvanie: 45 minút
Nadväznosť: Digitálny signál, časovače a DAC.

Ciele hodiny

Žiak má vedieť:

  • vysvetliť princíp PWM,
  • vypočítať striedu a frekvenciu,
  • nastaviť jas LED pomocou PWM,
  • rozlíšiť priemerné napätie a okamžitý priebeh,
  • opísať ovládanie výkonovej záťaže cez budič.

1. Čo je PWM?

0 – 5 min

PWM – Pulse Width Modulation – je impulzno-šírková modulácia.

V bežnom PWM s pevnou periódou meníme čas, počas ktorého je signál v aktívnom stave.

Výstup prepína medzi dvoma úrovňami. Mení sa šírka impulzu.

Použitie:

  • regulácia jasu LED,
  • riadenie motorov,
  • riadenie výkonových meničov,
  • vytvorenie filtrovaného riadiaceho napätia.

2. Perióda a strieda

5 – 16 min

T = t_\text{ON} + t_\text{OFF}
f = \frac{1}{T}
D = \frac{t_\text{ON}}{T}

Striedu D vyjadrujeme aj v percentách.

Príklad

  • perióda 2 ms,
  • čas zapnutia 0,5 ms.
f = \frac{1}{0{,}002} = 500\ \text{Hz}
D = \frac{0{,}5}{2} = 0{,}25 = 25\%

Priemerné napätie

Pre ideálny signál prepínajúci medzi 0 V a U_H:

U_\text{priemer} = D \cdot U_H

Pri 5 V a striede 25 %:

U_\text{priemer} = 1{,}25\ \text{V}

Na pine však stále striedavo meriame približne 0 V a 5 V. Priemer nie je totožný s okamžitým napätím.

Účinok na záťaž závisí od jej vlastností. Výkon nemožno vo všetkých prípadoch vypočítať jednoduchým dosadením priemerného napätia do vzorca pre jednosmerné napájanie.

3. Arduino Uno: jas LED

16 – 28 min

Zapojenie

  • D9 → rezistor 680 Ω → anóda LED,
  • katóda LED → GND,
  • potenciometer 10 kΩ medzi 5 V a GND,
  • jazdec potenciometra → A0.
Otvoriť Wokwi Arduino Uno

const byte LED = 9;
const byte POTENCIOMETER = A0;

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  int vstup = analogRead(POTENCIOMETER);

  int pwm = vstup / 4;

  analogWrite(LED, pwm);
}

Vysvetlenie

Na Uno:

  • analogRead() vracia bežne 0 až 1023,
  • analogWrite() používa bežne 0 až 255,
  • delením štyrmi získame vhodný rozsah.

PWM podporujú piny Uno R3:

3, 5, 6, 9, 10 a 11.

Frekvencia závisí od pinu a nastavenia časovača. Bežne je približne 490 Hz alebo 980 Hz.

Vnímanie jasu

Dvojnásobná strieda nemusí vyzerať ako dvojnásobný jas. Ľudské vnímanie nie je lineárne.

Súvis s časovačmi

PWM vytvára hardvérový časovač. Program nemusí každý impulz ručne zapínať a vypínať.

Zmena konfigurácie časovača môže ovplyvniť iné funkcie a knižnice.

4. Výkonové riadenie

28 – 35 min

GPIO neposkytuje prúd potrebný pre motor alebo výkonový LED pás.

Typický princíp:

GPIO s PWM → budič alebo vhodný tranzistor → záťaž

Pre jednosmerný motor môžeme použiť vhodný MOSFET alebo motorový ovládač.

Treba riešiť:

  • napätie a prúd záťaže,
  • vhodné budenie tranzistora,
  • ochranu pri indukčnej záťaži,
  • napájanie a spoločnú referenciu, ak nie je obvod izolovaný.

Výber frekvencie

  • Príliš nízka frekvencia môže spôsobiť viditeľné blikanie LED.
  • Pri motore môže vzniknúť počuteľný zvuk.
  • Vyššia frekvencia zvyšuje nároky na spínanie a môže zvýšiť straty.

PWM ako približný analógový výstup

PWM → dolnopriepustný filter → vyhladené napätie

Filter zmenšuje zvlnenie, ale spomaľuje reakciu na zmenu striedy.

5. ESP32 a Raspberry Pi

35 – 40 min

ESP32

Periféria LEDC umožňuje nastaviť frekvenciu a rozlíšenie PWM.

Medzi dosiahnuteľnou frekvenciou a rozlíšením existuje kompromis.

Príklad pre Arduino-ESP32 3.x na doske s vhodným GPIO25:

Otvoriť Wokwi ESP32

const int LED_PIN = 25;

void setup() {
  if (ledcAttach(LED_PIN, 5000, 8)) {
    ledcWrite(LED_PIN, 128);
  }
}

void loop() {
}

Ide o približne polovičnú striedu pri 8-bitovom nastavení. LED pripojíme cez rezistor.

Staršie verzie jadra používajú odlišné LEDC API.

Raspberry Pi

Príklad s gpiozero:

Otvoriť Wokwi Raspberry Pi Pico

Upozornenie: Tento príklad používa knižnicu gpiozero určenú pre Raspberry Pi s Linuxom. Na Raspberry Pi Pico nie je priamo spustiteľný; na simuláciu použite Wokwi Pico po prepise programu na MicroPython.

from gpiozero import PWMLED
from signal import pause

led = PWMLED(18, frequency=100)
led.value = 0.5

try:
    pause()
finally:
    led.close()

Kvalita a spôsob generovania PWM závisia od GPIO backendu. Pri presnom časovaní vyberáme vhodné hardvérové riešenie.

6. Úlohy a zápis

40 – 45 min

  1. Pri perióde 1 ms je zapnutie 0,75 ms. Aká je strieda?

75 %.

  1. Aká je frekvencia?

1 kHz.

  1. Aké je ideálne priemerné napätie pri 3,3 V a 50 %?

1,65 V.

  1. Je na nefiltrovanom pine stále 1,65 V?

Nie.

PWM mení šírku impulzu, bežne pri pevnej perióde.

Strieda je pomer času zapnutia k perióde.

PWM je digitálny impulzný priebeh.

Priemerné napätie závisí od striedy a úrovní signálu.

Výkonové záťaže riadime cez vhodný ovládač.

Filtrovaním PWM môžeme získať približné analógové napätie.
