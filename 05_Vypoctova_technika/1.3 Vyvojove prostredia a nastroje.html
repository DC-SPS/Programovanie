1.3 Vývojové prostredia a nástroje

Úvod do mikroprocesorových a embedded systémov · 45 minút

Trvanie: 45 minút Nadväznosť: Základné princípy embedded systémov.

Ciele hodiny

Žiak má vedieť:

  • opísať postup od zdrojového kódu k programu v zariadení,
  • rozlíšiť editor, kompilátor, linker a debugger,
  • vysvetliť rozdiel medzi nahrávaním a ladením,
  • použiť základné funkcie vývojového prostredia,
  • rozlíšiť chybu prekladu a chybu behu.

1. Zdrojový program nestačí

0 – 5 min

Mikrokontrolér spravidla nevykonáva priamo text C alebo C++.

IDE – Integrated Development Environment – spája viac nástrojov do jedného prostredia.

Nahrávanie a ladenie

  • Nahratie: uloženie programu do cieľového zariadenia.
  • Ladenie: zisťovanie priebehu a príčin chýb.

Nahrávací bootloader nemusí poskytovať hardvérové ladenie.

Debugger

Umožňuje podľa podpory hardvéru:

  • nastaviť breakpoint,
  • krokovať program,
  • čítať premenné a registre,
  • sledovať zásobník volaní.

Zastavenie debuggerom mení časové správanie zariadenia. Pri riadení výstupov na to musíme myslieť.

STM32CubeMX poskytuje konfiguráciu čipu, pinov a generovanie inicializačného kódu. Jeho funkcie môžu byť dostupné aj cez integráciu s ďalšími nástrojmi podľa verzie.

Knižnice

Knižnica poskytuje hotové funkcie, napríklad ovládač displeja.

Pri projekte evidujeme jej názov a verziu. Rôzne verzie môžu mať odlišné API.

4. Praktická ukážka v Arduino IDE

26 – 37 min

Postup:

  1. Pripojiť podporovanú dosku.
  2. Vybrať správny model dosky.
  3. Vybrať port.
  4. Otvoriť alebo napísať program.
  5. Spustiť preklad.
  6. Nahrať program.
  7. Overiť správanie.

Program pre Arduino Uno R3

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(500);

  digitalWrite(LED_BUILTIN, LOW);
  delay(500);
}

LED svieti približne pol sekundy a pol sekundy nesvieti.

Celá perióda je približne jedna sekunda.

Pri inej doske overíme prítomnosť a polaritu zabudovanej LED.

Zmena

Žiaci upravia oba intervaly na 250 ms a vysvetlia výsledok.

Odpoveď: Celá perióda bude približne 500 ms, frekvencia približne 2 Hz.

5. Diagnostika chýb

37 – 41 min

ProblémČo overiť
Program sa nepreložíSyntax, názvy, knižnice
Preklad funguje, nahratie nieDosku, port, kábel, režim nahrávania
Nahratie prebehne, zariadenie nereagujeZapojenie, piny, logiku
Sériový výpis je nečitateľnýRýchlosť a nastavenie portu

USB kábel môže byť iba napájací. Taký kábel nemusí poskytovať dátové spojenie.

Pri chybe čítame najmä prvé relevantné hlásenie, nie iba posledný riadok výpisu.

6. Zápis

41 – 45 min

Vývojový reťazec premieňa zdrojový kód na program pre cieľové zariadenie.

IDE spája editor a ďalšie nástroje.

Kompilátor prekladá, linker spája časti programu.

Nahrávanie a ladenie sú rozdielne operácie.

Úspešný preklad ešte nedokazuje správnosť programu.

Verzie nástrojov a knižníc sú súčasťou dokumentácie projektu.

Praktická ukážka vo Wokwi

Vložte sketch do Arduino IDE s vybranou doskou Arduino Uno R3. Zabudovaná LED svieti a zhasína v polsekundových intervaloch.

Otvoriť Wokwi: Arduino Uno R3 (ATmega328P)
void setup() {
    pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
    digitalWrite(LED_BUILTIN, HIGH);
    delay(500);
    digitalWrite(LED_BUILTIN, LOW);
    delay(500);
}
