5.6 Filtrácia, kalibrácia a presnosť merania

Analógové a výkonové periférie · 45 minút

Bezpečnosť: Pri praktických ukážkach používajte iba nízke napätia. Motory, výkonové LED ani iné výkonové záťaže nepripájajte priamo na GPIO; použite vhodný výkonový ovládač. Každá prednáška je určená na 45 minút pre 3. ročník strednej školy.

Trvanie: 45 minút
Nadväznosť: ADC, vzorkovanie a kvantovanie.

Ciele hodiny

Žiak má vedieť:

  • rozlíšiť rozlíšenie, presnosť a opakovateľnosť,
  • rozpoznať náhodnú a systematickú zložku chyby,
  • použiť jednoduché priemerovanie,
  • vysvetliť dvojbodovú kalibráciu,
  • posúdiť kompromis medzi vyhladením a rýchlosťou reakcie.

1. Prečo dostávame rôzne výsledky?

0 – 5 min

Na zdanlivo rovnakom vstupe ADC číta:

510, 512, 511, 514, 513

Príčinou môže byť:

  • elektrický šum,
  • kolísanie napájania,
  • rušenie,
  • zmena meranej veličiny,
  • vlastnosti ADC a zdroja signálu.

Kolísanie nemusí znamenať chybu programu.

2. Základné pojmy

5 – 15 min

PojemVýznam
RozlíšenieJemnosť dostupných kódov alebo zobrazovaných hodnôt
PresnosťZhoda výsledku so skutočnou alebo referenčnou hodnotou
OpakovateľnosťZhoda opakovaných výsledkov za rovnakých podmienok
Chyba meraniaRozdiel nameranej a referenčnej hodnoty

Prístroj môže stále ukazovať 25,0 °C, hoci referencia ukazuje 23,0 °C.

Má dobrú opakovateľnosť, ale systematicky posunutý výsledok.

Zdroje chýb

  • offset – posunutie,
  • chyba zosilnenia alebo mierky,
  • nelinearita,
  • neistota referencie,
  • šum,
  • teplotná závislosť,
  • nevhodné zapojenie.

Počet desatinných miest na displeji nedokazuje presnosť.

3. Filtrácia

15 – 25 min

Aritmetický priemer

\bar{x} = \frac{x_1+x_2+\dots+x_N}{N}

Pre hodnoty:

510, 512, 511, 514, 513

je priemer:

\bar{x}=512

Priemerovanie môže zmenšiť vplyv náhodného šumu. Neodstráni automaticky systematický posun.

Pri nezávislom šume vhodných vlastností klesá smerodajná odchýlka priemeru približne s 1/\sqrt{N}. V praxi však vzorky môžu byť vzájomne závislé.

Arduino: priemer 16 vzoriek

Otvoriť Wokwi Arduino Uno

const byte VSTUP = A0;
const byte POCET = 16;

void setup() {
  Serial.begin(9600);
}

void loop() {
  uint32_t sucet = 0;

  for (byte i = 0; i < POCET; i++) {
    sucet += analogRead(VSTUP);
    delay(2);
  }

  float priemer = sucet / float(POCET);

  Serial.println(priemer, 2);
  delay(100);
}

Ide o jednoduchú blokujúcu ukážku. Pre súbežné riadenie by sme vzorky zbierali priebežne bez dlhého čakania.

Ďalšie filtre

FilterTypická vlastnosť
Kĺzavý priemerVyhladzuje, ale oneskoruje zmeny
MediánPotláča ojedinelé odľahlé hodnoty
Exponenciálny filterJednoduchý, potrebuje málo pamäte
Analógový RC filterPotláča rýchle zmeny ešte pred ADC

Exponenciálny filter:

y_k = y_{k-1}+\alpha(x_k-y_{k-1})

Pre 0<\alpha\leq1:

  • menšie \alpha znamená silnejšie vyhladenie,
  • väčšie \alpha znamená rýchlejšiu reakciu.

Filter inicializujeme vhodne, napríklad prvou vzorkou.

4. Kalibrácia

25 – 35 min

Kalibráciou určujeme vzťah medzi údajom meradla a referenčnými hodnotami. Na jeho základe môžeme zaviesť korekciu výsledkov.

Jednobodová korekcia

Ak meranie vykazuje približne konštantný posun:

Referencia:  20,0 °C
Meranie:     22,0 °C

môžeme v príslušnom rozsahu skúsiť korekciu:

T_\text{opravené}=T_\text{merané}-2

Jeden bod však nestačí na overenie chyby mierky ani nelinearity.

Dvojbodová lineárna korekcia

Zmeriame dva známe body:

Referenčné napätieKód ADC
1,00 V210
4,00 V820

Použijeme:

U=a\cdot k+b
a=\frac{4{,}00-1{,}00}{820-210} =\frac{3}{610} \approx0{,}004918
b=1{,}00-a\cdot210 \approx-0{,}03279

Pre kód 515:

U\approx2{,}50\ \text{V}

Program:

Otvoriť Wokwi Arduino Uno

Ide o úryvok kódu. Pred spustením ho vložte na označené miesto do úplného programu.

float prepocitajNapatie(int kod) {
  const float A = 3.0f / 610.0f;
  const float B = 1.0f - A * 210.0f;

  return A * kod + B;
}

Obmedzenia

  • Referencia musí byť dostatočne spoľahlivá.
  • Kalibračné body majú pokrývať používaný rozsah.
  • Dva body neopravia všeobecnú nelinearitu.
  • Mimo kalibrovaného rozsahu môže byť odhad horší.
  • Zmenu teploty alebo zostarnutie súčiastok treba podľa požiadaviek zohľadniť.

5. Návrh kvalitného merania

35 – 41 min

Odporúčaný postup:

  1. Overiť elektrické zapojenie a prípustný vstupný rozsah.
  2. Zvoliť vhodnú referenciu a rozsah ADC.
  3. Zabezpečiť primerané vzorkovanie a analógovú filtráciu.
  4. Prezrieť si nespracované údaje.
  5. Vybrať digitálny filter podľa požadovanej reakcie.
  6. Porovnať výsledky s referenciou.
  7. Zaviesť a overiť kalibračnú korekciu.
  8. Uvádzať primeraný počet platných číslic.

Porovnanie platforiem

  • AVR/Uno: dôležitá je referencia, zdrojová impedancia a obmedzené rozlíšenie.
  • ESP32: využijeme dostupné kalibračné rozhrania a overíme charakteristiku ADC.
  • Raspberry Pi: výsledok závisí najmä od externého ADC, referencie, zapojenia a časovania získavania dát.

Úloha

Meradlo pri skutočnej hodnote 10,0 ukazuje:

12,0; 12,1; 11,9; 12,0

Otázky:

  • Pomôže priemerovanie?

Zmenší kolísanie.

  • Odstráni odchýlku približne +2?

Nie.

  • Čo potrebujeme?

Overenie referenciou a vhodnú korekciu, prípadne opravu príčiny.

6. Overenie a zápis

41 – 45 min

  1. Je stabilná hodnota automaticky správna?

Nie.

  1. Ktorý filter je vhodný na ojedinelé odľahlé hodnoty?

Často medián.

  1. Čo býva nevýhodou silného vyhladenia?

Pomalšia reakcia.

  1. Zaručí dvojbodová korekcia presnosť v celom rozsahu?

Nie.

Rozlíšenie, presnosť a opakovateľnosť sú odlišné vlastnosti.

Filtrácia môže potlačiť šum, ale mení časovú odozvu merania.

Priemerovanie automaticky neodstraňuje systematickú chybu.

Kalibrácia porovnáva meranie s referenčnými hodnotami.

Dvojbodová lineárna korekcia upravuje posun a mierku.

Kvalita výsledku závisí od celého meracieho reťazca.
