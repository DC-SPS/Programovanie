1. Teoretický výklad

Typ určuje interpretáciu bitov aj povolené operácie. Typy uint8_t a int16_t z knižnice stdint.h majú pevnú šírku. uint8_t pokrýva 0–255; int8_t pokrýva −128 až 127. Operátor sizeof zistí veľkosť v bajtoch.

Súvislosti a praktické použitie

Na Arduino Uno s ATmega328P je SRAM 2 KiB a zdieľajú ju premenné aj zásobník. Veľkosť int sa môže líšiť podľa platformy; pri prenose dát použite typ s pevnou šírkou a skontrolujte konverzie. Výpočet 250 + 10 sa nezmestí do uint8_t.

Upozornenie: Predpoklad, že int má všade rovnakú šírku; ignorovanie pretečenia; zámena veľkosti pointera a dát.

2. Ukážkový kód

Úplný program pre Arduino Uno. Otvorte simulátor Wokwi, vložte kód do sketch.ino a spustite ho. Toto je úplný program, ktorý môžete priamo spustiť.

Otvoriť simulátor Wokwi Arduino Uno

#include <stdint.h>
void setup() {
  Serial.begin(9600);
  Serial.print("uint8_t bajty: ");
  Serial.println(sizeof(uint8_t));
  Serial.print("uint16_t bajty: ");
  Serial.println(sizeof(uint16_t));
  const uint8_t limit = 250;
  Serial.println(limit);
}
void loop() {}

Rozbor: sizeof(uint8_t) je 1 a sizeof(uint16_t) je 2. Typy majú určenú šírku; výsledok nehovorí nič o veľkosti ukazovateľa. Úryvok vložte do setup() úplného Arduino programu.

4. Samostatné úlohy

  1. A – Základ: Určte rozsah uint16_t a veľkosť poľa 20 prvkov uint16_t. Porovnajte s kapacitou SRAM ATmega328P.
  2. B – Použitie: Vytvorte vlastný jednoduchý príklad a doplňte medzikroky.
  3. C – Analýza: Zmeňte vstup ukážky, najprv odhadnite výstup a potom ho overte.
  4. D – Rozšírenie: Navrhnite bezpečnú kontrolu chybného vstupu alebo obmedzenia platformy a zdôvodnite ju.
