3.6 Memory map a adresovanie

Adresa označuje miesto v adresovom priestore. Memory map opisuje, ktoré rozsahy patria pamätiam alebo periféri…

Témy: adresy, priestory, registre

Ciele a prerekvizity

  • vysvetliť základné pojmy a súvislosti témy;
  • vyriešiť príklad a zdôvodniť jednotlivé kroky;

1. Teoretický výklad

Adresa označuje miesto v adresovom priestore. Memory map opisuje, ktoré rozsahy patria pamätiam alebo perifériám. Architektúry sa líšia: AVR oddeľuje programovú Flash od dátového priestoru a registre opisuje v datasheete.

Súvislosti a praktické použitie

Adresu interpretujte iba spolu s modelom MCU a jeho dokumentáciou. Na prístup k perifériám používajte názvy registrov a API dodané pre platformu, nie ľubovoľné číselné adresy. Číslo adresy premennej sa môže meniť medzi zostaveniami.

Upozornenie: Zámena adresy a hodnoty; prenos mapy medzi MCU; dereferencovanie ľubovoľného čísla ako pointera.

2. Ukážkový kód

Úplný program pre Arduino Uno. Otvorte simulátor Wokwi, vložte kód do sketch.ino a spustite ho. Program vypíše adresu globálnej premennej a prečíta hodnotu cez ukazovateľ.

Otvoriť simulátor Wokwi Arduino Uno

#include <stdint.h>
uint8_t vzorka = 42;
void setup() {
  Serial.begin(9600);
  Serial.print("Adresa vzorky: ");
  Serial.println((uintptr_t)&vzorka, HEX);
  Serial.print("Hodnota: ");
  Serial.println(*(&vzorka));
}
void loop() {}

Rozbor: Operátor & získa adresu a * pristúpi k objektu na nej. Zobrazená adresa je len pre tento beh; nespoliehajte sa na jej konkrétne číslo. Úryvok vložte do setup() úplného programu.

3. Časté chyby a ich oprava

  • Zámena adresy a hodnoty.
  • prenos mapy medzi MCU.
  • dereferencovanie ľubovoľného čísla ako pointera..

4. Samostatné úlohy

  1. A – Základ: Nájdite v datasheete rozdelenie pamäťových priestorov. Vysvetlite, prečo adresa z jedného behu nie je univerzálna konštanta.
  2. B – Použitie: Vytvorte vlastný jednoduchý príklad a doplňte medzikroky.
  3. C – Analýza: Zmeňte vstup ukážky, najprv odhadnite výstup a potom ho overte.
  4. D – Rozšírenie: Navrhnite bezpečnú kontrolu chybného vstupu alebo obmedzenia platformy a zdôvodnite ju.
