7.3 Multitasking

Embedded a reálne operačné systémy · 45 minút

Platforma a bezpečnosť: Pojem ?reálny operačný systém? v tomto tematickom celku označuje RTOS. Kódové ukážky FreeRTOS sú určené pre Arduino-ESP32 na Wokwi ESP32. Konkrétne piny, počet jadier, ADC a vlastnosti FreeRTOS závisia od modelu dosky a verzie frameworku. Pred zapojením overte pinout dosky; LED pripojte cez rezistor.

Trvanie: 45 minút
Nadväznosť: Úlohy a služby OS.

Ciele hodiny

Žiak má vedieť:

  • vysvetliť multitasking,
  • rozlíšiť súbežnosť a paralelné vykonávanie,
  • porovnať kooperatívny a preemptívny prístup,
  • vysvetliť prepnutie kontextu,
  • rozpoznať výhodu blokujúceho čakania úlohy.

1. Viac činností

0 – 5 min

Zariadenie má:

  • merať teplotu,
  • aktualizovať displej,
  • prijímať príkazy,
  • odosielať údaje.

Multitasking umožňuje organizovať viac plánovaných činností tak, aby sa v čase striedali alebo vykonávali paralelne.

2. Súbežnosť a paralelizmus

5 – 15 min

Jedno jadro

V jednom okamihu vykonáva jednu vykonávaciu cestu. Úlohy sa striedajú.

Čas →
A A | B B | A | C C | B | A

Viac jadier

Niektoré úlohy môžu skutočne bežať súčasne na rôznych jadrách.

Jadro 1: A A A A
Jadro 2: B B B B
  • Súbežnosť: viac činností postupuje počas rovnakého obdobia.
  • Paralelizmus: viac činností sa vykonáva v rovnakom okamihu.

Nie každý ESP32 má dve jadrá. Závisí od variantu.

Prepnutie kontextu

Pri prepnutí systém uloží stav jednej úlohy a obnoví stav druhej.

Uchováva napríklad:

  • registre,
  • ukazovateľ zásobníka,
  • miesto pokračovania.

Prepnutie spotrebúva čas.

3. Dva prístupy

15 – 25 min

Kooperatívny

Úlohy alebo činnosti dobrovoľne odovzdávajú riadenie.

V jednoduchej superloop aplikácii:

Otvoriť Wokwi ESP32

Kódový výňatok: Ukážka demonštruje časť FreeRTOS programu. Na simuláciu ju vložte do kompletného projektu pre Arduino-ESP32.

void loop() {
  obsluzTlacidlo();
  aktualizujLed();
  skontrolujKomunikaciu();
}

Každá funkcia má rýchlo skončiť. Takáto slučka realizuje kooperatívne striedanie činností, hoci nemusí používať OS.

Ak jedna funkcia uviazne, ostatné činnosti sa nevykonajú.

Preemptívny

Plánovač môže vykonávanú úlohu prerušiť a prideliť procesor inej.

Napríklad keď sa stane pripravenou úloha s vyššou prioritou.

Aktívne a blokujúce čakanie

Nevhodné plytvanie procesorom:

Stále kontroluj, či už prišla správa.

Vhodný mechanizmus RTOS:

Zablokuj úlohu, kým nepríde správa alebo neuplynie timeout.

Zablokovaná úloha nepotrebuje priebežne vykonávať kontrolnú slučku.

4. ESP32: dve nezávislé úlohy

25 – 36 min

Ukážka pre Arduino framework na ESP32. Použijeme externé LED cez rezistory približne 680 Ω na vhodných GPIO25 a GPIO26 klasickej dosky ESP32.

Otvoriť Wokwi ESP32

#include <Arduino.h>

const int LED_A = 25;
const int LED_B = 26;

void ulohaA(void* parameter) {
  bool stav = false;

  for (;;) {
    stav = !stav;
    digitalWrite(LED_A, stav ? HIGH : LOW);

    vTaskDelay(pdMS_TO_TICKS(500));
  }
}

void ulohaB(void* parameter) {
  bool stav = false;

  for (;;) {
    stav = !stav;
    digitalWrite(LED_B, stav ? HIGH : LOW);

    vTaskDelay(pdMS_TO_TICKS(200));
  }
}

void setup() {
  pinMode(LED_A, OUTPUT);
  pinMode(LED_B, OUTPUT);

  digitalWrite(LED_A, LOW);
  digitalWrite(LED_B, LOW);

  BaseType_t vysledokA =
      xTaskCreate(ulohaA, "LED_A", 2048, nullptr, 1, nullptr);

  BaseType_t vysledokB =
      xTaskCreate(ulohaB, "LED_B", 2048, nullptr, 1, nullptr);

  if (vysledokA != pdPASS || vysledokB != pdPASS) {
    digitalWrite(LED_A, LOW);
    digitalWrite(LED_B, LOW);

    for (;;) {
      vTaskDelay(pdMS_TO_TICKS(1000));
    }
  }
}

void loop() {
  vTaskDelay(pdMS_TO_TICKS(1000));
}

Vysvetlenie

  • Každá úloha má vlastnú nekonečnú slučku.
  • vTaskDelay() zablokuje volajúcu úlohu na zadaný počet tickov.
  • Medzitým môžu pracovať iné pripravené úlohy.
  • Číslo 1 určuje prioritu.
  • Veľkosť zásobníka je v tejto implementácii ESP-IDF/Arduino-ESP32 zadávaná v bajtoch. V štandardnom FreeRTOS bývajú jednotkou slová zásobníka.

Ukážka demonštruje organizáciu úloh, nie presné generovanie časových impulzov.

5. Rozbor

36 – 41 min

  1. Blokuje vTaskDelay() celý procesor? Nie, blokuje volajúcu úlohu.
  1. Bežia úlohy nevyhnutne na dvoch jadrách? Nie.
  1. Aká je približná perióda LED A? Jedna sekunda – 500 ms svieti a 500 ms nesvieti.
  1. Prečo majú obe úlohy nekonečnú slučku? Majú opakovane vykonávať svoju činnosť.

Úloha FreeRTOS nemá iba vrátiť riadenie zo svojej funkcie. Ak má skončiť, použije sa príslušný mechanizmus, napríklad vTaskDelete(nullptr).

6. Zápis

41 – 45 min

Multitasking organizuje postup viacerých úloh.

Na jednom jadre sa úlohy striedajú.

Paralelné vykonávanie vyžaduje viac vykonávacích prostriedkov.

Kooperatívny prístup odovzdáva riadenie dobrovoľne, preemptívny umožňuje zásah plánovača.

Blokujúce čakanie úlohy umožňuje využiť procesor na inú prácu.
