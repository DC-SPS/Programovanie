Témy: sústavy, prevody, bit, rozsah

1. Teoretický výklad

Binárna sústava má základ 2. Pozície sprava zodpovedajú mocninám 2: 2⁰, 2¹, 2² atď. Preto 101101₂ = 32 + 8 + 4 + 1 = 45₁₀. Pri prevode do binárnej sústavy delíme číslom 2 a zvyšky čítame zdola nahor.

Súvislosti a praktické použitie

Pri pevnej šírke n bitov má neznamienková hodnota rozsah 0 až 2ⁿ−1. Osem bitov preto pokrýva 0–255. Úvodné nuly nemenia číselnú hodnotu, ale vyjadrujú šírku zápisu.

Upozornenie: Zabudnúť váhu 2⁰; čítať bity opačným poradím; hovoriť o napätí bez znalosti logických prahov.

2. Ukážkový kód

Úplný program pre Arduino Uno. Otvorte simulátor Wokwi, vložte kód do sketch.ino a spustite ho. Program načíta osem znakov 0/1 a vypíše ich hodnotu.

Otvoriť simulátor Wokwi Arduino Uno

#include <stdint.h>
uint8_t citajBity(const char *bity) {
  uint8_t hodnota = 0;
  while (*bity == '0' || *bity == '1') {
    hodnota = (uint8_t)(hodnota * 2u + (uint8_t)(*bity - '0'));
    ++bity;
  }
  return hodnota;
}
void setup() {
  Serial.begin(9600);
  Serial.println(citajBity("00101101"));
}
void loop() {}

Rozbor: Každý znak posúva doterajšiu hodnotu o jednu pozíciu a pridá ďalší bit. Výsledok je 45. Tento úryvok vložte do úplného programu v setup() a deklaráciu premennej umiestnite pred funkcie.

3. Časté chyby a ich oprava

  • Zabudnúť váhu 2⁰.
  • čítať bity opačným poradím.
  • hovoriť o napätí bez znalosti logických prahov..

4. Samostatné úlohy

  1. A – Základ: Preveďte 110101₂ na desiatkovú hodnotu a 58₁₀ na osem bitov. Overte výsledok spätným súčtom váh.
  2. B – Použitie: Vytvorte vlastný jednoduchý príklad a doplňte medzikroky.
  3. C – Analýza: Zmeňte vstup ukážky, najprv odhadnite výstup a potom ho overte.
  4. D – Rozšírenie: Navrhnite bezpečnú kontrolu chybného vstupu alebo obmedzenia platformy a zdôvodnite ju.
