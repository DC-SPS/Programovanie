1. Teoretický výklad

ATmega328P má 32 KiB Flash, 2 KiB SRAM a 1 KiB EEPROM. Flash uchováva program aj po vypnutí; SRAM je pracovná a po odpojení napájania stráca obsah; EEPROM uchová malé údaje aj po vypnutí.

Súvislosti a praktické použitie

Flash sa používa na firmvér; SRAM na premenné počas behu; EEPROM na nastavenia, ktoré majú prežiť reštart. EEPROM má obmedzený počet zápisov, preto nepoužívajte každý priechod slučky na ukladanie. Kapacity závisia od čipu.

Upozornenie: SRAM nie je trvalá; EEPROM nie je neobmedzená RAM; veľkosti pamätí sa líšia podľa MCU.

2. Ukážkový kód

Úplný program pre Arduino Uno. Otvorte simulátor Wokwi, vložte kód do sketch.ino a spustite ho. Program načíta hodnotu a aktualizuje ju iba pri zmene.

Otvoriť simulátor Wokwi Arduino Uno

#include <EEPROM.h>
const int ADRESA = 0;
void setup() {
  Serial.begin(9600);
  const uint8_t ulozenaHodnota = EEPROM.read(ADRESA);
  Serial.print("Hodnota EEPROM: ");
  Serial.println(ulozenaHodnota);
  EEPROM.update(ADRESA, 42);
  Serial.println("Nastavenie aktualizovane.");
}
void loop() {}

Rozbor: EEPROM.read načíta bajt; update zapíše hodnotu iba pri zmene. Príklad potrebuje #include <EEPROM.h> na začiatku úplného programu. Wokwi demonštruje API; pri reálnom návrhu rešpektujte životnosť čipu.
