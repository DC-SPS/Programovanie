9.2 TCP/IP a IP komunikácia

IoT – architektúra, komunikácia a bezpečnosť · 45 minút

Praktické prostredie: Ukážky Wi-Fi na ESP32 možno spustiť v online simulátore. Príkazy pre broker a Raspberry Pi určené na lokálnu laboratórnu sieť spúšťajte len na zariadeniach, na ktoré máte oprávnenie. V príkladoch nepoužívajte skutočné heslá ani tokeny.

Ciele hodiny

Žiak má vedieť:

  • rozlíšiť IP adresu a port,
  • vysvetliť úlohu IP, TCP a UDP,
  • opísať význam DNS, DHCP a predvolenej brány,
  • použiť základné diagnostické nástroje,
  • vysvetliť rozdiel medzi doručením dát a vykonaním príkazu.

1. Sieťové vrstvy

Pri odoslaní merania spolupracuje viac mechanizmov:

Platforma: text

MQTT → TCP → IP → Wi-Fi

Wi-Fi a MQTT nie sú alternatívy tej istej vrstvy. Môžu byť použité súčasne.

2. IP adresa, port a brána

16 – 27 min

IP adresa

Identifikuje sieťové rozhranie v príslušnom adresovom prostredí.

Príklad IPv4:

Platforma: text

192.168.1.25

Zápis:

Platforma: text

192.168.1.25/24

určuje aj dĺžku sieťového prefixu.

Port

Rozlišuje komunikačné koncové body aplikácií.

Platforma: text

192.168.1.25:1883

  • IP adresa smeruje k zariadeniu,
  • port pomáha vybrať službu.

PojemVýznam

IPv6 používa 128-bitové adresy a môže fungovať súčasne s IPv4.

3. TCP a UDP

27 – 35 min

VlastnosťTCPUDP
Základný modelSpojenie a tok bajtovSamostatné datagramy
Poradie a opakovanieZabezpečuje transportAplikácia rieši podľa potreby
Hranice správNezachováva aplikačné hraniceZachováva hranice datagramov
Typické použitieHTTP, MQTTNiektoré telemetrické a časové protokoly

TCP poskytuje usporiadaný spoľahlivý tok bajtov, pokiaľ spojenie funguje. Pri poruche môže skončiť chybou.

Potvrdenie TCP neznamená, že aplikácia vykonala príkaz. Na to môže byť potrebná aplikačná odpoveď.

4. Diagnostika na Raspberry Pi

35 – 41 min

Platforma: bash

ip address
Dokumentácia Raspberry Pi

Zobrazí adresy rozhraní.

Platforma: bash

ip route
Dokumentácia Raspberry Pi

Zobrazí smerovacie pravidlá.

Platforma: bash

ping -c 4 192.168.1.1
Dokumentácia Raspberry Pi

Overí odpoveď na ICMP, ak ju cieľ a sieť povoľujú.

Platforma: bash

getent hosts example.com
Dokumentácia Raspberry Pi

Overí preklad názvu.

Neúspešný ping automaticky nedokazuje, že všetky služby cieľa sú nedostupné. ICMP môže byť blokované.

5. Úlohy a zápis

41 – 45 min

  1. Čo rozlišuje službu na zariadení? Port.
  2. Prekladá DHCP názvy serverov? Nie, na to slúži DNS.
  3. Zachová TCP hranice našich správ? Nie.

IP zabezpečuje adresovanie a smerovanie.

TCP poskytuje usporiadaný tok bajtov, UDP prenáša datagramy.

IP adresa a port majú rozdielne úlohy.

DNS prekladá názvy, DHCP poskytuje sieťovú konfiguráciu.

Transportné doručenie nie je potvrdením vykonania aplikačného príkazu.
