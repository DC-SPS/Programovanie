8.5 Procesy a služby

Jednodoskové počítače a ich operačný systém · 45 minút

Platforma: Príkazy a príklady Python GPIO Zero sú určené pre Raspberry Pi s Raspberry Pi OS. Wokwi Raspberry Pi Pico simuluje mikrokontrolér Pico, nie Linuxový SBC; príkazy a GPIO Zero ukážky sa v ňom nespustia. GPIO používa 3,3 V; na piny nepripájajte 5 V.

8.5 Procesy a služby

Ciele hodiny

Žiak má vedieť:

  • rozlíšiť program a proces,
  • vysvetliť PID,
  • zobraziť a ukončiť vlastný proces,
  • vysvetliť úlohu služby,
  • použiť základné príkazy systemctl a journalctl.

Časový plán

ČasObsah
0 – 5 minProgram verzus proces
5 – 16 minStav a riadenie procesov
16 – 26 minPraktická práca
26 – 36 minSlužby a systemd
36 – 41 minDiagnostika
41 – 45 minOverenie a zápis

1. Program a proces

0 – 5 min

  • Program: uložený kód a súvisiace údaje.
  • Proces: bežiaca inštancia programu.

Rovnaký program môže byť spustený viackrát ako viac procesov.

PID – Process ID – je číselný identifikátor procesu.

2. Život procesu

5 – 16 min

Proces môže:

  • vykonávať výpočty,
  • čakať na procesor,
  • spať,
  • čakať na vstup alebo inú udalosť,
  • skončiť.

Čakajúci proces nemusí spotrebúvať významný čas CPU.

Príkazy

PríkazÚloha
ps -efPrehľad procesov
topPriebežný prehľad využitia
jobsÚlohy aktuálneho shellu
kill PIDOdošle signál procesu

Signály

  • SIGTERM: žiadosť o ukončenie, proces môže upratať prostriedky.
  • SIGKILL: nútené ukončenie bez možnosti obsluhy.

Najprv používame primeraný spôsob ukončenia. Nútené ukončenie môže prerušiť zápis údajov.

3. Bezpečné cvičenie s vlastným procesom

16 – 26 min

Spustenie na pozadí:

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

sleep 300 &

Zobrazenie úloh shellu:

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

jobs -l

Ak ide o prvú úlohu v tomto shelli:

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

fg %1

Prenesie sa do popredia. Ukončíme ju pomocou Ctrl+C.

Dôležité klávesy

  • Ctrl+C: pošle foreground skupine procesov signál prerušenia.
  • Ctrl+Z: pozastaví foreground úlohu; neukončí ju.

Príkaz bg môže pozastavenú úlohu obnoviť na pozadí.

Úloha: Vysvetli, prečo sleep 300 neznamená päť minút výpočtovej záťaže.

Odpoveď: Proces čaká na uplynutie času.

4. Služby a systemd

26 – 36 min

Služba zabezpečuje činnosť na pozadí, napríklad:

  • SSH server,
  • webový server,
  • záznam meraní.

Na Raspberry Pi OS služby bežne spravuje systemd.

PríkazVýznam
systemctl status sshStav služby
sudo systemctl start sshSpustenie teraz
sudo systemctl stop sshZastavenie teraz
sudo systemctl restart sshReštart
sudo systemctl enable sshPovolenie spúšťania pri štarte
sudo systemctl disable sshZrušenie spúšťania pri štarte

enable nie je to isté ako start.

Kombináciu umožňuje:

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

sudo systemctl enable --now ssh

Názov služby môže byť v inej distribúcii odlišný.

Správanie pri chybe

Služba môže byť nakonfigurovaná na automatický reštart. Ten však neopravuje príčinu chyby a nemusí sám odhaliť aplikáciu, ktorá stále existuje, ale zasekla sa.

5. Diagnostika

36 – 41 min

Záznamy služby:

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

journalctl -u ssh -n 30 --no-pager

Niektoré záznamy môžu podľa oprávnení vyžadovať sudo.

Postup pri probléme:

  1. over stav služby,
  2. prezri log,
  3. skontroluj konfiguráciu,
  4. oprav príčinu,
  5. službu podľa potreby reštartuj.

6. Zápis

41 – 45 min

Proces je bežiaca inštancia programu a má PID.

Proces môže pracovať alebo čakať.

Signály umožňujú riadiť jeho správanie a ukončenie.

Služba poskytuje funkciu na pozadí.

systemctl spravuje služby, journalctl zobrazuje systémové záznamy.

Spustenie služby teraz a povolenie pri štarte sú rozdielne operácie.

Zdroje na ďalšie štúdium

  • Raspberry Pi OS a Imager
  • Raspberry Pi – hardvér a GPIO
  • GPIO Zero – vstupné zariadenia
  • GPIO Zero – výstupné zariadenia
  • Linux GPIO character device API
  • Zastarané Linux sysfs GPIO API
  • systemd systemctl
  • Raspberry Pi – vzdialený prístup a SSH
