2.3 Inštrukčný cyklus mikrokontroléra

Architektúra mikrokontroléra · 45 minút

Trvanie: 45 minút Nadväznosť: CPU, ALU a registre.

Ciele hodiny

Žiak má vedieť:

  • vysvetliť základné fázy vykonania inštrukcie,
  • rozlíšiť hodinový cyklus a inštrukciu,
  • opísať účinok skoku,
  • vysvetliť základný princíp pipeline,
  • približne vypočítať čas vykonania podľa počtu cyklov.

1. Od C++ k strojovým inštrukciám

0 – 5 min

Procesor priamo nevykonáva riadky programu C++.

Zjednodušene:

Zdrojový program
       ↓
Prekladač a ďalšie nástroje
       ↓
Strojové inštrukcie
       ↓
Procesor

Jeden riadok môže vytvoriť:

  • viac inštrukcií,
  • jednu inštrukciu,
  • žiadnu inštrukciu, ak ho optimalizácia odstráni.

2. Základné fázy

5 – 17 min

Didaktický model:

  1. Fetch – načítanie inštrukcie
  2. Decode – dekódovanie
  3. Execute – vykonanie
  4. Prístup k pamäti a zápis výsledku, ak sú potrebné
Načítaj → Dekóduj → Vykonaj → Ulož výsledok
   ↑                                  │
   └──────── ďalšia inštrukcia ────────┘

Skutočný procesor môže fázy spájať, deliť alebo prekrývať.

Načítanie

Procesor získa inštrukciu z programovej pamäte.

Dekódovanie

Riadiaca jednotka určí:

  • operáciu,
  • operandy,
  • spôsob adresovania.

Vykonanie

Procesor napríklad:

  • sčíta registre,
  • načíta údaj,
  • zapíše výstup,
  • zmení tok programu.

Zápis výsledku

Výsledok môže smerovať do registra, pamäte alebo periférie.

Nie každá inštrukcia potrebuje samostatný prístup k dátovej pamäti.

3. Príklad na AVR

17 – 27 min

Jednoduchý zápis assemblera:

LDI R16, 5
LDI R17, 3
ADD R16, R17

Význam

InštrukciaÚčinok
LDI R16, 5Uloží konštantu 5 do R16
LDI R17, 3Uloží konštantu 3 do R17
ADD R16, R17Sčíta hodnoty a výsledok uloží do R16

Výsledok:

R16 = 8
R17 = 3

Na AVR má LDI obmedzenia na použité registre; v tomto príklade sú R16 a R17 platné.

Skok

Bežný priebeh pokračuje ďalšou inštrukciou. Skok zmení miesto pokračovania.

RJMP zaciatok

Podmienený skok môže závisieť od stavového príznaku, napríklad Z.

Takto procesor realizuje podmienky a cykly vyššieho jazyka.

Prerušenie

Prerušenie dočasne zmení tok vykonávania. Procesor uloží potrebné informácie a prejde na obsluhu podľa pravidiel architektúry.

Po návrate pokračuje v prerušenom programe.

4. Hodinový cyklus a pipeline

27 – 35 min

Hodinový cyklus

Pri frekvencii 16 MHz:

T_\text{clk}=\frac{1}{16\,000\,000}=62{,}5\ \text{ns}

Jedna inštrukcia nemusí trvať jeden hodinový cyklus.

Na ATmega328P:

  • mnohé jednoduché inštrukcie trvajú jeden cyklus,
  • iné potrebujú viac cyklov,
  • pri niektorých závisí čas aj od výsledku podmienky.

Pipeline

Procesor môže prekrývať fázy viacerých inštrukcií.

Zjednodušený príklad:

Cyklus 1: načítanie A
Cyklus 2: vykonanie A + načítanie B
Cyklus 3: vykonanie B + načítanie C

AVR používa jednoduché prekrytie načítania a vykonávania. Skok môže bežný priebeh narušiť a vyžiadať ďalší čas.

Pipeline zvyšuje priepustnosť, ale neznamená, že každá jednotlivá inštrukcia má nulové čakanie.

5. Výpočty a aktivita

35 – 41 min

A. Čas inštrukcie

Inštrukcia potrebuje dva cykly pri 16 MHz:

t=\frac{2}{16\,000\,000}=125\ \text{ns}

B. Čas úseku programu

Úsek má celkovo 160 cyklov:

t=\frac{160}{16\,000\,000}=10\ \mu\text{s}

Výpočet predpokladá známy počet cyklov a nezahŕňa dodatočné prerušenia či iné oneskorenia.

C. Aktivita

Traja žiaci predstavujú:

  • pamäť programu,
  • dekodér,
  • ALU a registre.

Spracujú kartičky:

NAČÍTAJ 5
PRIPOČÍTAJ 3
ULOŽ VÝSLEDOK

Trieda určí, ktorá časť systému vykonáva jednotlivé kroky.

6. Overenie a zápis

41 – 45 min

  1. Je jeden riadok C++ jedna inštrukcia? Nie nevyhnutne.
  2. Musí každá inštrukcia trvať jeden cyklus? Nie.
  3. Čo robí skok? Mení miesto pokračovania programu.

Zápis do zošita

Inštrukčný cyklus zahŕňa načítanie, dekódovanie a vykonanie inštrukcie.

Podľa operácie nasleduje prístup k pamäti a zápis výsledku.

Hodinový cyklus a strojová inštrukcia nie sú totožné pojmy.

Skok mení tok programu.

Pipeline prekrýva fázy viacerých inštrukcií.

Čas vykonania závisí od počtu cyklov aj podmienok systému.

Praktická ukážka: čítanie vstupu a riadenie LED

Úplný program skopírujte do online simulátora Arduino Uno. Simulátor predstavuje mikrokontrolér ATmega328P a umožňuje sledovať vykonávanie programu. Zapojte tlačidlo medzi pin 2 a GND.

Otvoriť online simulátor Arduino Uno (Wokwi)
const byte LED_PIN = LED_BUILTIN;
unsigned long previousMillis = 0;
bool ledState = false;

void setup() {
    pinMode(LED_PIN, OUTPUT);
}

void loop() {
    const unsigned long now = millis();
    if (now - previousMillis >= 500) {
        previousMillis = now;
        ledState = !ledState;
        digitalWrite(LED_PIN, ledState);
    }
}

Zdroje na ďalšie štúdium

  • AVR instruction execution timing (Microchip)
  • Wokwi supported hardware
