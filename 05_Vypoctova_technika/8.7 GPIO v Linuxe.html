1. GPIO cez operačný systém

0 – 5 min

Na mikrokontroléri môže program priamo ovládať registre periférie.

V Linuxe bežná aplikácia používa knižnicu a rozhrania ovládača:

Python aplikácia
       ↓
GPIO knižnica
       ↓
Rozhranie jadra a ovládač
       ↓
GPIO hardvér

Konkrétny spôsob závisí od knižnice, backendu a modelu Raspberry Pi.

2. Číslovanie a elektrické pravidlá

5 – 15 min

Na bežnom 40-pinovom konektore:

SignálFyzický pin
GPIO1711
GPIO2713
GNDNapríklad 6
3,3 VNapríklad 1
5 VNapríklad 2

gpiozero používa označenie BCM GPIO.

Fyzický pin 17 nie je GPIO17. Na bežnom konektore je fyzický pin 17 napájanie 3,3 V.

Pravidlá zapojenia

  • GPIO používa logiku 3,3 V.
  • Na GPIO nepripájame priamo 5 V.
  • LED potrebuje sériový rezistor.
  • Motor ani cievka relé nepatria priamo na GPIO.
  • Prúdové limity overujeme podľa modelu a dokumentácie.
  • Zapojenie meníme pri odpojenom napájaní.

Pri bežnom neizolovanom prepojení potrebujeme spoločnú zem.

3. Praktická ukážka: tlačidlo ovláda LED

15 – 28 min

Zapojenie

  • tlačidlo medzi GPIO17 a GND,
  • GPIO27 → rezistor 680 Ω → anóda LED,
  • katóda LED na GND.

Na Raspberry Pi OS býva gpiozero dostupné. Ak chýba, správca ho môže doinštalovať:

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

sudo apt install python3-gpiozero

Program

Súbor tlacidlo_led.py:

Kód pre Raspberry Pi OS (Python)

Dokumentácia Raspberry Pi

from gpiozero import Button, LED
from signal import pause

tlacidlo = Button(
    17,
    pull_up=True,
    bounce_time=0.05
)

led = LED(
    27,
    initial_value=False
)

def zapni():
    led.on()

def vypni():
    led.off()

tlacidlo.when_pressed = zapni
tlacidlo.when_released = vypni

try:
    led.value = tlacidlo.is_pressed
    pause()

except KeyboardInterrupt:
    pass

finally:
    led.off()
    tlacidlo.close()
    led.close()

Spustenie:

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

python3 tlacidlo_led.py

Ukončenie: Ctrl+C.

Vysvetlenie

  • pull_up=True zabezpečuje vysokú úroveň uvoľneného vstupu.
  • Stlačenie spojí vstup s GND.
  • Knižnica tento nízky stav interpretuje ako stlačenie.
  • bounce_time=0.05 zapína potlačenie zákmitov s intervalom 50 ms.
  • Callbacky reagujú na zmeny.
  • pause() ponechá program spustený.
  • finally uvoľní prostriedky aj pri bežnom prerušení programu.

Presné správanie potlačenia zákmitov závisí aj od použitého GPIO backendu.

4. Ovládače, nástroje a oprávnenia

28 – 35 min

Moderný Linux poskytuje znakové GPIO rozhranie, často cez zariadenia:

/dev/gpiochip0
/dev/gpiochip1
...

Na prácu s týmto rozhraním slúži aj knižnica a nástroje libgpiod.

Číslo GPIO čipu a offset linky nie sú automaticky totožné s BCM označením na konektore. Mapovanie sa môže líšiť podľa modelu.

Staršie návody používajú:

/sys/class/gpio

Toto sysfs GPIO rozhranie je zastarané. Pri novom projekte uprednostňujeme podporované aktuálne knižnice a rozhrania.

Prístupové práva

Prístup ku GPIO závisí od:

  • oprávnení zariadenia,
  • používateľských skupín,
  • pravidiel systému,
  • knižnice a backendu.

Chybu prístupu neriešime automaticky spustením celého programu ako root. Najprv overíme správnu konfiguráciu.

Na Pi 5 používame aktuálne knižnice s podporou jeho GPIO architektúry.

5. Časovanie a obmedzenia

35 – 41 min

Python callback v Linuxe nie je hardvérová ISR ako na AVR.

Reakciu ovplyvňuje:

  • plánovanie,
  • systémová záťaž,
  • knižnica,
  • ovládač.

Softvérové blikanie

Kód pre Raspberry Pi OS (Python)

Dokumentácia Raspberry Pi

from gpiozero import LED
from time import sleep

led = LED(27)

try:
    while True:
        led.on()
        sleep(0.5)

        led.off()
        sleep(0.5)

except KeyboardInterrupt:
    pass

finally:
    led.close()

Pre viditeľné blikanie je tento postup vhodný. Nie je zárukou presných impulzov s mikrosekundovým časovaním.

Pre náročné časovanie použijeme:

  • vhodnú hardvérovú perifériu,
  • podporovaný špecializovaný ovládač,
  • externý radič,
  • mikrokontrolér.

Analógové vstupy

Bežné GPIO Pi 4 alebo Pi 5 neposkytujú univerzálne analógové meranie. Potrebujeme externý ADC, napríklad cez SPI alebo I²C.

6. Overenie a zápis

41 – 45 min

  1. Čo označuje číslo 17 v Button(17)?

BCM GPIO17.

  1. Môžeme na vstup priviesť 5 V?

Nie priamo.

  1. Je callback v Pythone ISR mikrokontroléra?

Nie.

  1. Zaručí sleep(0.001) presne jednu milisekundu?

Nie.

Linux sprístupňuje GPIO cez ovládače a používateľské knižnice.

Rozlišujeme BCM označenie a fyzické číslo pinu.

Raspberry Pi GPIO používa logiku 3,3 V.

gpiozero umožňuje jednoduché ovládanie vstupov a výstupov.

Bežný používateľský program negarantuje presné krátke reakčné časy.

Pre analógové meranie a výkonové záťaže potrebujeme vhodné externé obvody.
