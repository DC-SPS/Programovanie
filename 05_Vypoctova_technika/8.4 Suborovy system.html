8.4 Súborový systém

Jednodoskové počítače a ich operačný systém · 45 minút

Platforma: Príkazy a príklady Python GPIO Zero sú určené pre Raspberry Pi s Raspberry Pi OS. Wokwi Raspberry Pi Pico simuluje mikrokontrolér Pico, nie Linuxový SBC; príkazy a GPIO Zero ukážky sa v ňom nespustia. GPIO používa 3,3 V; na piny nepripájajte 5 V.

8.4 Súborový systém

Ciele hodiny

Žiak má vedieť:

  • vysvetliť súbor a adresár,
  • rozlíšiť absolútnu a relatívnu cestu,
  • orientovať sa v základných adresároch Linuxu,
  • vykonať jednoduché operácie so súbormi,
  • vysvetliť základné oprávnenia.

1. Čo je súborový systém?

0 – 5 min

Súborový systém organizuje údaje na súbory a adresáre a uchováva informácie o nich.

Súbor môže obsahovať:

  • text,
  • program,
  • obrázok,
  • merania,
  • konfiguráciu.

Adresár organizuje názvy súborov a ďalších adresárov.

2. Strom adresárov

5 – 15 min

Linux používa jeden strom začínajúci koreňom /.

CestaBežný význam
/homeDomovské adresáre používateľov
/etcSystémová konfigurácia
/varPremenlivé údaje, napríklad logy
/usrVäčšina používateľských nástrojov a knižníc
/devRozhrania zariadení
/tmpDočasné súbory
/procVirtuálne informácie o procesoch a jadre
/sysVirtuálne informácie a rozhrania jadra

Nie všetky súbory predstavujú údaje uložené na karte. /proc a /sys poskytujú najmä dynamické informácie.

Cesty

Absolútna cesta:

/home/ziak/merania/teplota.csv

Relatívna cesta:

merania/teplota.csv

Relatívna cesta závisí od aktuálneho adresára.

  • . znamená aktuálny adresár,
  • .. nadradený adresár,
  • ~ sa v shelli bežne rozvinie na domovský adresár.

Linux rozlišuje veľké a malé písmená: Data.txt a data.txt môžu byť dva rôzne súbory.

3. Praktické operácie

15 – 28 min

Pracujeme vo vlastnom domovskom adresári:

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

mkdir -p ~/vyuka8/merania

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

cd ~/vyuka8

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

printf 'cas,teplota\n0,23.5\n' > merania/teplota.csv

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

cat merania/teplota.csv

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

cp merania/teplota.csv merania/zaloha.csv

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

mv merania/zaloha.csv merania/teplota-zaloha.csv

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

ls -l merania

Presmerovanie

  • > zapisuje výstup a existujúci súbor prepíše,
  • >> pridáva na koniec súboru.

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

printf '1,23.7\n' >> merania/teplota.csv

Mazanie pomocou rm bežne nepoužíva grafický kôš. Pri cvičení mažeme iba vlastné pripravené súbory.

4. Oprávnenia

28 – 36 min

Výpis môže obsahovať:

-rw-r----- 1 ziak ziak ... teplota.csv

Tri skupiny oprávnení patria:

  1. vlastníkovi,
  2. skupine,
  3. ostatným.
ZnakSúborAdresár
rČítanie obsahuVýpis názvov položiek
wZmena obsahuZmena položiek adresára pri potrebných ďalších právach
xSpusteniePrechod do adresára a prístup k položkám podľa mena

Príklad:

Príkazy pre Raspberry Pi OS (shell)

Dokumentácia Raspberry Pi

chmod u+x program.sh

pridá vlastníkovi právo na spustenie.

chmod 777 nie je univerzálna oprava problémov s prístupom. Práva nastavujeme podľa potreby.

5. Úložisko a zápis

36 – 41 min

Operačný systém môže zápisy dočasne držať v pamäti.

Náhle vypnutie môže spôsobiť:

  • stratu posledných údajov,
  • poškodenie súboru,
  • problémy so súborovým systémom.

Žurnálovanie, napríklad pri ext4, pomáha pri obnove konzistencie, ale negarantuje zachovanie každého posledného zápisu.

Dôležité údaje zálohujeme.

6. Úlohy a zápis

41 – 45 min

  1. Čím začína absolútna cesta? /.
  2. Čo robí >>? Pridáva výstup na koniec.
  3. Je /dev obyčajný priečinok dokumentov? Nie, obsahuje rozhrania zariadení.

Súborový systém organizuje súbory a adresáre.

Linux používa strom začínajúci /.

Absolútna cesta začína od koreňa, relatívna od aktuálneho adresára.

Oprávnenia určujú čítanie, zápis a vykonanie alebo prechod.

Správne vypnutie a zálohy chránia údaje.
