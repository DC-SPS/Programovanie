2.2 Architektúra MCU – CPU, ALU a registre

Architektúra mikrokontroléra · 45 minút

Trvanie: 45 minút Nadväznosť: Pamäťové architektúry.

Ciele hodiny

Žiak má vedieť:

  • pomenovať hlavné časti mikrokontroléra,
  • rozlíšiť CPU a celý MCU,
  • vysvetliť funkciu ALU a riadiacej jednotky,
  • opísať význam registrov,
  • vysvetliť úlohu PC, SP a stavových príznakov.

1. Čo obsahuje MCU?

0 – 5 min

Mikrokontrolér spája procesorové jadro, pamäte a periférie do jedného integrovaného obvodu.

┌───────────────────────────────────────┐
│                  MCU                  │
│                                       │
│  CPU ↔ pamäte ↔ vnútorné prepojenia    │
│                    ↕                  │
│       GPIO, časovače, ADC, UART...     │
└───────────────────────────────────────┘

CPU je časť MCU. Tieto pojmy nie sú totožné.

2. CPU a ALU

5 – 15 min

CPU

Procesorové jadro zabezpečuje vykonávanie inštrukcií.

Obsahuje alebo používa najmä:

  • riadiacu jednotku,
  • ALU,
  • registre,
  • vnútorné dátové cesty.

Riadiaca jednotka

  • dekóduje inštrukcie,
  • organizuje jednotlivé kroky,
  • vytvára riadiace signály.

ALU

Arithmetic Logic Unit – aritmeticko-logická jednotka.

Vykonáva napríklad:

  • sčítanie a odčítanie,
  • AND, OR a XOR,
  • porovnávanie,
  • posuny podľa možností procesora.

Nie každá operácia vyššieho programovacieho jazyka má vlastnú hardvérovú jednotku. Napríklad delenie alebo výpočty s desatinnými číslami môžu na niektorých MCU vyžadovať viac inštrukcií a knižničný kód.

3. Registre

15 – 27 min

Register je malé rýchlo dostupné úložisko používané procesorom alebo perifériou.

Pracovné registre

Uchovávajú operandy a výsledky.

ATmega328P má 32 pracovných 8-bitových registrov R0 až R31. Niektoré dvojice sa používajú aj ako adresové registre.

Špeciálne registre

RegisterÚloha
PC – program counterUrčuje miesto vykonávania programu
SP – stack pointerUrčuje aktuálnu pozíciu zásobníka
Stavový registerUchováva príznaky výsledkov a riadenia

Presná definícia hodnoty PC počas jednotlivých fáz závisí od architektúry. Pre základný model predstavuje informáciu, odkiaľ procesor získava alebo bude získavať inštrukcie.

Stavové príznaky

Na AVR napríklad:

PríznakVýznam
Z – ZeroVýsledok príslušnej operácie je nula
C – CarryPrenos alebo výpožička podľa operácie
N – NegativeIndikuje najvyšší bit výsledku
V – OverflowZnamienkové pretečenie
IGlobálne povolenie prerušení

Nie každá inštrukcia mení všetky príznaky.

Príklad

Pri 8-bitovom neznamienkovom sčítaní:

255 + 1 → spodných 8 bitov je 0

Pri zodpovedajúcej inštrukcii môže byť:

  • Z = 1,
  • C = 1.

Prenos pri neznamienkovom výpočte a znamienkové pretečenie nie sú rovnaký jav.

4. Pamäte a periférie

27 – 35 min

Pamäte

  • Flash: program a konštanty,
  • SRAM: pracovné údaje,
  • EEPROM: nastavenia na čipoch, ktoré ju poskytujú.

Periférie

PerifériaÚloha
GPIODigitálne vstupy a výstupy
ČasovačPočítanie času alebo impulzov
ADCPrevod analógového signálu
UARTAsynchrónna sériová komunikácia
SPI a I²CKomunikácia s ďalšími obvodmi
WatchdogDohľad nad postupom programu

Periférie môžu pracovať čiastočne nezávisle od CPU. Časovač napríklad počíta impulzy aj počas vykonávania iného kódu.

Dva druhy registrov

Rozlišujeme:

  • pracovné registre CPU,
  • konfiguračné a stavové registre periférií.

Napríklad PORTB na AVR ovláda GPIO port. Nie je to všeobecný pracovný register typu R16.

5. Model vykonania operácie

35 – 41 min

Úloha:

vysledok = a + b;

Zjednodušený priebeh:

  1. Získaj hodnotu a.
  2. Získaj hodnotu b.
  3. Umiestni operandy do vhodných registrov.
  4. ALU vykoná sčítanie.
  5. Ulož výsledok.
  6. Podľa inštrukcie aktualizuj príznaky.

Kompilátor môže postup optimalizovať. Premenné môžu zostať v registroch a niektoré výpočty sa môžu vykonať už pri preklade.

Úloha pre žiakov

Priraď funkciu:

  • ALU,
  • PC,
  • SP,
  • ADC,
  • UART.

Riešenie: výpočty; miesto v programe; zásobník; analógový prevod; sériový prenos.

6. Overenie a zápis

41 – 45 min

  1. Je MCU iba ALU? Nie.
  2. Má každý mikrokontrolér ADC? Nie, závisí od typu.
  3. Je register to isté ako súbor na úložisku? Nie.

Zápis do zošita

MCU obsahuje CPU, pamäte a periférie.

CPU vykonáva inštrukcie. Riadiaca jednotka organizuje ich priebeh.

ALU vykonáva aritmetické a logické operácie.

Registre uchovávajú operandy, výsledky, adresy a riadiace informácie.

PC súvisí s vykonávaním programu, SP so zásobníkom.

Stavové príznaky opisujú výsledky vybraných operácií.

Praktická ukážka: čítanie vstupu a riadenie LED

Úplný program skopírujte do online simulátora Arduino Uno. Simulátor predstavuje mikrokontrolér ATmega328P a umožňuje sledovať vykonávanie programu. Zapojte tlačidlo medzi pin 2 a GND.

Otvoriť online simulátor Arduino Uno (Wokwi)
const byte LED_PIN = LED_BUILTIN;
const byte SENSOR_PIN = A0;
unsigned int sensorValue = 0;

void setup() {
    pinMode(LED_PIN, OUTPUT);
}

void loop() {
    sensorValue = analogRead(SENSOR_PIN);
    digitalWrite(LED_PIN, sensorValue > 512 ? HIGH : LOW);
    delay(20);
}
