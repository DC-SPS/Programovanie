# Vstup a výstup

## Cieľ témy

Pochopte, ako program prijíma údaje, spracuje ich a zobrazí výsledok.

## Predpoklady

Základná orientácia v prostredí Pythonu z [témy 1.2](../1.2%20Vstup%20do%20predmetu.html).

## Materiály

Samostatná prednáška venovaná výhradne vstupu a výstupu zatiaľ nie je v prehľade kurzu. Základné použitie `input()` a `print()` je súčasťou [algoritmizácie funkcií](../2.10%20Algoritmiz%C3%A1cia%20funkci%C3%AD.html).
