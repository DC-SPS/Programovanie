# Reťazce a súbory

## Cieľ témy

Pracujte s textovými údajmi a pochopte, ako program môže čítať alebo ukladať údaje do súboru.

## Predpoklady

Poznajte premenné a základné dátové typy. Na prácu so sekvenciami nadväzujú [dátové štruktúry a výrezy](../U%C4%8Debn%C3%A9%20materi%C3%A1ly/2.7.1%20D%C3%A1tov%C3%A9%20%C5%A1trukt%C3%BAry%20v%20Pythone.html).

## Materiály

Samostatná lekcia o reťazcoch a textových súboroch zatiaľ nie je v prehľade kurzu. Výrezy reťazcov sú zahrnuté v [téme 2.7.2](../U%C4%8Debn%C3%A9%20materi%C3%A1ly/2.7.2%20V%C3%BDrezy%20v%20Pythone.html); ukážkový projekt ukladá merania do JSON v súbore [`spravca_senzorov.py`](../projekty/spravca_senzorov.py).

## Ďalší krok

Pozrite si, ako sa údaje z kolekcií spracúvajú vo [funkciách](../2.10%20Algoritmiz%C3%A1cia%20funkci%C3%AD.html).
