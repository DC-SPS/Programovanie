Test 2: Trasovanie kódu v Pythone

Tieto otázky preverujú, či viete sledovať vykonávanie algoritmu zapísaného v Pythone.

1. Čo vypíše tento program?
sucet = 0
for cislo in range(1, 4):
    sucet += cislo
print(sucet)

2. Čo vypíše program pri n = 0?
n = 0
if n >= 0:
    print("nezáporné")
else:
    print("záporné")

3. Čo vypíše tento program?
def zdvojnasob(x):
    return x * 2

print(zdvojnasob(4))
